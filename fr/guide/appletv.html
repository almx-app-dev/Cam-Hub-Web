14Apple TV

L’app Apple TV affiche les appareils et le mur LiveView Mix configurés sur un iPhone ou un iPad, et permet de regarder la vidéo en direct et les enregistrements à l’aide de la télécommande. L’ordre recommandé consiste à terminer d’abord toute la configuration sur un iPhone ou un iPad, puis à la transférer vers l’Apple TV. Ce chapitre donne les étapes correspondantes, décrit les quatre onglets de l’app Apple TV et énumère les différences par rapport à l’iPhone et à l’iPad.

Configurer d’abord sur un iPhone ou un iPad

L’Apple TV se commande à la télécommande. La saisie, le dessin et le choix y sont laborieux, et plusieurs fonctions ne sont pas proposées du tout. Ces tâches se font donc sur un iPhone ou un iPad avant d’utiliser l’Apple TV :

  • Ajouter les appareils ; voir chapitre 3 : « Ajouter un appareil ».
  • Construire le mur LiveView Mix, avec une disposition personnalisée et des panneaux de commande si nécessaire ; voir chapitre 8 : « LiveView Mix » et chapitre 9 : « Panneaux de commande et webhooks ».
  • Choisir les formules et les caméras à afficher ; voir chapitre 11 : « Formules et limites ».

Transférer la configuration vers l’Apple TV

Prérequis : l’iPhone ou l’iPad et l’Apple TV sont connectés à iCloud avec le même compte Apple, et les deux utilisent la même version de Cam Hub. Une sauvegarde réalisée par une version plus ancienne n’apparaît pas sur l’Apple TV.

  1. Sur l’iPhone ou l’iPad, terminez la configuration : les appareils, le mur LiveView Mix, les formules et le choix des caméras à afficher.

    Vérification : Les appareils et le mur apparaissent sur l’iPhone ou l’iPad tels qu’ils doivent apparaître sur le téléviseur.

  2. Sur l’iPhone ou l’iPad, sauvegardez sur iCloud avec Apple TV comme destination ; voir « Sauvegarder sur iCloud ».

    Vérification : La page de sauvegarde affiche le message indiquant que la sauvegarde a été réalisée, et Sauvegarde actuelle indique l’heure et le nombre d’appareils. Une nouvelle sauvegarde vers Apple TV remplace la copie Apple TV précédente.

  3. Sur l’Apple TV, ouvrez l’onglet Réglages et sélectionnez Restaurer depuis iCloud dans la section Sauvegarde iCloud.

    Vérification : La page indique l’heure de la sauvegarde dans Créée le et son contenu dans Appareils. Si la section affiche Aucune sauvegarde trouvée dans iCloud pour l’instant à la place de la ligne, voir « Partage, import et sauvegarde iCloud ».

  4. Sélectionnez Restaurer. Ce qu’une restauration modifie est décrit dans « Restaurer depuis iCloud ».

    Vérification : La page indique combien d’appareils ont été restaurés. L’onglet Appareils de l’Apple TV les liste, et l’onglet LiveView Mix affiche le mur.

  5. Sur l’Apple TV, sélectionnez Formules dans l’onglet Réglages.

    Vérification : La page affiche la formule du compte Apple. Une formule qui n’est pas encore affichée apparaît après Restaurer les achats.

L’Apple TV ne restaure que la copie sauvegardée pour elle. Les sauvegardes nommées conservées sous Ma sauvegarde ne sont listées que sur l’iPhone et l’iPad ; voir « Plusieurs sauvegardes nommées : renommer et supprimer ».

Les modifications ultérieures n’atteignent l’Apple TV qu’avec une nouvelle sauvegarde

Après une modification des appareils, du mur ou des formules sur l’iPhone ou l’iPad, répétez les étapes 2 à 4. L’Apple TV ne suit pas les modifications d’elle-même. Un mot de passe d’appareil modifié peut aussi être saisi sur l’Apple TV avec Modifier les identifiants sur la page de l’appareil ; voir « L’onglet Appareils et la page de l’appareil ».

Avec un code de partage

Lorsque les deux appareils ne partagent pas le même compte Apple, un code de partage remplace la sauvegarde. Un code peut compter de plusieurs centaines à plusieurs milliers de caractères ; une sauvegarde iCloud est donc préférable chaque fois que le compte Apple est le même. Créez le code sur l’iPhone ou l’iPad comme décrit dans « Exporter des caméras (créer un code) », puis poursuivez sur l’Apple TV.

  1. Ouvrez l’onglet Réglages.

    Vérification : La liste des réglages commence par la section Sauvegarde iCloud.

  2. Dans la section Partager les caméras, sélectionnez Importer des caméras.

    Vérification : La page Importer des caméras affiche un champ sous Saisir le code et le bouton Importer des caméras.

  3. Sélectionnez le champ et saisissez le code.

    Vérification : Le code apparaît dans le champ. Tant que le clavier est affiché, un iPhone à proximité peut saisir le code. Un code verrouillé affiche une note sous le champ : Verrouillé par un code PIN à 6 chiffres — il vous sera demandé. ou Verrouillé par un mot de passe — il vous sera demandé.

  4. Sélectionnez Importer des caméras.

    Vérification : Un code verrouillé ouvre Saisir le code PIN ou Saisir le mot de passe. Un code ouvert est importé, et l’alerte 3 caméras ajoutées apparaît. L’une des questions décrites ci-dessous peut s’afficher avant.

  5. Pour un code verrouillé, saisissez le code PIN ou le mot de passe.

    Vérification : Le champ de la boîte de dialogue affiche la saisie ; un mot de passe apparaît sous forme de points.

  6. Sélectionnez Importer.

    Vérification : La boîte de dialogue se ferme, et l’import se poursuit comme pour un code ouvert. Un code PIN ou un mot de passe qui ne déverrouille pas le code affiche Code PIN incorrect ou Mot de passe incorrect.

  7. Dans l’alerte 3 caméras ajoutées, sélectionnez OK.

    Vérification : La liste des réglages s’affiche de nouveau, et l’onglet Appareils liste les appareils ajoutés.

Avant l’ajout des caméras, les mêmes questions que sur un iPhone ou un iPad peuvent apparaître :

  • Ce code modifie des adresses de caméras, lorsque le code déplacerait vers d’autres adresses des caméras qui existent déjà sur cette Apple TV. La boîte de dialogue liste ces caméras avec l’adresse actuelle et la nouvelle adresse. Utiliser les nouvelles adresses envoie aux nouvelles adresses les mots de passe enregistrés pour ces caméras et ne convient qu’à un code provenant d’un expéditeur de confiance, Conserver les adresses actuelles conserve leurs adresses, et Annuler n’importe rien ; voir « Lorsqu’un code modifie des adresses de caméras ».
  • Ce code contient aussi les réglages de l’app de l’expéditeur, lorsque le code contient des réglages de l’app. Ajouter les caméras seulement conserve les réglages de l’Apple TV, et Utiliser aussi ses réglages les remplace, y compris le mur LiveView Mix et la langue ; voir « Importer des caméras ».

Lorsque le code ne peut pas être lu, l’alerte Impossible de lire ce code demande de vérifier que le code complet issu d’un export Cam Hub a été saisi.

L’onglet En direct

L’app Apple TV comporte quatre onglets en haut de l’écran : LiveView Mix, En direct, Appareils et Réglages. L’onglet En direct affiche les caméras activées d’un seul appareil à la fois sous forme de mur, avec le nom de l’appareil en haut à droite.

  • Choisir l’appareil : avec plusieurs appareils, une rangée de boutons sous le titre contient un bouton par appareil ; son symbole distingue un enregistreur d’une caméra. Sélectionnez un bouton pour afficher les caméras de cet appareil. Le bouton sélectionné est rempli de cyan, et le choix est conservé à la prochaine ouverture de l’app. Avec un seul appareil, la rangée n’est pas affichée.
  • Le mur : une caméra occupe toute la zone, deux à quatre caméras sont affichées à raison de deux par rangée, et cinq ou plus à raison de trois par rangée. Trois rangées tiennent à l’écran ; les rangées suivantes apparaissent à mesure que la sélection descend. Chaque case affiche le numéro et le nom de la caméra en bas à gauche.
  • Qualité et bandes noires : le mur utilise Plusieurs caméras et Bandes noires de l’onglet Réglages ; voir « L’onglet Réglages ». L’onglet n’a de bouton propre ni pour l’un ni pour l’autre.
  • Ouvrir une caméra : placez la sélection sur une case, puis appuyez sur Sélectionner. La caméra s’ouvre dans la vue d’une seule caméra, dans la qualité de Une seule caméra ; voir « La vue d’une seule caméra, la lecture et les événements ». Un cadre cyan marque la case sélectionnée ; il s’estompe lorsque la sélection n’a pas bougé pendant environ 5 secondes et réapparaît lorsque la sélection bouge de nouveau. Une case hors ligne, en pause ou hors formule ne peut pas être sélectionnée. La mise en pause et la reprise se font sur un iPhone ou un iPad ; voir « Options d’un canal (appui long) ».
  • Caméras sans signal : tant que Masquer les caméras hors ligne est activé, elles sont exclues du mur ; voir « L’onglet Réglages ».

Sans appareil, l’onglet affiche Aucun appareil avec Ajoutez une caméra ou un enregistreur dans l’onglet Appareils. Un appareil sans caméra activée affiche Aucune caméra activée avec Activez les caméras de cet appareil sur votre iPhone ou iPad. Sur l’Apple TV elle-même, les caméras s’activent dans Réglages › Choisissez les caméras à afficher tant que cette ligne est proposée ; voir « L’onglet Réglages ».

L’onglet LiveView Mix

L’app s’ouvre sur l’onglet LiveView Mix. Il affiche la page paysage du mur. Une page portrait ou une zone du bas arrivée avec une sauvegarde est conservée mais n’est pas affichée, et ses panneaux de commande n’utilisent aucun quota.

L’aperçu dans l’onglet

Sous le titre, le bouton Plein écran ouvre le mur. En dessous, les caméras du mur apparaissent sous forme de grille simple, et non dans la disposition du mur : une caméra occupe toute la zone, deux à quatre sont affichées à raison de deux par rangée, et cinq ou plus à raison de trois par rangée. La grille utilise les bandes noires et le filigrane du mur. Sélectionnez une case pour ouvrir cette caméra dans la vue d’une seule caméra ; une caméra ouverte depuis LiveView Mix démarre toujours en HD. Les panneaux de commande, les horloges, les étiquettes et les images n’apparaissent pas dans l’aperçu. Tant que Masquer les caméras hors ligne est activé, les caméras sans signal sont exclues de la grille.

Lorsque le mur ne contient aucune caméra présente sur cette Apple TV, par exemple uniquement des panneaux de commande, l’onglet affiche Ouvrir en plein écran avec Vos panneaux LiveView Mix apparaissent sur le mur en plein écran. au lieu de la grille. Lorsqu’aucun mur n’est configuré, l’onglet affiche LiveView Mix est vide.

Le mur plein écran

  1. Sélectionnez Plein écran.

    Vérification : Le mur occupe l’écran dans sa disposition, et un cadre cyan marque la caméra ou le bouton sélectionné. Le mur s’ouvre sur la première page qui a quelque chose à afficher.

  2. Déplacez la sélection avec la télécommande.

    Vérification : Le cadre passe à la caméra ou au bouton de panneau de commande suivant. Un appui à gauche ou à droite au bord du mur affiche la page précédente ou suivante. Le cadre s’estompe lorsque la sélection n’a pas bougé pendant environ 5 secondes et réapparaît lorsque la sélection bouge de nouveau.

  3. Appuyez sur Sélectionner.

    Vérification : Sur une caméra, la vue d’une seule caméra s’ouvre en HD ; Menu ramène au mur. Sur un bouton de panneau de commande, le bouton envoie sa requête.

  4. Appuyez sur Menu.

    Vérification : Le mur se ferme, et l’onglet affiche de nouveau l’aperçu.

Chaque bouton d’un panneau de commande constitue une sélection à part, et la sélection saute un panneau qui n’est pas inclus dans la formule. Un bouton pour lequel Confirmer avant d’exécuter est activé ouvre d’abord une boîte de dialogue intitulée avec le nom du panneau, ou Exécuter cette action ? pour un panneau sans nom, qui propose le libellé du bouton (ou Confirmer) et Annuler. Les panneaux de commande apparaissent et peuvent être actionnés uniquement sur le mur plein écran, et non dans l’aperçu, et ils ne peuvent pas être modifiés sur l’Apple TV. Un filigrane réglé sur l’iPhone ou l’iPad est affiché sur les cases. Lorsque le mur ne contient que des caméras qui ne sont pas sur cette Apple TV, le mur affiche Ces caméras ne sont pas sur cet appareil. Un mur plein écran qui était ouvert s’affiche de nouveau après le redémarrage de l’app.

Modifier le mur sur l’Apple TV

La page Réglages › LiveView Mix modifie la page paysage du mur sur l’Apple TV elle-même. La ligne indique le nombre de caméras du mur, ou Désactivé tant qu’aucun mur n’est configuré.

  1. Dans l’onglet Réglages, sélectionnez LiveView Mix.

    Vérification : La page LiveView Mix s’ouvre. La section Disposition plein écran affiche une rangée de dispositions prêtes à l’emploi et le sélecteur Bandes noires sur ce mur. Plus bas, la note Appuyez sur une caméra pour l’ajouter en SD. Appuyez de nouveau pour la HD, et une fois de plus pour la retirer. est suivie des caméras de chaque appareil, une section par appareil.

  2. Sélectionnez une caméra.

    Vérification : La ligne affiche une coche et SD : la caméra est sur le mur en SD. Une section au-dessus des caméras compte les caméras du mur, par exemple Sélection — 3 caméras, et propose Tout en SD et Tout en HD.

  3. Sélectionnez de nouveau la même caméra.

    Vérification : La ligne affiche HD : la caméra est sur le mur en HD. Un troisième appui retire la caméra du mur.

  4. Dans la rangée des dispositions, sélectionnez une disposition.

    Vérification : La disposition est mise en évidence, et le mur plein écran l’utilise.

La rangée propose toutes les dispositions prêtes à l’emploi, y compris celles de plus de 16 cases, que l’iPhone et l’iPad ne proposent plus pour un nouveau mur. Une disposition personnalisée ne peut pas être dessinée à la télécommande : une fois qu’elle a été dessinée sur un iPhone ou un iPad, elle apparaît à la fin de la rangée et peut être choisie, ce qu’indique le texte sous la section. Bandes noires sur ce mur règle les bandes noires de ce mur uniquement. Tout en SD et Tout en HD règlent en une fois toutes les caméras du mur. Le changement de l’ordre, la modification des cases, l’ajout d’horloges, d’étiquettes, d’images ou de panneaux de commande, le filigrane et Garder les caméras connectées entre les pages ne sont pas proposés sur l’Apple TV. Une note en fin de page recommande de tout configurer sur l’iPhone ou l’iPad et de transférer la configuration avec une sauvegarde. Sans appareil, la page affiche Aucun appareil avec Ajoutez d’abord un appareil, puis choisissez ses caméras ici.

L’onglet Appareils et la page de l’appareil

L’onglet Appareils commence par Ajouter un appareil IP. En dessous, la section Appareils liste une ligne par appareil avec son nom, son modèle et son adresse. À droite, chaque ligne affiche l’indicateur de connexion, le symbole Wi-Fi vert ou rouge décrit dans « La liste des appareils », ou à la place Démo pour un appareil de démonstration et iPhone ou iPad uniquement pour une diffusion YouTube ou Twitch. Non inclus dans votre formule s’ajoute lorsque la formule exclut des caméras de l’appareil.

Sans appareil, la section Configurez sur iPhone, iPad ou Mac, puis restaurez ici explique que les caméras et le mur se configurent de préférence sur l’un de ces appareils et se restaurent sur l’Apple TV à partir d’une sauvegarde iCloud, et qu’un seul abonnement couvre tous les appareils connectés au même compte Apple. Ajouter un appareil IP reste disponible au-dessus. Un appareil se supprime sur sa page ; la liste n’offre aucun autre moyen de le supprimer.

Ajouter un appareil

Ajouter un appareil IP ouvre la page Ajouter un appareil. Le formulaire est plus court que sur un iPhone ou un iPad : il n’y a ni analyse du réseau, ni liste de marques, ni liste de vérification, ni rapport sur l’appareil.

  1. Dans l’onglet Appareils, sélectionnez Ajouter un appareil IP.

    Vérification : La page Ajouter un appareil s’ouvre.

  2. Saisissez l’adresse de l’appareil dans Adresse IP ou nom d’hôte.

    Vérification : L’adresse apparaît dans le champ.

  3. Saisissez le mot de passe dans Mot de passe.

    Vérification : Le champ affiche le mot de passe sous forme de points.

  4. Sélectionnez Ajouter.

Ajouter est indisponible tant que l’adresse ou le nom d’utilisateur est vide. Annuler interrompt une connexion encore en cours et ferme la page sans rien enregistrer. À la limite d’enregistreurs, le formulaire affiche La formule gratuite inclut 1 enregistreur. Ajoutez-en plus avec une formule NVR., ou une phrase plus longue lorsque les appareils de démonstration occupent la place, au lieu d’ouvrir l’écran des formules. Sous le bouton, Ajouter des caméras de démo ajoute deux caméras de démonstration qui dessinent leur propre image, et Ajouter le parc de démonstration ajoute cinq enregistreurs de démonstration et deux caméras de ce type ; voir « Essayer l’app sans appareil ».

La page de l’appareil

Sélectionnez un appareil dans la liste pour ouvrir sa page. Le nom de l’appareil apparaît en haut à droite, au-dessus d’une rangée de boutons :

  • Retour ramène à la liste.
  • Afficher les détails ou Masquer les détails affiche ou masque les détails : Modèle, Adresse IP (Lien pour une diffusion YouTube ou Twitch), Type (Enregistreur ou Caméra), Numéro de série et Micrologiciel lorsque l’appareil les signale, Caméras avec le nombre de caméras, et HTTPS avec le port tant que HTTPS est activé.
  • Renommer ouvre Renommer l’appareil, avec le champ Nom et Enregistrer.
  • Modifier les identifiants, pour un appareil doté de ses propres identifiants de connexion, enregistre un nouveau nom d’utilisateur et un nouveau mot de passe ; voir « Modifier le nom d’utilisateur et le mot de passe d’un appareil ». Un appareil sans mot de passe enregistré affiche Aucun mot de passe enregistré. Saisissez-le à nouveau dans « Appareils ». sur ses cases ; sur l’Apple TV, le mot de passe se saisit ici.
  • HTTPS, proposé lorsque l’appareil répond en HTTPS ou que HTTPS est déjà activé, ouvre les réglages HTTPS de l’appareil ; voir « HTTPS pour un appareil enregistré ».

Sous les boutons, les caméras activées forment un mur qui utilise Plusieurs caméras et Bandes noires de l’onglet Réglages. Sélectionnez une case pour ouvrir la caméra dans la qualité de Une seule caméra. Tant que Masquer les caméras hors ligne est activé, les caméras sans signal sont aussi exclues de ce mur ; seul le nombre sous Caméras les compte encore. Sans caméra activée, la page affiche Aucune caméra activée avec Choisissez les caméras à afficher dans Réglages. Il n’y a ni menu pour une caméra, ni mur plein écran, ni État du disque.

Supprimer l’appareil, sous le mur, demande Supprimer cet appareil ? Le message nomme l’appareil et le nombre de ses caméras qui sont supprimées, ainsi que le mot de passe enregistré s’il y en a un, et indique que cette action est irréversible. Sélectionnez Supprimer pour supprimer l’appareil, ou Annuler.

La vue d’une seule caméra, la lecture et les événements

Une caméra ouverte depuis un mur occupe tout l’écran. Une caméra ouverte depuis l’onglet En direct ou une page d’appareil démarre dans la qualité de Une seule caméra ; une caméra ouverte depuis LiveView Mix démarre en HD. Une pastille en haut à gauche affiche DIRECT, ou l’heure de l’enregistrement en cours de lecture. Les boutons se trouvent en haut à droite :

BoutonAffichéAction
ÉvénementsLorsque l’appareil offre des événements ; voir ci-dessous.Ouvre la liste des événements du jour choisi.
SD ou HDEn vue en direct.Indique la qualité actuelle et bascule entre SD et HD.
Couper le son ou Activer le sonLorsque le flux comporte du son.Coupe ou active le son. Le choix s’applique à toutes les caméras.
Ajuster ou RemplirToujours.Indique le mode actuel et le change. Ajuster affiche l’image entière ; Remplir l’étire jusqu’aux bords de l’écran, ce qui peut la déformer. La vue s’ouvre toujours en Ajuster.
FermerToujours.Ramène au mur.

À part SD ou HD, chaque bouton n’affiche qu’un symbole ; son nom apparaît à côté du symbole tant que le bouton est sélectionné. Après environ 5 secondes sans appui, les boutons et la frise chronologique se masquent ; un balayage sur la télécommande les affiche de nouveau. Menu ferme la vue. Pendant la connexion de l’image, Connexion… ou Reconnexion… s’affiche ; lorsque le flux échoue, la raison s’affiche avec Réessayer. Une caméra hors formule affiche Non inclus dans votre formule avec le bouton Choisissez les caméras à afficher, qui ouvre la page Licence ; voir « L’onglet Réglages ». Il n’y a ni instantané, ni enregistrement d’extraits, ni conversation, ni PTZ, ni zoom.

Lire un enregistrement

Pour un appareil compatible avec la lecture, une frise chronologique s’étend le long du bas de l’image. Les barres bleues marquent les enregistrements continus et les barres rouges les enregistrements sur événement. Le jour apparaît en haut à gauche de la frise, et l’heure sous la ligne centrale fixe, en haut au milieu. La frise affiche 4 heures au départ.

  1. Descendez la sélection jusqu’à la frise chronologique.

    Vérification : La frise est entourée de cyan, et une rangée de boutons apparaît au-dessus : Jour précédent, Jour suivant, Zoom arrière, Zoom avant et Lire. Chaque bouton affiche un symbole, et son nom apparaît tant qu’il est sélectionné.

  2. Appuyez à gauche ou à droite sur la télécommande.

    Vérification : L’heure sous la ligne centrale avance ou recule d’un vingtième de la durée visible et reste dans le jour choisi. Rien n’est encore lu.

  3. Sélectionnez Lire.

    Vérification : L’enregistrement est lu à partir de l’heure sous la ligne centrale. La pastille en haut à gauche affiche l’heure de l’enregistrement au lieu de DIRECT, et le bouton En direct apparaît dans la rangée.

  4. Sélectionnez En direct.

    Vérification : L’image en direct revient.

Jour précédent et Jour suivant changent le jour ; Jour suivant est indisponible pour le jour actuel de l’appareil. Zoom arrière et Zoom avant modifient la durée visible entre 10 minutes et 24 heures. La rangée de boutons n’est affichée que tant que la sélection se trouve sur la frise ou sur l’un de ces boutons. Lorsqu’aucun enregistrement ne suit, Fin de l’enregistrement s’affiche. Un enregistrement qui doit être téléchargé sous forme de fichier avant sa lecture n’est pas lu sur l’Apple TV ; l’écran affiche Regardez cet enregistrement sur votre iPhone ou iPad. L’Apple TV n’a pas de calendrier et ne lit les enregistrements qu’à vitesse normale.

Événements

Lorsque l’appareil tient un index des événements ou que la frise comporte des enregistrements sur événement, le bouton Événements ouvre la liste des événements. Le jour apparaît en haut entre deux flèches qui le changent ; la flèche de droite est indisponible pour le jour actuel de l’appareil. Chaque ligne nomme le type d’événement, Personne détectée, Mouvement détecté, Entrée d’alarme ou Enregistrement sur événement, avec son heure. La liste va du plus ancien au plus récent et contient aussi les événements de la veille, affichés sans leur date. Un jour sans événement affiche Aucun événement ce jour-là., ou Aucune personne détectée ce jour-là. pour un appareil qui recherche les personnes. La liste sur l’iPhone et l’iPad est décrite dans « La liste des enregistrements et des événements ».

  1. Sélectionnez Événements.

    Vérification : La page Événements s’ouvre avec les événements du jour choisi.

  2. Sélectionnez un événement.

    Vérification : La liste se ferme, et l’enregistrement est lu à partir de 5 secondes avant l’événement, mais pas avant le début de son enregistrement. Menu ferme la liste sans lancer de lecture.

Réinitialiser

Rétablir les réglages par défaut demande Rétablir tous les réglages par défaut ? et Supprimer toutes les données demande Supprimer toutes les données ?. Les deux boîtes de dialogue et leurs effets sont les mêmes que sur un iPhone ou un iPad, avec la confirmation Rétablir les valeurs par défaut et Tout supprimer ; voir « Réinitialisation : valeurs par défaut, suppression de toutes les données, suppression de la sauvegarde iCloud ». Rétablir les réglages par défaut vide donc aussi le mur LiveView Mix de l’Apple TV. Supprimer la sauvegarde iCloud demande Supprimer la sauvegarde iCloud ? et supprime uniquement la copie Apple TV de la sauvegarde ; les sauvegardes nommées de Ma sauvegarde restent, de même que les appareils et les réglages de l’Apple TV. La ligne est indisponible tant qu’aucune copie Apple TV n’existe.

Masquer les caméras hors ligne

Tant que Masquer les caméras hors ligne est activé, les caméras sans signal sont exclues des murs de l’onglet En direct et des pages d’appareil, ainsi que de l’aperçu de l’onglet LiveView Mix. Seul le mur LiveView Mix plein écran conserve leurs places. Ce fonctionnement diffère de celui de l’iPhone et de l’iPad, où la page de l’appareil les conserve ; voir « Masquer les caméras sans signal ». Lorsqu’il ne reste aucune caméra d’un mur, le mur reste vide. Activer ou désactiver l’interrupteur vérifie de nouveau toutes les caméras.

Formules

La page Formules affiche, dans la section Abonnements, la ligne Formule actuelle et chaque formule caméras et formule NVR avec ce qu’elle débloque ; la formule actuelle porte une coche. Sélectionnez une formule pour vous abonner avec le compte Apple ; une formule peut être sélectionnée dès que l’App Store a répondu. D’ici là, une ligne à la fin de la section indique que l’App Store n’a pas encore répondu ; lorsqu’il ne peut pas être joint, cette ligne propose de réessayer. Le texte sous la section indique que les deux quotas sont comptés séparément et que l’abonnement suit le compte Apple. La section Mentions légales suit, et Restaurer les achats se trouve en fin de page.

Un achat qui n’aboutit pas est signalé dans une alerte que OK ferme : L’achat a échoué. Veuillez réessayer., En attente d’approbation. La formule sera débloquée dès que l’achat sera approuvé. pour un achat en attente d’approbation, ou L’App Store n’a pas pu confirmer cet achat. Essayez « Restaurer les achats ». Il n’y a ni Gérer l’abonnement ni Utiliser un code ; tous deux se trouvent sur l’iPhone et l’iPad, voir « Abonnement ». Un seul abonnement couvre tous les appareils qui utilisent le même compte Apple.

Choisir les caméras affichées

Choisissez les caméras à afficher ouvre la page Licence. La section Votre formule indique les quotas sous Caméras et Enregistreurs ; les quotas eux-mêmes sont décrits dans « Le quota de chaque formule ». Chaque appareil suit sous forme de section, avec un interrupteur par caméra.

  1. Sélectionnez l’interrupteur d’une caméra.

    Vérification : L’interrupteur s’active, et la caméra apparaît sur les murs. Lorsque la formule ne le permet pas, l’interrupteur reste désactivé et une alerte en indique le motif.

  2. Lorsqu’une alerte apparaît, sélectionnez OK.

    Vérification : L’alerte se ferme. Contrairement à l’iPhone ou à l’iPad, l’écran des formules ne s’ouvre pas ; voir « Choisir les caméras à afficher ».

Un interrupteur peut toujours être désactivé. Sans appareil, la page affiche Aucun appareil avec Ajoutez d’abord un appareil, puis choisissez ses caméras ici.

Ce que l’onglet Réglages de l’Apple TV ne contient pas

L’Apple TV n’a ni Ouvrir au lancement, ni Vidéo bord à bord, ni export d’un code, ni création d’une sauvegarde. Il n’y a pas non plus de ligne Manuel ni de ligne Contacter l’équipe de développement : l’onglet se termine par À propos › Version. Pour écrire à l’équipe de développement, utilisez un iPhone ou un iPad ; voir « Contacter l’équipe de développement ».
