10Partage et sauvegarde

Les appareils avec leurs mots de passe, et éventuellement les réglages de l’app (pages LiveView Mix et panneaux de commande), peuvent être transférés vers un autre appareil ou partagés avec d’autres personnes sous forme d’un code chiffré, ou sauvegardés sur iCloud sous forme de plusieurs sauvegardes nommées, puis restaurés sur ses propres iPhone, iPad et Apple TV.

Exporter des caméras (créer un code)

Prérequis : au moins un appareil a été ajouté. Tant qu’il n’y a aucun appareil, Exporter les caméras est indisponible.

  1. Touchez l’onglet Réglages en bas de l’écran.

    Vérification : L’écran affiche la liste des réglages.

  2. Dans la section Partager les caméras, touchez Exporter les caméras.

    Vérification : La page Exporter les caméras s’ouvre : la liste Appareils à exporter (tous cochés par défaut), Verrouiller avec un code PIN, Inclure les réglages de l’app, et un bouton du type Exporter 5 appareils.

  3. Facultatif : touchez la ligne d’un appareil pour retirer ou rétablir sa coche.

    Vérification : Le bouton d’export affiche le nombre d’appareils sélectionnés, par exemple Exporter 3 appareils. Tant que tous les appareils sont cochés, le bouton à droite du titre de la liste indique Tout désélectionner et retire toutes les coches ; tant qu’un appareil n’est pas coché, il indique Tout sélectionner et coche tous les appareils. Tant qu’aucun appareil n’est sélectionné, le bouton d’export est indisponible.

  4. Facultatif : activez Inclure les réglages de l’app.

    Vérification : L’interrupteur est activé, et l’explication en dessous change pour indiquer que le code contient aussi les réglages de l’app, comme lors d’une restauration depuis iCloud. Pour les éléments transmis, voir « Contenu des sauvegardes et des codes ».

  5. Facultatif : définissez le verrouillage comme décrit dans « Verrouiller un code ».

    Vérification : Une fois un verrouillage défini, Exporter 3 appareils reste indisponible tant que la saisie n’est pas complète. Sans verrouillage, le code est ouvert : quiconque possède le code et Cam Hub peut l’importer.

  6. Touchez le bouton d’export, par exemple Exporter 3 appareils.

    Vérification : La page de résultat s’ouvre avec le titre Exporter les caméras. Sa partie supérieure précise que le code contient les caméras et leurs mots de passe, chiffrés. Pour un code ouvert, elle ajoute, avec un repère orange, que quiconque possède le code et Cam Hub peut les ajouter ; pour un code verrouillé, elle rappelle que le code PIN ou le mot de passe doit être envoyé séparément. En dessous se trouvent les boutons Partager et Copier, puis le texte complet du code.

  7. Touchez Partager et sélectionnez un moyen d’envoi, ou touchez Copier.

    Vérification : Toucher Partager ouvre la feuille de partage du système, avec des options telles que Messages, Mail ou AirDrop. Toucher Copier remplace le bouton par Copié, et le texte complet du code se trouve dans le presse-papiers.

  8. Touchez OK dans le coin supérieur droit.

    Vérification : La page de résultat se ferme et la page Exporter les caméras s’affiche de nouveau.

  • Partager envoie un lien, Copier copie du texte. Partager envoie un lien qui commence par https://cam-hub.almx.cc/i#, avec le code après le « # », que les navigateurs n’envoient pas au serveur web. Copier place le texte complet dans le presse-papiers.
  • Le destinataire : si Cam Hub est installé, l’ouverture du lien ouvre directement la page d’import avec le code déjà saisi. S’il n’est pas installé, le lien ouvre une page web qui renvoie vers la page de téléchargement de l’app et affiche le code à copier.
  • Le texte du code commence par une courte explication en anglais et l’adresse d’installation, suivies du code lui-même, qui commence par CAMHUB1:, CAMHUB1L: ou CAMHUB2: et peut compter plusieurs milliers de caractères. Lors de l’import, le texte entier peut être collé, ou le code seul.
  • Un code contient les mots de passe des appareils. Un code n’expire pas, et la suppression des appareils ou de l’app sur l’appareil source n’invalide pas un code déjà partagé. Si un code a pu être exposé, changez les mots de passe des appareils concernés.
Un code transmet les mots de passe des appareils

Quiconque obtient un code sans verrouillage et possède Cam Hub peut importer chacun des appareils qu’il contient, avec son mot de passe. N’envoyez le code qu’à des personnes de confiance et définissez un verrouillage si nécessaire.

Verrouiller un code

Un code peut être ouvert, verrouillé par un code PIN à six chiffres, ou verrouillé par un mot de passe (Chiffrement complexe). La solidité de la protection diffère beaucoup entre les trois, et le choix dépend de la manière dont le code est envoyé.

Verrouiller avec un code PIN à six chiffres

  1. Sur la page Exporter les caméras, activez Verrouiller avec un code PIN.

    Vérification : Le champ Code PIN (6 chiffres) apparaît sous l’interrupteur, et l’explication change pour indiquer que la personne qui importe doit saisir ce code PIN et qu’il doit être envoyé séparément du code.

  2. Saisissez six chiffres.

    Vérification : Le champ n’accepte que des chiffres, le clavier se ferme après le sixième chiffre, et le bouton d’export devient disponible. Avec moins de chiffres, le bouton d’export reste indisponible.

Verrouiller avec un mot de passe (chiffrement complexe)

  1. Sur la page Exporter les caméras, activez Verrouiller avec un code PIN.

    Vérification : L’interrupteur Chiffrement complexe et le champ Code PIN (6 chiffres) apparaissent.

  2. Activez Chiffrement complexe.

    Vérification : Le champ du code PIN est remplacé par les deux champs Mot de passe (8 caractères min.) et Confirmer le mot de passe, et tout ce qui a été saisi auparavant est effacé.

  3. Saisissez le mot de passe dans le champ Mot de passe (8 caractères min.).

    Vérification : Le champ masque les caractères par des points. Toutes les lettres, tous les chiffres et tous les symboles sont acceptés, et un mot de passe plus long est plus solide.

  4. Saisissez de nouveau le même mot de passe dans le champ Confirmer le mot de passe.

    Vérification : Lorsque les deux saisies concordent et comptent au moins 8 caractères, le bouton d’export devient disponible. Lorsqu’elles diffèrent, le texte orange Les deux mots de passe ne correspondent pas. apparaît sous le champ et le bouton reste indisponible.

  • Envoyez le code PIN ou le mot de passe séparément du code, jamais dans le même message.
  • Un code PIN ou un mot de passe oublié ne peut pas être récupéré. Cam Hub ne l’enregistre pas et ne l’envoie pas au développeur. En cas d’oubli, exportez un nouveau code.
  • Un mot de passe respecte la casse, et les espaces comptent. Une même lettre accentuée saisie sur des claviers différents est traitée comme identique.
  • Lorsqu’un code est déposé dans un endroit qui n’est pas privé, tel qu’un groupe de discussion ou un e-mail, verrouillez-le avec un mot de passe et envoyez ce mot de passe par un autre canal.
  • La personne qui importe n’a pas besoin de savoir à l’avance quel verrouillage a été utilisé. Une fois le code collé, Cam Hub reconnaît lui-même le verrouillage et affiche l’invite et le clavier correspondants ; voir « Importer des caméras ».

Importer des caméras

Emplacement : Réglages › Importer des caméras, ou directement en touchant un lien de partage reçu.

Coller un code

  1. Touchez l’onglet Réglages en bas de l’écran.

    Vérification : L’écran affiche la liste des réglages.

  2. Dans la section Partager les caméras, touchez Importer des caméras.

    Vérification : La page Importer des caméras s’ouvre. Le titre de la section est Collez le code, avec les boutons Coller et Importer des caméras et une zone de texte.

  3. Touchez Coller. Sinon, maintenez le doigt appuyé dans la zone de texte et collez manuellement.

    Vérification : Le code apparaît dans la zone de texte. Si le code est verrouillé, une note de verrouillage apparaît sous les boutons : Verrouillé par un code PIN à 6 chiffres — il vous sera demandé. ou Verrouillé par un mot de passe — il vous sera demandé. Un code ouvert n’affiche aucune note.

  4. Touchez Importer des caméras.

    Vérification : Un code ouvert est lu aussitôt. Lorsqu’il indique une autre adresse pour un appareil déjà présent sur cet appareil et ne contient pas le mot de passe de cet appareil, la boîte de dialogue Ce code modifie des adresses de caméras apparaît d’abord. Sinon, un code sans réglages de l’app est importé directement et l’écran affiche 3 caméras ajoutées, et un code qui contient des réglages de l’app ouvre la boîte de dialogue Ce code contient aussi les réglages de l’app de l’expéditeur. Un code verrouillé ouvre la boîte de dialogue Saisir le code PIN (clavier numérique, champ 6 chiffres) ou la boîte de dialogue Saisir le mot de passe (clavier complet).

  5. Pour un code verrouillé, saisissez le code PIN ou le mot de passe, puis touchez Importer.

    Vérification : La boîte de dialogue se ferme, et un indicateur de chargement apparaît sous Importer des caméras pendant le déverrouillage du code, qui peut prendre un moment ; Importer des caméras est indisponible pendant ce temps. L’import se poursuit ensuite comme pour un code ouvert : avec la boîte de dialogue Ce code modifie des adresses de caméras, la boîte de dialogue Ce code contient aussi les réglages de l’app de l’expéditeur ou 3 caméras ajoutées.

  6. Lorsque la boîte de dialogue Ce code modifie des adresses de caméras apparaît, touchez Utiliser les nouvelles adresses ou Conserver les adresses actuelles.

    Vérification : La boîte de dialogue liste chaque appareil concerné sur une ligne, avec son adresse actuelle et l’adresse du code, et explique que les mots de passe enregistrés dans Cam Hub pour ces caméras seraient alors envoyés aux nouvelles adresses. Après l’un ou l’autre choix, l’écran affiche 3 caméras ajoutées ou, pour un code qui contient des réglages de l’app, la boîte de dialogue Ce code contient aussi les réglages de l’app de l’expéditeur. Annuler ferme la boîte de dialogue et n’importe rien. Pour ce que modifie chaque choix, voir « Lorsqu’un code modifie des adresses de caméras ».

  7. Lorsque la boîte de dialogue Ce code contient aussi les réglages de l’app de l’expéditeur apparaît, touchez Ajouter les caméras seulement ou Utiliser aussi ses réglages.

    Vérification : La boîte de dialogue explique que les murs LiveView Mix, la langue et les autres préférences de l’expéditeur remplaceraient ceux de cet appareil, et que cette opération est irréversible. Après l’un ou l’autre choix, l’écran affiche 3 caméras ajoutées. Ajouter les caméras seulement laisse les réglages de cet appareil tels quels ; Utiliser aussi ses réglages applique les réglages du code. Annuler ferme la boîte de dialogue sans rien importer.

  8. Touchez OK.

    Vérification : L’écran revient à la liste des réglages, et les appareils ajoutés apparaissent dans l’onglet Appareils.

Lorsque Coller est touché, le système peut demander si Cam Hub peut coller depuis une autre app ; autorisez-le. Sinon, maintenez le doigt appuyé dans la zone de texte et collez avec le menu de modification.

Annuler dans la boîte de dialogue Saisir le code PIN ou Saisir le mot de passe la ferme sans rien importer. Un indicateur de chargement s’affiche aussi sous Importer des caméras pendant l’enregistrement des appareils et entre deux boîtes de dialogue ; Importer des caméras est indisponible tant qu’il est affiché.

Importer depuis un lien

  1. Sur un iPhone ou un iPad où Cam Hub est installé, touchez le lien de partage reçu.

    Vérification : Cam Hub ouvre la page Importer des caméras avec le code déjà dans la zone de texte. Pour un code verrouillé, la note de verrouillage correspondante s’affiche.

  2. Touchez Importer des caméras et, pour un code verrouillé, saisissez le code PIN ou le mot de passe.

    Vérification : L’écran affiche 3 caméras ajoutées ou, d’abord, l’une des boîtes de dialogue décrites dans les étapes pour coller un code, ou les deux : Ce code modifie des adresses de caméras, puis, pour un code qui contient des réglages de l’app, Ce code contient aussi les réglages de l’app de l’expéditeur.

  3. Répondez à chaque boîte de dialogue qui apparaît, comme dans les étapes pour coller un code.

    Vérification : L’écran affiche 3 caméras ajoutées.

  • L’import fusionne. Un appareil du code qui correspond à un appareil déjà présent sur cet appareil le met à jour ; les autres appareils du code sont ajoutés, et les appareils déjà présents sur cet appareil ne sont pas supprimés. Un appareil correspond lorsqu’il a la même marque, le même numéro de série et le même nom d’utilisateur ou, lorsque l’un des deux n’a pas de numéro de série, la même marque, la même adresse, le même port HTTP et le même nom d’utilisateur ; un code importé sur l’appareil qui l’a créé correspond aussi à ses propres appareils. Un appareil correspondant reprend du code le nom, le modèle, le numéro de série et la version du micrologiciel, ainsi que les canaux. Il ne reprend le nom d’utilisateur, le mot de passe et les réglages SNMP d’un NAS (voir « État des disques ») que lorsque le code les contient : un mot de passe enregistré sur cet appareil n’est donc jamais remplacé par un mot de passe vide. Lorsque le code contient le mot de passe de l’appareil, l’appareil reprend aussi l’adresse, les ports et le chemin du flux du code, et son réglage HTTPS suit la règle décrite dans « Contenu des sauvegardes et des codes ». Lorsque le code ne contient pas de mot de passe pour lui, l’appareil conserve son adresse, ses ports, son chemin de flux et son réglage HTTPS, sauf si Utiliser les nouvelles adresses est choisi dans la boîte de dialogue Ce code modifie des adresses de caméras ; voir « Lorsqu’un code modifie des adresses de caméras ».
  • L’état d’activation des canaux est vérifié par rapport à la formule de cet appareil. Avec une formule, les canaux au-delà de son quota sont importés avec Désactivée. Avec la formule gratuite, l’état d’activation est conservé tel qu’il figure dans le code, et les canaux au-delà du quota gratuit affichent Non inclus dans votre formule et un cadenas jusqu’à ce qu’une formule les couvre. Pour les quotas, voir chapitre 11 : « Formules et limites ».
  • Réglages de l’app : les réglages ne sont appliqués que si le code a été exporté avec Inclure les réglages de l’app activé et que Utiliser aussi ses réglages est choisi. Ils remplacent alors les réglages correspondants de cet appareil, y compris les pages LiveView Mix et la langue. Une case qui affiche une caméra non importée avec le code devient une case vide, et toutes les autres cases gardent leur place. Avec Ajouter les caméras seulement, ou pour un code sans réglages de l’app, les réglages de cet appareil restent inchangés.
  • Les diffusions YouTube et Twitch d’un code sont importées comme les autres appareils et n’entament aucun quota de formule. Avant la lecture de la première diffusion d’un service sur cet appareil, les conditions de ce service sont présentées pour acceptation ; voir « Diffusions YouTube et Twitch ».

Lorsqu’un code modifie des adresses de caméras

Un code de partage peut indiquer une autre adresse pour un appareil déjà présent sur cet appareil, par exemple après un changement d’adresse de la caméra de l’expéditeur. Lorsque le code contient le mot de passe de cet appareil, l’appareil reprend l’adresse du code sans poser de question. Lorsque le code ne contient pas de mot de passe pour lui, l’import enverrait le mot de passe enregistré sur cet appareil à l’adresse du code, qui peut appartenir à quelqu’un d’autre. Cam Hub pose donc d’abord la question, avec la boîte de dialogue Ce code modifie des adresses de caméras. La boîte de dialogue et ses choix sont les mêmes sur iPhone, iPad et Apple TV.

Quand la boîte de dialogue apparaît

  • La boîte de dialogue apparaît après la lecture du code, après le code PIN ou le mot de passe d’un code verrouillé, et avant la boîte de dialogue Ce code contient aussi les réglages de l’app de l’expéditeur. Lorsqu’aucun appareil n’est listé, elle n’apparaît pas.
  • Un appareil n’est listé que si toutes ces conditions sont réunies : l’appareil du code correspond à un appareil de cet appareil (voir « Importer des caméras »), le code ne contient pas de mot de passe pour lui, et le code indique une autre adresse, un autre port HTTP ou un autre port RTSP. La même adresse écrite autrement, par exemple en majuscules ou avec des espaces avant ou après, ne compte pas comme une autre adresse. Lorsque le code n’a pas d’adresse pour l’appareil, l’adresse actuelle est considérée comme inchangée ; seul un port peut alors différer.
  • Un code contient le mot de passe de chaque appareil pour lequel le Cam Hub de l’expéditeur a un mot de passe enregistré. Un appareil sans mot de passe enregistré chez l’expéditeur (voir « Un appareil sans mot de passe enregistré ») est transmis sans mot de passe.

La boîte de dialogue comporte une ligne par appareil listé : son nom sur cet appareil, son adresse actuelle et l’adresse du code, chacune écrite sous la forme adresse et port HTTP, par exemple Porte d’entrée : 192.168.1.64:80 → 192.168.1.70:80. Lorsque le port RTSP diffère, les deux adresses l’ajoutent, par exemple Porte d’entrée : 192.168.1.64:80 (RTSP 554) → 192.168.1.64:80 (RTSP 8554). Sous la liste, la boîte de dialogue explique que les mots de passe enregistrés dans Cam Hub pour ces caméras seraient alors envoyés aux nouvelles adresses, et que les nouvelles adresses ne doivent être utilisées que si l’expéditeur est digne de confiance. Les boutons sont Utiliser les nouvelles adresses, Conserver les adresses actuelles et Annuler.

Comment une sauvegarde est chiffrée et protégée

Une sauvegarde est enregistrée chiffrée dans l’iCloud privé de l’utilisateur et n’est synchronisée qu’avec les appareils qui utilisent le même compte Apple. Une sauvegarde n’a pas de code PIN. La clé de chiffrement est intégrée à l’app et identique dans chaque installation : chacun de ses propres appareils peut donc restaurer sans mot de passe à retenir. La clé empêche seulement que la sauvegarde soit enregistrée en clair ; ce n’est pas un secret gardé vis-à-vis de quelqu’un qui obtiendrait à la fois la sauvegarde et l’app. La protection d’une sauvegarde repose sur la sécurité du compte Apple et d’iCloud ; le compte Apple doit donc être bien protégé.

Plusieurs sauvegardes nommées : renommer et supprimer

La liste Sauvegardes dans iCloud sous Ma sauvegarde affiche toutes les sauvegardes, de la plus récente à la plus ancienne. Une sauvegarde nommée affiche son nom, avec en dessous la date, l’heure et le contenu, par exemple 28 oct. 2026 à 21:41 · 3 enregistreurs · 2 caméras. Une sauvegarde sans nom affiche la date et l’heure, avec le contenu en dessous. La même liste, avec les mêmes actions, figure sur la page Restaurer depuis iCloud ; voir « Restaurer depuis iCloud ». La copie Apple TV n’a pas de nom et n’apparaît pas dans la liste.

Renommer une sauvegarde

  1. Sur la page Sauvegarde iCloud, avec Ma sauvegarde sélectionnée, balayez vers la gauche une sauvegarde de Sauvegardes dans iCloud.

    Vérification : Les boutons Renommer et Supprimer apparaissent à droite de la ligne. Un appui prolongé sur la ligne ouvre un menu avec les deux mêmes actions.

  2. Touchez Renommer.

    Vérification : La boîte de dialogue Renommer la sauvegarde apparaît, avec le champ Nom qui contient le nom actuel et les boutons Enregistrer et Annuler.

  3. Saisissez le nouveau nom et touchez Enregistrer.

    Vérification : La ligne affiche le nouveau nom. Si le champ est laissé vide, le nom est supprimé et la ligne affiche de nouveau la date et l’heure.

Supprimer une sauvegarde

  1. Balayez vers la gauche la sauvegarde à supprimer.

    Vérification : Les boutons Renommer et Supprimer apparaissent.

  2. Touchez Supprimer.

    Vérification : La boîte de dialogue Supprimer cette sauvegarde ? apparaît et précise que la sauvegarde est supprimée définitivement d’iCloud, que les autres appareils connectés la perdent à leur prochaine synchronisation, et que les appareils et les réglages de cet appareil ne sont pas affectés.

  3. Touchez Supprimer dans la boîte de dialogue.

    Vérification : La sauvegarde disparaît de la liste. Les autres sauvegardes, la copie Apple TV et les appareils de cet appareil restent inchangés.

  • Les espaces au début et à la fin d’un nom sont supprimées. Renommer ne change que le nom ; le contenu et la date de la sauvegarde restent les mêmes.
  • Les sauvegardes créées, renommées ou supprimées sur un autre appareil utilisant le même compte Apple apparaissent dans la liste une fois synchronisées par iCloud, y compris pendant que la page est ouverte.
  • Une sauvegarde créée avec une version antérieure de Cam Hub apparaît dans la liste comme l’une des sauvegardes.
  • Lorsqu’un nouveau nom ne peut pas être enregistré, l’alerte Impossible d’enregistrer la sauvegarde. Vérifiez que vous êtes connecté à iCloud. apparaît.
  • Pour supprimer toutes les sauvegardes en une fois, voir « Supprimer toutes les sauvegardes iCloud ».

Prérequis : cet appareil est connecté avec le compte Apple auquel appartiennent les sauvegardes, et une sauvegarde existe dans iCloud. Juste après une sauvegarde, sa synchronisation vers un autre appareil peut prendre un certain temps.

    Vérification : L’écran affiche la liste des réglages.

    Vérification : La page Restaurer depuis iCloud s’ouvre, avec Ma sauvegarde sélectionnée dans le sélecteur Source, la liste Choisir une sauvegarde et le bouton Restaurer. La sauvegarde la plus récente est marquée d’une coche. Si aucune sauvegarde n’est trouvée, la liste affiche Aucune sauvegarde trouvée dans iCloud. Sauvegardez d’abord depuis votre iPhone, connecté au même compte Apple. et le bouton Restaurer est indisponible.

  3. Touchez la sauvegarde à restaurer.

    Vérification : La coche se place sur cette sauvegarde.

  4. Touchez Restaurer.

    Vérification : Un indicateur de chargement apparaît à côté du bouton. Une fois la restauration terminée, la page affiche le texte vert 5 appareils restaurés.

  • Réglages de l’app : les réglages de la sauvegarde remplacent les réglages correspondants de cet appareil, y compris les pages LiveView Mix, Ouvrir au lancement et la langue. Les réglages absents de la sauvegarde restent inchangés. Avec la formule gratuite, l’état d’activation de la sauvegarde est conservé, et les canaux au-delà du quota gratuit affichent Non inclus dans votre formule et un cadenas jusqu’à ce que la formule soit restaurée ou qu’une formule soit souscrite. Pour les quotas, voir chapitre 11 : « Formules et limites ».
  • Le texte orange Certains mots de passe n’ont pas pu être enregistrés sur cet appareil. Ouvrez ces appareils et utilisez « Modifier les identifiants ». signifie que les mots de passe de certains appareils n’ont pas pu être enregistrés. Saisissez-les de nouveau comme décrit dans « Modifier le nom d’utilisateur et le mot de passe d’un appareil ».
  • Impossible de lire cette sauvegarde. Refaites une sauvegarde pour la remplacer. signifie que la sauvegarde est endommagée, ou qu’elle a été créée par une ancienne app avec un code PIN. Sauvegardez de nouveau sur l’appareil d’origine.
  • Aucune sauvegarde à restaurer. et La restauration a échoué. Veuillez réessayer. signifient qu’aucune sauvegarde lisible n’existe, ou que la restauration a échoué. Vérifiez que la connexion à iCloud et la synchronisation sont actives, puis réessayez.

Supprimer toutes les sauvegardes iCloud

Cette action supprime toutes les sauvegardes en une fois. Pour supprimer une seule sauvegarde, balayez-la dans la liste comme décrit dans « Plusieurs sauvegardes nommées : renommer et supprimer ».

  1. Touchez l’onglet Réglages, puis touchez Supprimer la sauvegarde iCloud dans la section Réinitialiser.

  2. Touchez Supprimer la sauvegarde iCloud dans la boîte de dialogue.

    Vérification : La boîte de dialogue se ferme et la ligne Supprimer la sauvegarde iCloud devient indisponible.

  • Les autres appareils connectés avec le même compte Apple perdent les sauvegardes à leur prochaine synchronisation. Les appareils et les réglages de cet appareil ne sont pas affectés.

Transférer les appareils et les murs vers un nouveau téléphone

Les pages LiveView Mix et leurs panneaux de commande font partie des réglages de l’app. Les deux méthodes ci-dessous les transmettent : une sauvegarde iCloud les inclut toujours, et un code de partage exige que Inclure les réglages de l’app soit activé et que Utiliser aussi ses réglages soit choisi sur le nouveau téléphone.

Méthode 1 : transfert par sauvegarde iCloud (recommandée)

Prérequis : Cam Hub est installé sur le nouveau téléphone, qui est connecté à iCloud avec le même compte Apple.

  1. Sur l’ancien téléphone, ouvrez l’onglet Réglages et touchez Sauvegarder sur iCloud.

    Vérification : La page Sauvegarde iCloud s’ouvre. Un nom saisi dans Nom (facultatif), par exemple Ancien iPhone, permet de reconnaître ensuite la sauvegarde dans la liste.

  2. Vérifiez que Destination est réglé sur Ma sauvegarde, puis touchez Sauvegarder maintenant.

    Vérification : La page affiche le message de réussite en vert, et la nouvelle sauvegarde apparaît en tête de Sauvegardes dans iCloud.

  3. Sur le nouveau téléphone, ouvrez Cam Hub, touchez l’onglet Réglages, puis touchez Restaurer depuis iCloud.

    Vérification : La page Restaurer depuis iCloud s’ouvre. Avec Source réglé sur Ma sauvegarde, la liste Choisir une sauvegarde affiche les sauvegardes, et la plus récente est sélectionnée. Si la sauvegarde de l’ancien téléphone n’est pas encore synchronisée, rouvrez la page un peu plus tard.

  4. Vérifiez que la sauvegarde de l’ancien téléphone porte la coche, puis touchez Restaurer.

    Vérification : La page affiche 5 appareils restaurés. L’onglet LiveView Mix affiche le mur de l’ancien téléphone.

  5. Sur le nouveau téléphone, touchez Restaurer les achats dans l’onglet Réglages.

    Vérification : Achats restaurés. apparaît. La formule ne fait pas partie de la sauvegarde et se récupère de cette façon ; voir « S’abonner, restaurer les achats et utiliser un code ».

Méthode 2 : transfert par code de partage

  1. Sur l’ancien téléphone, ouvrez l’onglet Réglages et touchez Exporter les caméras.

    Vérification : La page Exporter les caméras s’ouvre, avec tous les appareils cochés par défaut.

  2. Activez Inclure les réglages de l’app.

    Vérification : L’interrupteur est activé, et les pages LiveView Mix et les panneaux de commande voyagent avec le code.

  3. Facultatif : définissez un code PIN ou un mot de passe comme décrit dans « Verrouiller un code ».

    Vérification : Le bouton d’export devient disponible dès que la saisie est complète.

  4. Touchez le bouton d’export, puis touchez Partager et envoyez le lien vers le nouveau téléphone.

    Vérification : La feuille de partage du système a envoyé le lien. Envoyez le code PIN ou le mot de passe par un autre canal.

  5. Sur le nouveau téléphone, touchez le lien reçu, touchez Importer des caméras et, pour un code verrouillé, saisissez le code PIN ou le mot de passe.

    Vérification : La boîte de dialogue Ce code contient aussi les réglages de l’app de l’expéditeur apparaît.

  6. Touchez Utiliser aussi ses réglages.

    Vérification : L’écran affiche 5 caméras ajoutées. L’onglet LiveView Mix affiche le mur de l’ancien téléphone.

Aucune des deux méthodes ne transmet la formule. Après la connexion avec le même compte Apple, récupérez-la sur le nouveau téléphone avec Restaurer les achats ; voir « S’abonner, restaurer les achats et utiliser un code ».

Transférer la configuration vers Apple TV

Sur l’Apple TV, un mur peut seulement recevoir ses caméras, chacune en SD ou en HD, une disposition et des bandes noires (voir « L’onglet LiveView Mix ») ; l’organisation d’un mur, la modification de ses cases, le dessin d’une disposition personnalisée et la création de panneaux de commande se font sur un iPhone ou un iPad, et la saisie d’un long code à la télécommande est laborieuse. La méthode recommandée consiste à terminer d’abord la configuration sur un iPhone ou un iPad. Une sauvegarde réalisée avec Apple TV comme destination (voir « Sauvegarder sur iCloud ») ou un code de partage (voir « Exporter des caméras (créer un code) ») transfère ensuite les appareils et le mur vers le téléviseur. Apple TV ne restaure que la copie Apple TV, pas les sauvegardes de Ma sauvegarde, et n’affiche les diffusions YouTube et Twitch que par leur nom. Pour les étapes sur l’Apple TV et ce qui y diffère, voir chapitre 14 : « Apple TV ».
