1Quick start

This chapter describes the shortest path from opening Cam Hub to the first live picture. Without a device at hand, the sample cameras can be used to try the app.

Before you begin

ItemDescription
NetworkCam Hub connects directly to the network address of the device and does not use a cloud service of the manufacturer. The iPhone or iPad must be on the same local network as the device, or must be able to reach its address.
IP address of the deviceThe address is listed in the connection list of the router or in the manufacturer's own app. It can also be found with the network scan; see “Finding devices with the network scan”.
Account of the deviceUsually the administrator account that was created when the device was first set up. On the device, the account needs the permissions for the functions to be used, for example live view, recording playback and PTZ control.
Local Network permissionOn first use, the system asks whether Cam Hub may find and connect to devices on the local network. Without this permission, Cam Hub cannot connect to devices. The permission can be turned on later under Settings › Privacy & Security › Local Network › Cam Hub.

Shortest path to a live picture

  1. Tap the Devices tab at the bottom of the screen.

    Check: The screen shows the device list. When no device has been added yet, it shows No Devices.

  2. Tap the ＋ button in the top-right corner.

    Check: A menu opens that contains Add Device.

  3. Select Add Device.

    Check: The screen shows the add-device form.

  4. Enter the address of the device in the IP address or hostname field.

    Check: The Add button in the top-right corner is available.

  5. Enter the account of the device in the Username and Password fields.

    Check: The Username field holds the typed name instead of the preset admin. The ports and Connect using stay folded under Advanced; with Auto-detect, no change is needed there.

  6. Tap Add in the top-right corner.

    Check: The form shows Connecting to device… with the step in progress, for example Looking for open ports…. When the connection succeeds, the form closes and the new device appears in the device list. For a network storage device that can report the health of its disks, the optional SNMP Settings sheet opens first; Not Now closes it, and it can be set up later, see “Disk Health”.

  7. Tap the newly added device in the device list.

    Check: The device page shows the device information and a thumbnail for each channel.

  8. Tap the thumbnail of a channel that is enabled.

    Check: The screen shows the live picture of that camera.

If the connection fails, see “When adding fails: the checklist”. If a thumbnail does not open, see Chapter 4, “The Devices tab and channels” and Chapter 11, “Plans and limits”. To watch several cameras at once, see Chapter 8, “LiveView Mix”. Where they are offered, the menu of step 2 also adds a YouTube live stream or Twitch channels as cameras; see “Adding YouTube live streams and Twitch channels”.

Trying the app without a device

At the bottom of the add-device form, Add Demo Cameras creates two sample cameras that draw their own picture. No device and no sign-in are needed, so they can be used to try live view and LiveView Mix. The sample cameras have no recording playback. The button is not shown when the form was opened from a scan result that already identified the device.

Delete the sample device before connecting real equipment

The sample device counts as a recorder. It uses up the recorder allowance and the enabled-channel allowance of the free plan. For deleting a device, see Chapter 4, “The Devices tab and channels”; for the allowances, see Chapter 11, “Plans and limits”.
