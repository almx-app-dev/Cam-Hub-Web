14Apple TV

The Apple TV app shows the devices and the LiveView Mix wall that were set up on an iPhone or an iPad, and it plays live video and recordings with the remote. The recommended order is to finish the whole setup on an iPhone or iPad first and to bring it to the Apple TV afterwards. This chapter gives the steps for that, describes the four tabs of the Apple TV app and lists what differs from the iPhone and iPad.

Set up on an iPhone or iPad first

The Apple TV is operated with a remote. Typing, drawing and choosing are laborious there, and several functions are not offered at all. These tasks are therefore done on an iPhone or an iPad before the Apple TV is used:

  • Adding the devices; see Chapter 3, “Adding a device”.
  • Building the LiveView Mix wall, with a custom layout and control panels where wanted; see Chapter 8, “LiveView Mix” and Chapter 9, “Control panels and webhooks”.
  • Choosing the plans and the cameras that show; see Chapter 11, “Plans and limits”.

Bringing the setup to the Apple TV

Prerequisites: the iPhone or iPad and the Apple TV are signed in to iCloud with the same Apple Account, and both run the same version of Cam Hub. A backup that an older version made does not appear on the Apple TV.

  1. On the iPhone or iPad, finish the setup: the devices, the LiveView Mix wall, the plans and the choice of cameras that show.

    Check: The devices and the wall appear on the iPhone or iPad the way they are to appear on the television.

  2. On the iPhone or iPad, back up to iCloud with Apple TV as the destination; see “Backing up to iCloud”.

    Check: The backup page shows the message that the backup was made, and Current Backup shows the time and the number of devices. A new backup to Apple TV replaces the previous Apple TV copy.

  3. On the Apple TV, open the Settings tab and select Restore from iCloud in the iCloud Backup section.

    Check: The page shows the time of the backup in From and its contents in Devices. When the section shows No backup found in iCloud yet instead of the row, see “Sharing, import and iCloud backup”.

  4. Select Restore. What a restore changes is described in “Restoring from iCloud”.

    Check: The page shows how many devices were restored. The Devices tab of the Apple TV lists them, and the LiveView Mix tab shows the wall.

  5. On the Apple TV, select Plans in the Settings tab.

    Check: The page shows the plan of the Apple Account. A plan that is not shown yet appears after Restore Purchases.

The Apple TV restores only the copy that was backed up for it. The named backups kept under My Backup are listed only on the iPhone and the iPad; see “Several named backups: renaming and deleting”.

Later changes reach the Apple TV only with a new backup

After devices, the wall or the plans have been changed on the iPhone or iPad, repeat steps 2 to 4. The Apple TV does not follow changes by itself. A changed password of a device can also be entered on the Apple TV with Edit Credentials on the device page; see “The Devices tab and the device page”.

With a sharing code

When the two devices do not share an Apple Account, a sharing code replaces the backup. A code can be hundreds to thousands of characters long, so an iCloud backup is preferable whenever the Apple Account is the same. Create the code on the iPhone or iPad as described in “Exporting cameras (creating a code)”, then continue on the Apple TV.

  1. Open the Settings tab.

    Check: The settings list starts with the iCloud Backup section.

  2. In the Share Cameras section, select Import Cameras.

    Check: The Import Cameras page shows a field below Enter the code and the button Import Cameras.

  3. Select the field and enter the code.

    Check: The code appears in the field. While the keyboard is shown, a nearby iPhone can type the code. A locked code shows a note below the field: Locked with a 6-digit PIN — you'll be asked for it. or Locked with a password — you'll be asked for it.

  4. Select Import Cameras.

    Check: A locked code opens Enter PIN or Enter Password. An open code is imported, and the alert Added 3 cameras appears. One of the questions described below can come first.

  5. For a locked code, enter the PIN or the password.

    Check: The field of the dialog shows the entry; a password appears as dots.

  6. Select Import.

    Check: The dialog closes, and the import continues as for an open code. A PIN or a password that does not unlock the code shows Wrong PIN or Wrong password.

  7. In the alert Added 3 cameras, select Done.

    Check: The settings list appears again, and the Devices tab lists the added devices.

Before the cameras are added, the same questions as on an iPhone or iPad can appear:

  • This code changes camera addresses, when the code would move cameras that already exist on this Apple TV to other addresses. The dialog lists those cameras with the current and the new address. Use New Addresses sends the passwords saved for those cameras to the new addresses and suits only a code from a trusted sender, Keep Current Addresses keeps their addresses, and Cancel imports nothing; see “When a code changes camera addresses”.
  • This code also has the sender's app settings, when the code carries app settings. Add Cameras Only keeps the settings of the Apple TV, and Also Use Their Settings replaces them, including the LiveView Mix wall and the language; see “Importing cameras”.

When the code cannot be read, the alert Couldn't read that code asks to make sure that the whole code from a Cam Hub export was entered.

The Live tab

The Apple TV app has four tabs at the top of the screen: LiveView Mix, Live, Devices and Settings. The Live tab shows the enabled cameras of one device at a time as a wall, with the name of the device at the top right.

  • Choosing the device: with more than one device, a row of buttons below the title holds one button per device; its symbol marks a recorder or a camera. Select a button to show the cameras of that device. The selected button is filled in cyan, and the choice is kept when the app is opened again. With a single device, the row is not shown.
  • The wall: one camera fills the area, two to four cameras are shown two per row, and five or more three per row. Three rows fit on the screen; further rows come into view as the selection moves down. Each tile shows the number and the name of the camera at the bottom left.
  • Quality and black bars: the wall uses Multiple cameras and Black bars of the Settings tab; see “The Settings tab”. The tab has no button of its own for either.
  • Opening a camera: move the selection onto a tile and press Select. The camera opens in the single-camera view at the quality of Single camera; see “The single-camera view, playback and events”. A cyan frame marks the selected tile; it fades when the selection has not moved for about 5 seconds and returns when the selection moves again. A tile that is offline, paused or not in the plan cannot be selected. A pause is set and lifted on an iPhone or iPad; see “Channel options (long press)”.
  • Cameras without a signal: while Hide offline cameras is on, they are left out of the wall; see “The Settings tab”.

Without devices, the tab shows No Devices with Add a camera or recorder in the Devices tab. A device without enabled cameras shows No Enabled Cameras with Enable cameras for this device on your iPhone or iPad. On the Apple TV itself, cameras are switched on in Settings › Choose which cameras to show while that row is offered; see “The Settings tab”.

The LiveView Mix tab

The app opens on the LiveView Mix tab. It shows the landscape page of the wall. A portrait page or a lower canvas that arrives with a backup is kept but not shown, and its control panels use no allowance.

The preview on the tab

Below the title, the button Full screen opens the wall. Under it, the cameras of the wall appear as a plain grid, not in the layout of the wall: one camera fills the area, two to four are shown two per row, and five or more three per row. The grid uses the black bars and the watermark of the wall. Select a tile to open that camera in the single-camera view; a camera opened from LiveView Mix always starts in HD. Control panels, clocks, labels and pictures do not appear in the preview. While Hide offline cameras is on, cameras without a signal are left out of the grid.

When the wall holds no camera that this Apple TV has, for example only control panels, the tab shows Open full screen with Your LiveView Mix panels appear on the full-screen wall. instead of the grid. When no wall is set up, the tab shows LiveView Mix is empty.

The full-screen wall

  1. Select Full screen.

    Check: The wall fills the screen in its layout, and a cyan frame marks the selected camera or button. The wall opens on the first page that has something to show.

  2. Move the selection with the remote.

    Check: The frame moves to the next camera or control-panel button. Left or right at the edge of the wall turns to the previous or the next page. The frame fades when the selection has not moved for about 5 seconds and returns when the selection moves again.

  3. Press Select.

    Check: On a camera, the single-camera view opens in HD; Menu returns to the wall. On a control-panel button, the button sends its request.

  4. Press Menu.

    Check: The wall closes, and the tab shows the preview again.

Each button of a control panel is a selection of its own, and the selection skips a panel that is not in the plan. A button with Confirm before firing first opens a dialog titled with the name of the panel, or Run this action? for a panel without a name, offering the label of the button (or Confirm) and Cancel. Control panels appear and can be pressed on the full-screen wall only, not in the preview, and they cannot be edited on the Apple TV. A watermark set on the iPhone or iPad is shown on the tiles. When the wall holds only cameras that are not on this Apple TV, the wall shows These cameras aren't set up here. A full-screen wall that was open is shown again after the app restarts.

Editing the wall on the Apple TV

The page Settings › LiveView Mix edits the landscape page of the wall on the Apple TV itself. The row shows the number of cameras of the wall, or Off while no wall is set up.

  1. In the Settings tab, select LiveView Mix.

    Check: The LiveView Mix page opens. The Full-screen layout section shows a row of ready-made layouts and the picker Black bars on this wall. Further down, the note Press a camera to add it at SD. Press again for HD, and once more to remove it. is followed by the cameras of every device, one section per device.

  2. Select a camera.

    Check: The row shows a check mark and SD: the camera is on the wall in SD. A section above the cameras counts the cameras of the wall, for example Selected — 3 cameras, and offers All SD and All HD.

  3. Select the same camera again.

    Check: The row shows HD: the camera is on the wall in HD. A third press removes the camera from the wall.

  4. In the row of layouts, select a layout.

    Check: The layout is highlighted, and the full-screen wall uses it.

The row offers every ready-made layout, including those with more than 16 tiles, which the iPhone and iPad no longer offer for a new wall. A custom layout cannot be drawn with the remote: once one has been drawn on an iPhone or iPad, it appears at the end of the row and can be chosen, and the text below the section says so. Black bars on this wall sets the black bars of this wall only. All SD and All HD set every camera of the wall at once. Arranging the order, editing slots, adding clocks, labels, pictures or control panels, the watermark and Keep cameras connected between pages are not offered on the Apple TV. A note at the end of the page recommends setting everything up on the iPhone or iPad and bringing it over with a backup. Without devices, the page shows No Devices with Add a device first, then choose its cameras here.

The Devices tab and the device page

The Devices tab starts with Add IP Device. Below, the Devices section lists one row per device with its name, its model and its address. At the right, a row shows the connection indicator, the green or red Wi-Fi symbol described in “The device list”, or instead Demo for a sample device and iPhone or iPad only for a YouTube or Twitch stream. Not in your plan is added when the plan holds back cameras of the device.

Without devices, the section Set up on iPhone, iPad, or Mac — then restore here explains that the cameras and the wall are best set up on one of those devices and restored on the Apple TV from an iCloud backup, and that one subscription covers every device signed in to the same Apple Account. Add IP Device remains available above it. A device is deleted on its device page; the list has no other way to delete it.

Adding a device

Add IP Device opens the Add Device page. The form is shorter than on an iPhone or iPad: there is no network scan, no list of brands, no checklist and no device report.

The device page

Select a device in the list to open its page. The name of the device appears at the top right, above a row of buttons:

  • Back returns to the list.
  • Show details or Hide details shows or hides the details: Model, IP address (Link for a YouTube or Twitch stream), Type (Recorder or Camera), Serial number and Firmware where the device reports them, Cameras with the number of cameras, and HTTPS with the port while HTTPS is on.
  • Rename opens Rename Device, with the field Name and Save.
  • Edit Credentials, for a device with a sign-in of its own, stores a new username and password; see “Changing the user name and password of a device”. A device without a saved password shows No password saved. Enter it again under Devices. on its tiles; on the Apple TV, the password is entered here.
  • HTTPS, offered when the device serves HTTPS or HTTPS is on already, opens the HTTPS settings of the device; see “HTTPS for a saved device”.

Below the buttons, the enabled cameras form a wall that uses Multiple cameras and Black bars of the Settings tab. Select a tile to open the camera at the quality of Single camera. While Hide offline cameras is on, cameras without a signal are left out of this wall as well; only the number under Cameras still counts them. Without enabled cameras, the page shows No Enabled Cameras with In Settings, choose which cameras to show. There is no menu for a camera, no full-screen wall and no Disk Health.

Delete Device, below the wall, asks Delete this device? The message names the device and the number of its cameras that are removed, together with the saved password where there is one, and states that this cannot be undone. Select Delete to remove the device, or Cancel.

The single-camera view, playback and events

A camera opened from a wall fills the whole screen. A camera opened from the Live tab or a device page starts at the quality of Single camera; a camera opened from LiveView Mix starts in HD. A badge at the top left shows LIVE, or the time of the recording that plays. The buttons sit at the top right:

ButtonShownAction
EventsWhen the device offers events; see below.Opens the list of events of the chosen day.
SD or HDIn live view.Shows the current quality and switches between SD and HD.
Mute or UnmuteWhen the stream carries sound.Turns the sound off or on. The choice applies to every camera.

Apart from SD or HD, each button shows only a symbol; its name appears beside the symbol while the button has the selection. After about 5 seconds without a press, the buttons and the timeline hide; a swipe on the remote shows them again. Menu closes the view. While the picture connects, Connecting… or Reconnecting… appears; when the stream fails, the reason appears with Retry. A camera beyond the plan shows Not in your plan with the button Choose which cameras to show, which opens the License page; see “The Settings tab”. There is no snapshot, no clip recording, no talk, no PTZ and no zoom.

Playing a recording

For a device that supports playback, a timeline runs along the bottom of the picture. Blue bars mark continuous recordings and red bars event recordings. The day appears at the top left of the timeline, and the time under the fixed center line at the top in the middle. The timeline shows 4 hours at first.

  1. Move the selection down to the timeline.

    Check: The timeline is outlined in cyan, and a row of buttons appears above it: Previous day, Next day, Zoom out, Zoom in and Play. Each button shows a symbol, and its name appears while it has the selection.

  2. Press left or right on the remote.

    Check: The time under the center line moves by one twentieth of the visible span and stays within the chosen day. Nothing plays yet.

  3. Select Play.

    Check: The recording plays from the time under the center line. The badge at the top left shows the time of the recording instead of LIVE, and the button Live appears in the row.

  4. Select Live.

    Check: The live picture returns.

Previous day and Next day change the day; Next day is unavailable on the current day of the device. Zoom out and Zoom in change the visible span between 10 minutes and 24 hours. The row of buttons is shown only while the selection is on the timeline or on one of these buttons. When no recording follows, End of recording appears. A recording that has to be downloaded as a file before it plays is not played on the Apple TV; the screen shows Watch this recording on your iPhone or iPad. The Apple TV has no calendar and plays recordings at normal speed only.

Events

Where the device keeps an event index or has event recordings on the timeline, the button Events opens the list of events. The day appears at the top between two arrows that change it; the right arrow is unavailable on the current day of the device. Each row names the kind of event, Person detected, Motion detected, Alarm input or Event recording, with its time. The list runs oldest first and also holds the events of the day before, shown without their date. A day without events shows No events on this day., or No people detected on this day. for a device that searches for people. The list on the iPhone and iPad is described in “The list of recordings and events”.

  1. Select Events.

    Check: The Events page opens with the events of the chosen day.

  2. Select an event.

    Check: The list closes, and the recording plays from 5 seconds before the event, but not from before the start of its recording. Menu closes the list without playing.

Changing the language

  1. In the Language section, select a language.

    Check: A dialog titled with the name of the language, written in that language, offers Switch and Cancel.

  2. Select Switch.

    Check: The app switches to the language at once, and the screen stays on the Settings tab.

Reset

Restore Default Settings asks Restore all settings to defaults? and Delete All Data asks Delete all data?. Both dialogs and their effects are the same as on an iPhone or iPad, confirmed with Restore Defaults and Delete Everything; see “Reset: defaults, delete all data, delete iCloud backup”. Restore Default Settings therefore also clears the LiveView Mix wall of the Apple TV. Delete iCloud Backup asks Delete iCloud backup? and removes only the Apple TV copy of the backup; the named backups of My Backup stay, and so do the devices and settings of the Apple TV. The row is unavailable while no Apple TV copy exists.

Hide offline cameras

While Hide offline cameras is on, cameras without a signal are left out of the walls of the Live tab and of the device pages, and out of the preview of the LiveView Mix tab. Only the full-screen LiveView Mix wall keeps their places. This differs from the iPhone and iPad, where the device page keeps them; see “Hiding cameras without signal”. When no camera of a wall remains, the wall stays empty. Turning the switch on or off checks all cameras again.

Plans

The Plans page shows, in the Subscriptions section, the row Current plan and every camera plan and NVR plan with what it unlocks; the current plan has a check mark. Select a plan to subscribe with the Apple Account; a plan can be selected once the App Store has answered. Until then, a row at the end of the section shows that the App Store has not answered yet; when it cannot be reached, that row offers to try again. The text below the section states that the two allowances are counted separately and that the subscription follows the Apple Account. The Legal section follows, and Restore Purchases is at the end of the page.

A purchase that does not complete is reported in an alert that OK closes: Purchase failed. Please try again., Waiting for approval. The plan unlocks as soon as the purchase is approved. for a purchase that awaits approval, or The App Store could not confirm this purchase. Try Restore Purchases. There is no Manage Subscription and no Redeem Code; both are on the iPhone and iPad, see “Subscription”. One subscription covers every device that uses the same Apple Account.

Choosing the cameras that show

Choose which cameras to show opens the License page. The Your plan section shows the allowances under Cameras and Recorders; the allowances themselves are described in “The allowance of each plan”. Each device follows as a section with one switch per camera.

  1. Select the switch of a camera.

    Check: The switch turns on, and the camera appears on the walls. When the plan does not allow it, the switch stays off and an alert states the reason.

  2. When an alert appears, select OK.

    Check: The alert closes. Unlike on an iPhone or iPad, the plans screen does not open; see “Choosing which cameras show”.

A switch can always be turned off. Without devices, the page shows No Devices with Add a device first, then choose its cameras here.

Not in the Settings tab of the Apple TV

The Apple TV has no Open on launch, no Edge-to-edge video, no export of a code and no creation of a backup. It also has no User Manual and no Contact the Development Team: the tab ends with About › Version. To write to the development team, use an iPhone or an iPad; see “Contacting the development team”.

OperationTouch, with gestures such as pinch, drag and long press.Remote. The selection moves with the directional pad or by swiping, Select acts like a tap and Menu goes back. There are no touch gestures.
Live tabThe list button, SD or HD for the wall, the black-bar button and the Full Screen Wall; see “The Live tab”.A row of buttons, one per device. The wall follows Multiple cameras and Black bars of the Settings tab; there is no button for the quality or the black bars and no Full Screen Wall. See “The Live tab”.
Adding devicesA form that finds the connection method and the ports by itself, with both under Advanced; the network scan, the checklist, the device report, and separate forms for YouTube live streams and Twitch channels.A short form with two switches in place of the list of methods. There is no scan, no list of brands, no checklist and no device report, and a YouTube or Twitch link is refused. See “The Devices tab and the device page”.
Device pageRename, Edit Credentials, HTTPS where the device serves it, Disk Health where the device reports it, and a menu for each camera: rename, enable or disable, pause. A device is deleted from the list.Buttons for the details, Rename, Edit Credentials and, where offered, HTTPS, then the wall and Delete Device. There is no menu for a camera and no Disk Health. Cameras are switched on and off in Settings › Choose which cameras to show. See “The Devices tab and the device page”.
Live view and single cameraSD and HD, sound, snapshot, clip recording, two-way talk, PTZ, pinch zoom, landscape view.SD and HD, sound, and a choice between fitting the picture and filling the screen. There is no snapshot, no clip recording, no talk, no PTZ and no zoom. See “The single-camera view, playback and events”.
YouTube and TwitchPlayed by the services' own players in tiles, on the camera page and full screen.Shown by name only, with YouTube live streams play only on iPhone and iPad. or Twitch streams play only on iPhone and iPad.; the device list marks them iPhone or iPad only. They never play on the Apple TV; see “YouTube and Twitch”.
Recording playbackA calendar that marks the days with recordings, a timeline that is dragged, speeds of 2×, 4× and 8×, a list of events.A timeline moved with the remote, played with Play, and the list behind Events where the device offers it. There is no calendar and no faster speed, and a recording that has to be downloaded first is not played. See “The single-camera view, playback and events”.
LiveView MixChoosing cameras, arranging, drawing layouts, editing slots, watermark, keeping cameras connected, a portrait page and, on iPhone Duo, two canvases.Only the landscape wall is shown. The tab shows the cameras as a plain grid, not in the layout of the wall; control panels appear and can be pressed on the full-screen wall only, and they cannot be edited. The editor in Settings › LiveView Mix offers the cameras with SD or HD, every ready-made layout and black bars; a custom layout drawn on an iPhone or iPad can be chosen but not edited. Arranging, slot editing, setting the watermark and keeping cameras connected are not offered. See “The LiveView Mix tab”.
Backup and sharingCreating named backups, restoring, exporting a code, importing a code.Restoring the Apple TV copy of a backup and importing a typed code. A backup or a code cannot be created. Delete iCloud Backup removes only the Apple TV copy.
PlansPlans, Manage Subscription, Restore Purchases and Redeem Code.Plans and Restore Purchases. There is no Manage Subscription and no Redeem Code. A camera beyond the allowance is refused with an alert instead of the plans screen. See “The Settings tab”.
Legal pagesTerms of Use and Privacy Policy in the Settings tab open the Cam Hub website.Terms of Use (EULA) and Privacy Policy, in the Legal section of the Settings tab and on the Plans page, show the full text inside the app, with the web address at the top. The text ships with the app, so no connection is needed. Done returns.
HelpUser Manual and Contact the Development Team at the end of the Settings tab; see “Contacting the development team”.Neither row. The Settings tab ends with About › Version. Write to the development team from an iPhone or an iPad; see “Reaching the developer”.
PermissionsLocal Network; Camera for Take Photo; Microphone for talking through a camera; adding to the photo library when a snapshot or clip is saved; Location for the Speedometer.Local Network only; see “Permission requests and system dialogs”.

The sections of the Settings tab of the Apple TV are described in “The Settings tab”. Problems with a backup that does not appear on the Apple TV are covered in “Sharing, import and iCloud backup”.
