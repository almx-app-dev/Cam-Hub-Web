12도구 탭

도구 탭에는 기기를 찾는 네트워크 검색, 나침반이 있는 속도계, 데모 기기를 추가하는 섹션이 있습니다. 네트워크 검색의 절차는 기기 추가 장에서 단계별로 설명하며, 이 장에서는 탭의 개요와 속도계를 설명합니다.

도구 탭의 구성

경로: 화면 아래의 도구 탭. 이 탭은 하나의 목록이며 섹션이 아래 순서대로 이어집니다.

섹션내용자세한 내용
서브넷iPhone 또는 iPad 자체의 주소가 표시되는 이 기기 행, 범위의 주소 입력란, 범위 선택기, 검색 대상을 알려 주는 줄, 내 서브넷 사용 버튼(범위가 내 네트워크와 다를 때만 표시), 검색 또는 정지 버튼.‘네트워크 검색으로 기기 찾기’
찾은 기기검색 진행 상황, 응답한 주소와 열린 포트, 그리고 검색이 끝난 뒤 기기가 스스로 알려 주는 정보(이름 또는 모델, 녹화기는 채널 수). 결과를 탭하면 주소와 기기가 알려 준 정보가 입력된 기기 추가 양식이 열립니다.‘네트워크 검색으로 기기 찾기’
속도계나침반이 있는 속도계를 여는 속도계 행. 이 섹션은 기기의 지역 및 언어 설정에 따라 제공됩니다.‘속도계와 나침반’
데모데모 기기를 추가하는 데모 환경 추가(심사용) 버튼.이 페이지 아래쪽 참조.

  1. 화면 아래의 도구 탭을 선택합니다.

    확인: 서브넷으로 시작하는 탭의 섹션들이 표시됩니다. 주소 입력란과 범위에는 이미 기기의 네트워크가 입력되어 있습니다.

검색 절차는 ‘네트워크 검색으로 기기 찾기’ 참조. 다음은 탭 전체의 동작에 관한 내용입니다.

  • 저장된 범위: 주소와 범위는 저장됩니다. 기기가 다른 네트워크에 접속하면 범위를 직접 입력한 경우를 제외하고 두 입력란이 새 네트워크에 맞게 다시 채워집니다. 직접 입력한 범위는 유지됩니다. 내 서브넷 사용 버튼은 선택을 다시 앱에 맡깁니다. 기본 설정 복원은 저장된 범위를 지웁니다. 자세한 내용은 ‘초기화: 기본 설정, 모든 데이터 삭제, iCloud 백업 삭제’ 참조.
  • 검색하는 동안: 주소 입력란과 범위는 변경할 수 없습니다. 정지는 검색을 끝냅니다. 화면을 나가도 실행 중인 검색이 끝납니다.
  • 로그인 없음: 검색은 포트에 연결할 수 있는지만 확인하고 기기가 웹 포트에서 알리는 이름을 읽습니다. 검색이 끝나면 앱이 로컬 네트워크의 탐색 서비스를 통해 찾은 기기에 이름을 묻는 동안 목록에 기기 식별 중…이 표시됩니다. 어떤 기기에도 로그인하지 않습니다. 기기는 기기 추가 양식에 인증 정보를 입력한 뒤에야 추가됩니다.
  • 식별된 기기: 브랜드를 알려 준 기기의 결과를 열고 주소를 바꾸지 않았으면, 기기 추가 양식에 호환성 참고와 데모 카메라 추가가 표시되지 않습니다. 이 둘은 알 수 없는 기기에만 도움이 되기 때문입니다.
  • 로컬 네트워크 접근: 첫 검색에서 시스템이 Cam Hub의 로컬 네트워크 기기 검색을 허용할지 물을 수 있습니다. 접근이 거부되면 검색은 아무것도 찾지 못합니다. 결과 없이 검색이 끝나면 목록에 카메라가 이 네트워크에 있다면, 개인정보 보호 설정에서 Cam Hub의 로컬 네트워크 기기 검색 권한이 켜져 있는지 확인해 보세요. 문장이 추가됩니다. 자세한 내용은 ‘네트워크 검색으로 기기 찾기’ 및 ‘권한 요청과 시스템 대화상자’ 참조.

데모 기기 추가

데모 섹션은 탭의 맨 끝에 있습니다. 이 섹션의 문구는 이 기기들이 앱 심사용이며 일상적인 사용에는 필요하지 않다고 설명합니다. 장비가 없어도 누구나 앱을 체험하는 데 사용할 수 있습니다. 데모 기기는 자체적으로 영상을 생성하며 네트워크도 로그인도 필요하지 않습니다.

  1. 도구 탭 맨 끝까지 스크롤하여 데모 환경 추가(심사용)을 탭합니다.

    확인: 앱이 녹화기 5대와 카메라 2대를 추가합니다. 녹화기마다 채널이 3개입니다. 녹화기의 이름은 Demo NVR 1부터 Demo NVR 5까지이고, 카메라의 이름은 Demo Camera 1과 Demo Camera 2입니다.

  2. 기기 탭을 선택합니다.

    확인: 목록에 데모 기기가 표시됩니다. 현재 요금제가 허용하는 범위에서만 채널이 활성화되며 나머지 채널에는 비활성화됨이 표시됩니다. 자세한 내용은 ‘요금제 한도와 채널 활성화’ 참조.

  • 한 번만 추가됨: 탭하면 버튼이 흐리게 표시됩니다. 데모 기기가 이미 있으면 이 버튼은 아무것도 추가하지 않습니다.
  • 실제 기기와 똑같이 계산됨: 데모 녹화기는 요금제가 허용하는 녹화기 수에 포함되며, 활성화된 데모 채널은 요금제의 자리를 사용합니다. 무료 버전에서 실제 녹화기를 추가하기 전에 데모 기기를 삭제합니다. 자세한 내용은 ‘기기 목록’ 참조.
  • 요금제를 따름: 앱은 시작할 때와 요금제가 바뀔 때마다 데모 채널의 활성화 상태를 다시 설정하여 항상 요금제가 허용하는 상태를 표시합니다. 데모 채널의 스위치를 직접 바꾼 내용은 유지되지 않습니다.
  • 제한된 기능: 데모 기기에는 녹화 재생, 카메라 제어, 스냅샷이 없으며 기기 페이지에서 채널 목록을 새로 고칠 수도 없습니다.

속도계와 나침반

속도계는 기기의 속도와 기기가 이동하거나 향하는 방향을 보여 줍니다. 위치는 위성 위치 측정에서 가져옵니다. 도구 탭에 속도계가 제공되는지는 기기의 지역과 언어 설정에 따라 다릅니다. 제공되지 않으면 도구 탭에는 다른 섹션만 표시됩니다.

속도계 열기와 위치 접근 허용

사전 조건: iPhone 또는 iPad에서 하늘이 잘 보여야 합니다. 실내에서는 위치가 지연되거나 잡히지 않을 수 있습니다.

  1. 도구 탭을 선택하고 속도계 섹션까지 스크롤한 다음 속도계 행을 탭합니다.

    확인: 속도계 화면이 열립니다. Cam Hub가 위치를 사용하도록 허용된 적이 없으면 시스템 대화상자가 권한을 요청합니다.

  2. 앱을 사용하는 동안 허용을 탭합니다.

    확인: 첫 위치를 받을 때까지 화면에 GPS를 기다리는 중… 문구가 표시되며, 위치를 받으면 이 문구가 사라집니다.

  3. 기기를 가지고 이동합니다(예: 차량으로).

    확인: 큰 숫자가 속도를 표시하고 나침반 다이얼이 방향에 따라 회전합니다.

화면 읽는 방법

요소의미
큰 숫자km/h 단위의 속도이며 정수로 반올림됩니다. 첫 측정 전에는 — 기호가 표시됩니다. 정지한 기기는 0을 표시합니다.
km/h와 mph 줄같은 속도를 두 단위로 표시합니다. 두 단위가 항상 표시되며 단위를 바꾸는 설정은 없습니다. 첫 측정 전에는 이 줄에 0 mph라고 표시됩니다.
나침반 다이얼다이얼은 위쪽의 고정된 지시침 아래에서 회전합니다. 기기가 이동하거나 향하는 방향이 지시침 아래의 방향입니다. 링에는 5도마다 눈금이 있고 북, 동, 남, 서 글자가 있습니다.
다이얼 가운데의 텍스트방향의 이름(북, 북동, 동, 남동, 남, 남서, 서 또는 북서)과 북쪽에서 시계 방향으로 센 방위각(도)입니다. 방위각을 알 수 있을 때까지 이 텍스트에는 – 기호가 표시됩니다.

방위각은 두 가지 출처에서 가져옵니다. 기기가 시속 8 km/h 이상으로 이동하는 동안에는 위성 위치 측정으로 구한 이동 방향입니다. 그보다 느린 속도에서는 기기 나침반의 방위각입니다. 나침반 값이 없으면 마지막 이동 방향이 표시됩니다.

나침반 아래의 메시지

메시지의미와 조치
GPS를 기다리는 중…(회색)아직 위치를 받지 못했습니다. 몇 초 기다리거나 하늘이 잘 보이는 곳으로 이동합니다.
GPS 위치를 가져올 수 없습니다.(주황색)위치를 확인할 수 없습니다. 위치를 받으면 메시지가 바로 사라집니다. 메시지가 계속 남아 있으면 하늘이 잘 보이는 곳으로 이동하거나 화면을 나갔다가 다시 엽니다.
위치 접근이 꺼져 있습니다. 속도와 방위를 보려면 설정에서 켜세요.(주황색), 설정 열기 버튼 포함Cam Hub가 위치를 사용하도록 허용되어 있지 않습니다. 아래 설명대로 허용합니다.
메시지 없음위치를 알고 있습니다. 속도와 방위각이 최신 상태입니다.

나중에 위치 접근 허용

  1. 주황색 메시지 아래의 설정 열기를 탭합니다.

    확인: Cam Hub의 시스템 설정이 열립니다.

  2. 위치를 탭하고 앱을 사용하는 동안을 선택합니다.

    확인: 위치 항목에 앱을 사용하는 동안이 표시됩니다.

  3. Cam Hub로 돌아가 속도계의 뒤로 버튼을 탭한 다음 속도계 행을 다시 엽니다.

    확인: 화면에 GPS를 기다리는 중… 문구가 표시된 뒤 속도와 방위각이 표시됩니다.

속도 음성 안내

화면 아래의 속도 음성 안내 스위치는 기본적으로 켜져 있습니다. 스위치의 설명은 150km/h부터 450km/h까지 10km/h마다 속도를 음성으로 알려 줍니다.입니다.

  1. 속도 음성 안내 행을 탭합니다.

    확인: 스위치가 꺼집니다. 속도가 안내되지 않습니다. 이 선택은 저장됩니다.

  2. 속도 음성 안내 행을 다시 탭합니다.

    확인: 스위치가 켜집니다. 이제부터 음성이 속도를 안내합니다.

  • 안내하는 내용: 단위 없이 km/h 기준의 숫자만 말합니다. 속도가 150부터 450까지 다음 10의 배수를 지날 때마다 음성이 한 번 말합니다. 150 미만이거나 속도가 떨어지는 동안에는 아무것도 말하지 않습니다.
  • 반복 없음: 속도가 어떤 숫자 주변에서 약간씩 오르내리는 동안에는 그 숫자를 반복하지 않습니다. 속도가 그 숫자보다 확실히 떨어졌다가 다시 올라간 뒤에만 다시 말합니다.
  • 빠른 속도에서 켤 때: 높은 속도에서 음성을 켜면 이미 지난 숫자는 안내하지 않습니다. 다음 10의 배수부터 안내합니다.
  • 음성의 언어: 음성은 앱의 언어(설정 › Language)를 따릅니다. 기기에 해당 언어의 음성이 없으면 영어 음성을 사용합니다.
  • 다른 오디오: 동시에 재생되는 음악이나 다른 오디오는 숫자를 말하는 동안 작아졌다가 이후 계속 재생됩니다.
  • 백업과 초기화: 이 스위치는 백업에 포함되지 않으며 기본 설정 복원으로 바뀌지도 않습니다.

속도계 나가기

  1. 왼쪽 위의 뒤로 버튼을 탭합니다.

    확인: 도구 탭이 다시 표시됩니다. 위치 사용과 음성 안내가 중지됩니다.

  • 화면이 켜져 있음: 속도계가 열려 있는 동안 기기가 화면을 자동으로 잠그지 않습니다.
  • 열려 있는 동안에만 위치 사용: Cam Hub는 화면이 열려 있는 동안, 그리고 앱을 사용하는 동안에만 위치를 사용합니다. 위치는 표시에만 사용되며 저장되지 않습니다.
