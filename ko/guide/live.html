5실시간 탭과 전체 화면 비디오 월

실시간 탭은 기기 하나에서 활성화된 채널을 실시간 영상 비디오 월로 보여 줍니다. 이 탭에서 비디오 월의 화질을 전환하고, 카메라를 하나씩 열고, 비디오 월을 전체 화면 비디오 월로 확장할 수 있습니다. 신호가 없는 카메라는 두 비디오 월에서 모두 숨길 수 있습니다. YouTube와 Twitch 스트림도 카메라처럼 비디오 월에 표시됩니다.

실시간 탭

경로: 화면 아래의 실시간 탭

이 탭에는 한 번에 기기 하나가 표시됩니다. 녹화기라면 활성화된 모든 채널이, 독립형 카메라라면 그 카메라가 표시됩니다. 화면 제목은 해당 기기의 이름입니다. 서로 다른 기기의 카메라를 하나의 비디오 월에 표시하려면 LiveView Mix를 사용합니다. 자세한 내용은 8장 ‘LiveView Mix’ 참조.

  • 활성화된 채널만 표시: 비활성화된 채널은 이 탭에 나타나지 않습니다. 채널은 기기 페이지에서 활성화합니다. 자세한 내용은 ‘채널 옵션(길게 누르기)’ 참조.
  • 소리 없는 타일: 비디오 월의 타일에서는 YouTube와 Twitch 타일을 포함해 소리가 재생되지 않습니다. 소리는 단일 카메라 화면과 스트림의 전체 화면 보기에서 들을 수 있습니다. 자세한 내용은 ‘스냅샷, 소리, 화질’ 참조.
  • YouTube와 Twitch: 기기로 추가한 스트림은 해당 서비스의 플레이어가 있는 타일 하나로 표시됩니다. 타일을 탭하면 스트림이 전체 화면으로 열립니다. 자세한 내용은 ‘YouTube와 Twitch 스트림’ 참조.
  • 이 탭에는 새로 고침이 없음: 기기의 채널 목록은 기기 페이지를 열 때 기기에서 읽어 옵니다. 자세한 내용은 ‘기기 페이지’ 참조.
  • 앱을 벗어났을 때: 앱이 포그라운드를 벗어나면 모든 스트림이 중지됩니다. 앱으로 돌아오면 타일이 다시 연결됩니다.

실시간 탭 열기

  1. 화면 아래의 실시간 탭을 선택합니다.

    확인: 기기 하나에서 활성화된 채널의 실시간 영상이 표시됩니다. 제목은 기기의 이름입니다. 다른 기기를 선택하지 않은 동안에는 기기 탭의 첫 번째 기기가 표시됩니다.

제어 항목위치기능
목록 버튼(기기 선택)왼쪽 위기기 탭의 순서대로 기기 목록을 엽니다. 비디오 월에 표시된 기기에는 표시가 붙어 있습니다.
SD 또는 HD오른쪽 위, 첫 번째비디오 월 전체의 화질을 한꺼번에 전환합니다(모든 카메라를 HD로 전환 또는 모든 카메라를 SD로 전환). 버튼의 글자는 현재 화질입니다. 자세한 내용은 ‘비디오 월의 SD와 HD’ 참조. YouTube나 Twitch 스트림에서는 표시되지 않습니다.
검은 여백 버튼오른쪽 위, 두 번째기기 페이지와 마찬가지로 기본값, 확대해 채우기, 늘려 채우기를 차례로 전환합니다. 자세한 내용은 ‘기기 페이지’ 참조. 변경 내용은 이 비디오 월에만 적용되며 저장되지 않습니다. YouTube나 Twitch 스트림에서는 표시되지 않습니다.
전체 화면 비디오 월오른쪽 위, 세 번째전체 화면 비디오 월을 엽니다. 자세한 내용은 ‘전체 화면 비디오 월’ 참조.

추가된 기기가 없는 동안에는 SD/HD 버튼과 전체 화면 비디오 월 버튼을 사용할 수 없습니다. 검은 여백 버튼은 설정 › 화면 › 검은 여백의 모드로 시작합니다. 실시간 탭은 앱이 시작될 때 이 모드를 읽어 오므로 설정에서 바꾼 내용은 앱을 다음에 시작할 때 실시간 탭에 반영됩니다.

다른 기기 표시

  1. 왼쪽 위의 목록 버튼(기기 선택)을 탭합니다.

    확인: 기기 탭의 순서대로 모든 기기가 메뉴에 나열됩니다. 현재 표시 중인 기기에는 표시가 붙어 있습니다.

  2. 기기의 이름을 탭합니다.

    확인: 비디오 월에 선택한 기기의 활성화된 채널이 표시되고 제목이 해당 기기의 이름으로 바뀝니다. 선택 내용은 저장되며 앱을 종료한 뒤에도 유지됩니다.

실시간 탭에 표시할 기기는 실행 시 열기에서도 선택할 수 있습니다. 자세한 내용은 ‘설정의 LiveView Mix’ 참조. 선택한 기기를 삭제하면 비디오 월에는 목록의 첫 번째 기기가 표시됩니다.

비디오 월의 배치

화면나란히 표시되는 영상 수
세로로 든 iPhone1
가로로 든 iPhone2
iPad(두 방향 모두)2

타일은 16:9 비율을 유지합니다. 타일이 화면에 다 들어가지 않으면 비디오 월이 세로로 스크롤되며, 실시간 탭에는 페이지가 없습니다. 각 타일의 왼쪽 아래에는 채널 번호와 이름이 표시됩니다. 활성화된 채널이 하나뿐인 기기는 그 카메라를 전체 영역에 표시합니다. 기기를 회전하면 비디오 월이 즉시 다시 배치됩니다.

타일에 표시되는 내용

타일의미타일을 탭하면
실시간 영상(연결하는 동안에는 로딩 표시)채널이 활성화되어 있고, 요금제 범위 안이며, 온라인입니다.단일 카메라 화면이 열립니다.
어두운 배경의 오류 메시지스트림을 열 수 없었습니다. Cam Hub가 간격을 점점 늘리면서 스스로 다시 시도합니다. 로그인이 거부되었거나, 지원되지 않는 기기이거나, 요청이 너무 많았던 경우에는 다시 시도하지 않으며, 메시지는 앱이 포그라운드로 돌아오거나 비디오 월을 다시 열 때까지 유지됩니다.단일 카메라 화면이 열립니다.
회색 바탕에 사선이 그어진 카메라 기호와 신호 없음기기가 채널에 신호가 없다고 보고합니다.아무 일도 일어나지 않습니다.
회색 바탕에 일시정지 기호와 일시정지됨기기 페이지에서 채널의 영상을 수동으로 일시정지했습니다. 자세한 내용은 ‘채널 옵션(길게 누르기)’ 참조. 재개하려면 기기 페이지를 사용합니다.단일 카메라 화면이 열립니다.
잠금 기호와 요금제에 포함되지 않음채널은 활성화되어 있지만 요금제에 포함되지 않습니다. 자세한 내용은 11장 ‘요금제와 한도’ 참조.요금제 화면이 열립니다.
YouTube나 Twitch의 플레이어, 또는 스트림 이름과 메시지YouTube나 Twitch 스트림입니다. 소리가 없고 번호와 이름 레이블도 없습니다. 메시지는 ‘YouTube와 Twitch 스트림’에 나와 있습니다.스트림이 전체 화면으로 열립니다.

카메라 열기

  1. 실시간 영상이 표시된 타일을 탭합니다.

    확인: 카메라 이름을 제목으로 하는 단일 카메라 화면이 열립니다. 자세한 내용은 6장 ‘단일 카메라 화면’ 참조. 뒤로 버튼을 누르면 실시간 탭으로 돌아갑니다. YouTube나 Twitch 스트림의 타일을 탭하면 대신 스트림이 전체 화면으로 열립니다.

  2. 요금제에 포함되지 않음이 표시된 타일을 탭합니다.

    확인: 맨 위에 메시지가 있는 요금제 화면이 열립니다. 녹화기 채널에는 NVR 요금제로 모든 채널을 잠금 해제하세요. 메시지가, 무료 버전의 독립형 카메라에는 무료 버전의 활성화 카메라 2대 한도에 도달했습니다. 메시지가 표시됩니다. 완료로 화면을 닫습니다.

탭이 비어 있을 때

  • 추가된 기기가 없는 경우: 기기 없음과 먼저 ‘기기’ 탭에서 기기를 추가하세요. 문구가 표시됩니다. 자세한 내용은 3장 ‘기기 추가’ 참조.
  • 기기에 활성화된 채널이 없거나 모든 채널이 오프라인 카메라 숨기기 설정으로 숨겨진 경우: 활성화된 카메라 없음과 기기 페이지에서 카메라를 활성화하세요. 문구가 표시됩니다. 자세한 내용은 ‘표시할 카메라 선택’ 참조.

비디오 월의 SD와 HD

SD는 가벼운 영상이고 HD는 더 선명한 영상입니다. 실시간 탭 위쪽의 버튼과 전체 화면 비디오 월의 버튼은 비디오 월의 모든 카메라를 함께 전환합니다.

  1. 실시간 탭 오른쪽 위의 화질 버튼(SD 또는 HD)을 탭합니다.

    확인: 버튼의 글자가 다른 화질로 바뀌고 타일이 새 화질로 다시 연결됩니다.

  2. 버튼을 다시 탭합니다.

    확인: 비디오 월이 처음 화질로 돌아갑니다.

  • 시작 화질: 설정 › 기본 화질 › 여러 카메라(변경하지 않으면 SD). 설정에서 바꾼 내용은 실시간 탭에서 버튼을 탭하기 전까지 즉시 반영됩니다. 버튼을 탭한 뒤에는 앱을 종료할 때까지 비디오 월이 그 선택을 유지합니다. 전체 화면 비디오 월은 열 때마다 설정 값으로 시작합니다.
  • 저장되지 않음: 버튼으로 고른 화질은 저장되지 않습니다.
  • 채널당 스트림 하나: 일부 기기는 채널당 스트림을 하나만 제공합니다. 이러한 기기에서는 SD와 HD가 같은 영상을 표시합니다.
  • 확대 화면: 전체 화면 비디오 월에서 카메라를 확대해 열면 단일 카메라 설정을 사용하며 전환 버튼이 없습니다. 자세한 내용은 ‘기기의 전체 화면 비디오 월’ 참조.
  • 다른 모든 화면의 화질은 ‘기기 화면의 SD와 HD’, 설정은 ‘기본 화질’ 참조.

전체 화면 비디오 월

전체 화면 비디오 월은 기기에서 활성화된 모든 채널을 검은 배경에 화면 가득 표시합니다. 상태 막대가 숨겨지고 영상은 영상을 가장자리까지 표시 설정에 따라 화면 가장자리까지 확장됩니다. 자세한 내용은 ‘화면: 검은 여백과 영상을 가장자리까지 표시’ 참조. 이 비디오 월은 실시간 탭과 기기 페이지에서 열 수 있습니다. 기기 페이지에서 여는 방법은 ‘기기의 전체 화면 비디오 월’ 참조.

비디오 월 열기

  1. 실시간 탭 오른쪽 위의 전체 화면 비디오 월 버튼(대각선 화살표)을 탭합니다.

    확인: 비디오 월이 화면을 덮습니다. 맨 위 왼쪽에는 닫기 버튼이, 오른쪽에는 화질, 레이아웃, 검은 여백 버튼이 있습니다. 버튼은 흰색 테두리가 있는 원형 또는 캡슐형이어서 어떤 영상 위에서도 잘 보입니다. YouTube나 Twitch 스트림에서는 닫기 버튼과 레이아웃 버튼만 표시됩니다. 기기에 활성화된 채널이 없으면 활성화된 카메라 없음 문구가 표시됩니다.

  2. 왼쪽으로 쓸어넘긴 다음 오른쪽으로 쓸어넘깁니다.

  1. 비디오 월 오른쪽 위의 레이아웃을 탭합니다.

    확인: 타일이 한 줄에 1개 또는 2개씩 배치되고 버튼의 기호가 바뀝니다. 다음에 비디오 월을 열 때도 같은 배치가 사용됩니다.

카메라 열기와 비디오 월 닫기

  1. 실시간 영상이 표시된 타일을 탭합니다.

    확인: 비디오 월 위에 카메라의 확대 화면이 열리며 위쪽에 뒤로와 카메라 이름이 표시됩니다. 확대, 스피커, 카메라 제어, 녹화 영상은 ‘기기의 전체 화면 비디오 월’에서 설명합니다. 확대 화면이 열려 있는 동안 비디오 월의 다른 카메라는 일시정지됩니다. 요금제에 포함되지 않음이 표시된 타일은 요금제 화면을 열고, 신호 없음이 표시된 타일은 아무 일도 일어나지 않으며, YouTube나 Twitch 스트림의 타일은 스트림을 전체 화면으로 엽니다(‘YouTube와 Twitch 스트림’ 참조).

  2. 비디오 월 왼쪽 위의 가위표인 닫기를 탭합니다.

    확인: 실시간 탭이 다시 표시됩니다.

신호가 없는 카메라 숨기기

오프라인 카메라 숨기기 설정은 신호가 없는 카메라를 실시간 탭과 전체 화면 비디오 월에서 제거합니다. 기본값은 꺼짐입니다. 기기 페이지에는 여전히 모든 채널이 나열되며 신호가 없는 채널은 회색으로 표시됩니다. 자세한 내용은 ‘썸네일에 표시되는 내용’ 참조. LiveView Mix 비디오 월에는 영향이 없습니다. 신호가 없는 슬롯에는 신호 없음 판이 그대로 남습니다.

  1. 설정 탭을 선택한 다음 오프라인 카메라 숨기기까지 스크롤합니다. 이 행은 화면 아래의 별도 섹션에 있습니다.

    확인: 스위치가 꺼져 있습니다. 행 아래에 신호가 없는 카메라는 실시간 비디오 월에서 숨겨집니다. 기기 페이지에는 회색으로 계속 표시됩니다. 안내문이 표시됩니다.

  2. 오프라인 카메라 숨기기를 켭니다.

    확인: 스위치가 켜집니다. 모든 카메라가 다시 점검됩니다.

  3. 실시간 탭을 선택합니다.

    확인: 신호가 없는 카메라가 더 이상 비디오 월에 나타나지 않습니다. 기기에 남은 카메라가 없으면 활성화된 카메라 없음 문구가 표시됩니다.

  • 숨겨지는 카메라: 기기가 신호 없음으로 보고하는 채널과 스트림을 연속 두 번 열 수 없었던 카메라입니다. Cam Hub는 카메라를 숨기기 전에 한 번 더 시도합니다.
  • 숨겨진 카메라가 돌아오는 시점: 숨겨진 카메라는 앱이 포그라운드로 돌아오거나 스위치를 껐다가 다시 켤 때까지 다시 시도하지 않습니다. 그때 카메라를 한 번 더 시도하여 영상이 나오면 비디오 월에 남고, 다시 실패하면 다시 숨겨집니다. 기기가 신호 없음으로 보고한 채널은 기기가 다시 신호를 보고하면 돌아옵니다. 이 보고는 기기 페이지가 채널 목록을 읽을 때 갱신됩니다.
  • 적용 범위: 실시간 탭과 전체 화면 비디오 월(기기 페이지의 전체 화면 비디오 월 포함)에 적용됩니다. 이 설정은 앱 설정 백업에 포함되며 기본 설정 복원으로 초기화됩니다. 자세한 내용은 ‘초기화: 기본 설정, 모든 데이터 삭제, iCloud 백업 삭제’ 참조.
