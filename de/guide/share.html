10Teilen und Backup

Geräte mit ihren Passwörtern und optional die App-Einstellungen (LiveView-Mix-Seiten und Bedienfelder) lassen sich als verschlüsselter Code auf ein anderes Gerät übertragen oder mit anderen Personen teilen, oder sie werden in iCloud als mehrere benannte Backups gesichert und auf dem eigenen iPhone, iPad und Apple TV wiederhergestellt.

Kameras exportieren (Code erstellen)

Voraussetzung: Mindestens ein Gerät wurde hinzugefügt. Solange kein Gerät vorhanden ist, ist Kameras exportieren nicht verfügbar.

  1. Tippen Sie unten auf dem Bildschirm auf den Tab Einstellungen.

    Ergebnis: Der Bildschirm zeigt die Einstellungsliste.

  2. Tippen Sie im Abschnitt Kameras teilen auf Kameras exportieren.

    Ergebnis: Die Seite Kameras exportieren öffnet sich: die Liste Zu exportierende Geräte (standardmäßig alle abgehakt), Mit PIN sperren, App-Einstellungen einschließen und eine Schaltfläche wie 5 Geräte exportieren.

  3. Optional: Tippen Sie auf eine Gerätezeile, um das Häkchen zu entfernen oder wieder zu setzen.

    Ergebnis: Die Exportschaltfläche zeigt die Anzahl der ausgewählten Geräte, zum Beispiel 3 Geräte exportieren. Solange jedes Gerät abgehakt ist, heißt die Schaltfläche rechts neben dem Listentitel Auswahl aufheben und entfernt alle Häkchen; solange ein Gerät nicht abgehakt ist, heißt sie Alle auswählen und hakt jedes Gerät ab. Solange kein Gerät ausgewählt ist, ist die Exportschaltfläche nicht verfügbar.

  4. Optional: Schalten Sie App-Einstellungen einschließen ein.

    Ergebnis: Der Schalter ist eingeschaltet, und die Erklärung darunter ändert sich und besagt, dass der Code auch die App-Einstellungen enthält, genau wie bei einer Wiederherstellung aus iCloud. Zu den enthaltenen Punkten siehe „Was Backups und Codes enthalten“.

  5. Optional: Legen Sie die Sperre wie in „Einen Code sperren“ beschrieben fest.

    Ergebnis: Nach dem Festlegen einer Sperre bleibt 3 Geräte exportieren nicht verfügbar, bis die Eingabe vollständig ist. Ohne Sperre ist der Code offen: Jeder, der den Code und Cam Hub hat, kann ihn importieren.

  6. Tippen Sie auf die Exportschaltfläche, zum Beispiel 3 Geräte exportieren.

    Ergebnis: Die Ergebnisseite öffnet sich mit dem Titel Kameras exportieren. Ihr oberer Teil erklärt, dass der Code die Kameras und ihre Passwörter verschlüsselt enthält. Bei einem offenen Code fügt er mit einer orangefarbenen Markierung hinzu, dass jeder mit dem Code und Cam Hub die Kameras hinzufügen kann; bei einem gesperrten Code erinnert er daran, dass die PIN oder das Passwort getrennt zu senden ist. Darunter stehen die Schaltflächen Teilen und Kopieren und darunter der vollständige Text des Codes.

  7. Tippen Sie auf Teilen und wählen Sie einen Sendeweg, oder tippen Sie auf Kopieren.

    Ergebnis: Ein Tippen auf Teilen öffnet das Teilen-Menü des Systems, mit Optionen wie Nachrichten, Mail oder AirDrop. Ein Tippen auf Kopieren ändert die Schaltfläche zu Kopiert, und der vollständige Text des Codes liegt in der Zwischenablage.

  8. Tippen Sie oben rechts auf Fertig.

    Ergebnis: Die Ergebnisseite schließt sich, und die Seite Kameras exportieren erscheint wieder.

  • Teilen sendet einen Link, Kopieren kopiert Text. Teilen sendet einen Link, der mit https://cam-hub.almx.cc/i# beginnt, mit dem Code nach dem „#“, den Browser nicht an den Webserver senden. Kopieren legt den vollständigen Text in die Zwischenablage.
  • Der Empfänger: Ist Cam Hub installiert, öffnet der Link direkt die Importseite mit ausgefülltem Code. Ist es nicht installiert, öffnet der Link eine Webseite, die auf die Download-Seite der App verweist und den Code zum Kopieren anzeigt.
  • Der Text des Codes beginnt mit einer kurzen englischen Erklärung und der Installationsadresse, gefolgt vom Code, der mit CAMHUB1:, CAMHUB1L: oder CAMHUB2: beginnt und mehrere tausend Zeichen lang sein kann. Beim Import lässt sich der ganze Text einsetzen oder nur der Code.
  • Ein Code enthält die Passwörter der Geräte. Ein Code läuft nicht ab, und das Löschen der Geräte oder der App auf dem Quellgerät macht einen bereits geteilten Code nicht ungültig. Könnte ein Code offengelegt worden sein, sind die Passwörter der betroffenen Geräte zu ändern.
Ein Code gibt die Passwörter der Geräte weiter

Jeder, der einen Code ohne Sperre erhält und Cam Hub hat, kann jedes darin enthaltene Gerät mit seinem Passwort importieren. Der Code sollte nur an vertrauenswürdige Personen gesendet und bei Bedarf mit einer Sperre versehen werden.

Einen Code sperren

Ein Code kann offen sein, mit einer sechsstelligen PIN oder mit einem Passwort (Komplexe Verschlüsselung) gesperrt werden. Die Stärke des Schutzes unterscheidet sich zwischen den dreien stark, und die Wahl hängt davon ab, wie der Code gesendet wird.

Mit einer sechsstelligen PIN sperren

  1. Schalten Sie auf der Seite Kameras exportieren Mit PIN sperren ein.

    Ergebnis: Das Feld PIN (6 Ziffern) erscheint unter dem Schalter, und die Erklärung ändert sich und besagt, dass, wer importiert, diese PIN eingeben muss und dass sie getrennt vom Code zu senden ist.

  2. Geben Sie sechs Ziffern ein.

    Ergebnis: Das Feld akzeptiert nur Ziffern, der Zahlenblock schließt sich nach der sechsten Ziffer, und die Exportschaltfläche wird verfügbar. Bei weniger Ziffern bleibt die Exportschaltfläche nicht verfügbar.

Mit einem Passwort sperren (komplexe Verschlüsselung)

  1. Schalten Sie auf der Seite Kameras exportieren Mit PIN sperren ein.

    Ergebnis: Der Schalter Komplexe Verschlüsselung und das Feld PIN (6 Ziffern) erscheinen.

  2. Schalten Sie Komplexe Verschlüsselung ein.

    Ergebnis: Das PIN-Feld wird durch die beiden Felder Passwort (mind. 8 Zeichen) und Passwort bestätigen ersetzt, und alles zuvor Eingegebene wird gelöscht.

  3. Geben Sie das Passwort im Feld Passwort (mind. 8 Zeichen) ein.

    Ergebnis: Das Feld verdeckt die Zeichen mit Punkten. Beliebige Buchstaben, Ziffern und Symbole sind erlaubt, und ein längeres Passwort ist stärker.

  4. Geben Sie dasselbe Passwort im Feld Passwort bestätigen erneut ein.

    Ergebnis: Stimmen beide Eingaben überein und haben mindestens 8 Zeichen, wird die Exportschaltfläche verfügbar. Unterscheiden sie sich, erscheint unter dem Feld in Orange der Text Die beiden Passwörter stimmen nicht überein., und die Schaltfläche bleibt nicht verfügbar.

  • PIN oder Passwort getrennt vom Code senden, niemals in derselben Nachricht.
  • Eine vergessene PIN oder ein vergessenes Passwort lässt sich nicht wiederherstellen. Cam Hub speichert sie nicht und sendet sie nicht an den Entwickler. Wurde sie vergessen, ist ein neuer Code zu exportieren.
  • Bei einem Passwort zählt die Groß- und Kleinschreibung, und Leerzeichen zählen mit. Derselbe Buchstabe mit Akzent, auf verschiedenen Tastaturen eingegeben, wird als identisch behandelt.
  • Wird ein Code an einem nicht privaten Ort abgelegt, etwa in einer Chatgruppe oder einer E-Mail, ist er mit einem Passwort zu sperren, und das Passwort ist über einen anderen Kanal zu senden.
  • Wer importiert, muss nicht im Voraus wissen, welche Sperre verwendet wurde. Nach dem Einsetzen des Codes erkennt Cam Hub die Sperre selbst und zeigt die passende Abfrage und Tastatur; siehe „Kameras importieren“.

Kameras importieren

Ort: Einstellungen › Kameras importieren, oder direkt durch Tippen auf einen empfangenen Freigabelink.

Code einsetzen

  1. Tippen Sie unten auf dem Bildschirm auf den Tab Einstellungen.

    Ergebnis: Der Bildschirm zeigt die Einstellungsliste.

  2. Tippen Sie im Abschnitt Kameras teilen auf Kameras importieren.

    Ergebnis: Die Seite Kameras importieren öffnet sich. Der Abschnittstitel lautet Code einsetzen, mit den Schaltflächen Einsetzen und Kameras importieren und einem Textfeld.

  3. Tippen Sie auf Einsetzen. Alternativ berühren Sie das Textfeld lange und setzen den Code manuell ein.

    Ergebnis: Der Code erscheint im Textfeld. Ist der Code gesperrt, erscheint unter den Schaltflächen ein Sperrhinweis: Mit einer 6-stelligen PIN gesperrt – du wirst danach gefragt. oder Mit einem Passwort gesperrt – du wirst danach gefragt. Ein offener Code zeigt keinen Hinweis.

  4. Tippen Sie auf Kameras importieren.

    Ergebnis: Ein offener Code wird sofort gelesen. Nennt er für ein Gerät, das bereits auf diesem Gerät vorhanden ist, eine andere Adresse und enthält er das Passwort dieses Geräts nicht, erscheint zuerst der Dialog Dieser Code ändert Kameraadressen. Andernfalls wird ein Code ohne App-Einstellungen direkt importiert, worauf der Bildschirm 3 Kameras hinzugefügt zeigt; ein Code mit App-Einstellungen öffnet den Dialog Dieser Code enthält auch die App-Einstellungen des Absenders. Ein gesperrter Code öffnet den Dialog PIN eingeben (Zahlenblock, Feld 6 Ziffern) oder den Dialog Passwort eingeben (vollständige Tastatur).

  5. Geben Sie bei einem gesperrten Code die PIN oder das Passwort ein und tippen Sie auf Importieren.

    Ergebnis: Der Dialog schließt sich, und unter Kameras importieren erscheint ein Ladesymbol, während der Code entsperrt wird, was einen Moment dauern kann; Kameras importieren ist währenddessen nicht verfügbar. Danach geht der Import weiter wie bei einem offenen Code: mit dem Dialog Dieser Code ändert Kameraadressen, dem Dialog Dieser Code enthält auch die App-Einstellungen des Absenders oder 3 Kameras hinzugefügt.

  6. Erscheint der Dialog Dieser Code ändert Kameraadressen, tippen Sie auf Neue Adressen verwenden oder Aktuelle Adressen behalten.

    Ergebnis: Der Dialog führt jedes betroffene Gerät in einer Zeile auf, mit seiner aktuellen Adresse und der Adresse im Code, und erklärt, dass die in Cam Hub gespeicherten Passwörter dieser Kameras dann an die neuen Adressen gehen. In beiden Fällen zeigt der Bildschirm danach 3 Kameras hinzugefügt oder, bei einem Code mit App-Einstellungen, den Dialog Dieser Code enthält auch die App-Einstellungen des Absenders. Abbrechen schließt den Dialog und importiert nichts. Was jede Auswahl ändert, ist in „Wenn ein Code Kameraadressen ändert“ beschrieben.

  7. Erscheint der Dialog Dieser Code enthält auch die App-Einstellungen des Absenders, tippen Sie auf Nur Kameras hinzufügen oder Auch die Einstellungen übernehmen.

    Ergebnis: Der Dialog erklärt, dass die LiveView-Mix-Wände, die Sprache und weitere Einstellungen des Absenders die dieses Geräts ersetzen würden und dass sich das nicht rückgängig machen lässt. In beiden Fällen zeigt der Bildschirm danach 3 Kameras hinzugefügt. Nur Kameras hinzufügen lässt die Einstellungen dieses Geräts unverändert; Auch die Einstellungen übernehmen übernimmt die Einstellungen des Codes. Abbrechen schließt den Dialog und importiert nichts.

  8. Tippen Sie auf Fertig.

    Ergebnis: Der Bildschirm kehrt zur Einstellungsliste zurück, und die hinzugefügten Geräte erscheinen im Tab Geräte.

Wird Einsetzen getippt, kann das System fragen, ob Cam Hub aus einer anderen App einsetzen darf; erlauben Sie es. Alternativ berühren Sie das Textfeld lange und setzen den Code über das Bearbeiten-Menü ein.

Abbrechen im Dialog PIN eingeben oder Passwort eingeben schließt ihn, ohne zu importieren. Ein Ladesymbol unter Kameras importieren erscheint auch, während die Geräte gespeichert werden, und zwischen zwei Dialogen; solange es angezeigt wird, ist Kameras importieren nicht verfügbar.

Aus einem Link importieren

  1. Tippen Sie auf einem iPhone oder iPad mit Cam Hub auf den empfangenen Freigabelink.

    Ergebnis: Cam Hub öffnet die Seite Kameras importieren mit dem bereits im Textfeld stehenden Code. Bei einem gesperrten Code wird der passende Sperrhinweis angezeigt.

  2. Tippen Sie auf Kameras importieren und geben Sie bei einem gesperrten Code die PIN oder das Passwort ein.

    Ergebnis: Der Bildschirm zeigt 3 Kameras hinzugefügt oder zuerst einen oder beide der Dialoge, die in den Schritten zum Einsetzen eines Codes beschrieben sind: Dieser Code ändert Kameraadressen und danach, bei einem Code mit App-Einstellungen, Dieser Code enthält auch die App-Einstellungen des Absenders.

  3. Beantworten Sie jeden erscheinenden Dialog wie in den Schritten zum Einsetzen eines Codes.

    Ergebnis: Der Bildschirm zeigt 3 Kameras hinzugefügt.

  • Der Import führt zusammen. Ein Gerät des Codes, das einem bereits auf diesem Gerät vorhandenen Gerät entspricht, aktualisiert dieses; die übrigen Geräte des Codes werden hinzugefügt, und bereits auf diesem Gerät vorhandene Geräte werden nicht gelöscht. Ein Gerät entspricht einem anderen, wenn es dieselbe Marke, dieselbe Seriennummer und denselben Benutzernamen hat oder, wenn eines der beiden keine Seriennummer hat, dieselbe Marke, dieselbe Adresse, denselben HTTP-Port und denselben Benutzernamen; wird ein Code auf dem Gerät importiert, das ihn erstellt hat, entsprechen seine Geräte außerdem den Geräten, von denen sie stammen. Ein entsprechendes Gerät übernimmt den Namen, das Modell, die Seriennummer und die Firmware-Version sowie die Kanäle des Codes. Den Benutzernamen, das Passwort und die SNMP-Einstellungen eines NAS (siehe „Festplattenzustand“) übernimmt es nur, wenn der Code sie enthält; ein auf diesem Gerät gespeichertes Passwort wird also nie durch ein leeres ersetzt. Enthält der Code das Passwort des Geräts, übernimmt das Gerät auch die Adresse, die Ports und den Streampfad des Codes, und seine HTTPS-Einstellung folgt der Regel in „Was Backups und Codes enthalten“. Enthält der Code kein Passwort dafür, behält das Gerät seine Adresse, seine Ports, seinen Streampfad und seine HTTPS-Einstellung, es sei denn, im Dialog Dieser Code ändert Kameraadressen wird Neue Adressen verwenden gewählt; siehe „Wenn ein Code Kameraadressen ändert“.
  • Der Aktivierungszustand der Kanäle wird mit dem Abo dieses Geräts abgeglichen. Besteht ein Abo, werden Kanäle jenseits seines Kontingents als Deaktiviert importiert. Im Gratis-Tarif bleibt der Aktivierungszustand so, wie er im Code steht, und Kanäle jenseits des Gratis-Kontingents zeigen Nicht in deinem Abo und ein Schloss, bis ein Abo sie abdeckt. Zu den Kontingenten siehe Kapitel 11, „Abos und Limits“.
  • App-Einstellungen werden nur übernommen, wenn der Code mit eingeschaltetem App-Einstellungen einschließen exportiert wurde und Auch die Einstellungen übernehmen gewählt wird. Sie ersetzen dann die entsprechenden Einstellungen auf diesem Gerät, einschließlich der LiveView-Mix-Seiten und der Sprache. Eine Kachel, die eine nicht mit dem Code importierte Kamera zeigt, wird zu einer leeren Kachel, und jede andere Kachel bleibt an ihrer Stelle. Mit Nur Kameras hinzufügen oder bei einem Code ohne App-Einstellungen bleiben die Einstellungen dieses Geräts unverändert.
  • YouTube- und Twitch-Streams in einem Code werden wie die übrigen Geräte importiert und belegen kein Kontingent des Abos. Bevor der erste Stream eines Dienstes auf diesem Gerät abgespielt wird, werden die Bedingungen dieses Dienstes zur Zustimmung angezeigt; siehe „YouTube- und Twitch-Streams“.

Wenn ein Code Kameraadressen ändert

Ein Freigabecode kann für ein Gerät, das bereits auf diesem Gerät vorhanden ist, eine andere Adresse nennen, zum Beispiel nachdem sich die Adresse der Kamera des Absenders geändert hat. Enthält der Code das Passwort dieses Geräts, übernimmt das Gerät die Adresse des Codes ohne Rückfrage. Enthält der Code kein Passwort dafür, würde der Import das auf diesem Gerät gespeicherte Passwort an die Adresse im Code senden, die jemand anderem gehören kann. Cam Hub fragt deshalb zuerst nach, mit dem Dialog Dieser Code ändert Kameraadressen. Der Dialog und seine Auswahlmöglichkeiten sind auf iPhone, iPad und Apple TV gleich.

Wann der Dialog erscheint

  • Der Dialog erscheint, nachdem der Code gelesen wurde, nach der PIN oder dem Passwort eines gesperrten Codes und vor dem Dialog Dieser Code enthält auch die App-Einstellungen des Absenders. Wird kein Gerät aufgeführt, erscheint er nicht.
  • Ein Gerät wird nur aufgeführt, wenn alles Folgende zutrifft: Das Gerät des Codes entspricht einem Gerät auf diesem Gerät (siehe „Kameras importieren“), der Code enthält kein Passwort dafür, und der Code nennt eine andere Adresse, einen anderen HTTP-Port oder einen anderen RTSP-Port. Dieselbe Adresse in anderer Schreibweise, zum Beispiel in Großbuchstaben oder mit Leerzeichen davor oder danach, gilt nicht als andere Adresse. Hat der Code keine Adresse für das Gerät, gilt die aktuelle Adresse als unverändert, sodass sich nur ein Port unterscheiden kann.
  • Ein Code enthält das Passwort jedes Geräts, für das Cam Hub beim Absender ein gespeichertes Passwort hat. Ein Gerät ohne gespeichertes Passwort beim Absender (siehe „Ein Gerät ohne gespeichertes Passwort“) wird ohne Passwort übertragen.

Wie ein Backup verschlüsselt und geschützt wird

Ein Backup wird verschlüsselt in der privaten iCloud des Nutzers gespeichert und nur mit Geräten synchronisiert, die denselben Apple Account verwenden. Ein Backup hat keine PIN. Der Verschlüsselungsschlüssel ist in die App eingebaut und in jeder Installation derselbe, sodass jedes eigene Gerät ohne ein zu merkendes Passwort wiederherstellen kann. Der Schlüssel verhindert nur, dass das Backup als Klartext gespeichert wird; er ist kein Geheimnis gegenüber jemandem, der sowohl das Backup als auch die App erhält. Der Schutz eines Backups beruht auf der Sicherheit des Apple Accounts und von iCloud, daher muss der Apple Account sicher gehalten werden.

  2. Stellen Sie sicher, dass Ziel auf Mein Backup steht, und tippen Sie auf Jetzt sichern.

    Ergebnis: Die Seite zeigt die grüne Erfolgsmeldung, und das neue Backup erscheint oben in Backups in iCloud.

  3. Öffnen Sie auf dem neuen Telefon Cam Hub, tippen Sie auf den Tab Einstellungen und dann auf Aus iCloud wiederherstellen.

    Ergebnis: Die Seite Aus iCloud wiederherstellen öffnet sich. Steht Quelle auf Mein Backup, zeigt die Liste Backup auswählen die Backups, und das neueste ist ausgewählt. Ist das Backup des alten Telefons noch nicht synchronisiert, öffnen Sie die Seite etwas später erneut.

  4. Stellen Sie sicher, dass das Backup des alten Telefons das Häkchen trägt, und tippen Sie dann auf Wiederherstellen.

    Ergebnis: Die Seite zeigt 5 Geräte wiederhergestellt. Der Tab LiveView Mix zeigt die Wand des alten Telefons.

  5. Tippen Sie auf dem neuen Telefon im Tab Einstellungen auf Käufe wiederherstellen.

    Ergebnis: Käufe wiederhergestellt. erscheint. Das Abo ist nicht Teil des Backups und wird auf diese Weise abgerufen; siehe „Abonnieren, Käufe wiederherstellen und Code einlösen“.

Methode 2: Übertragung mit einem Freigabecode

  1. Öffnen Sie auf dem alten Telefon den Tab Einstellungen und tippen Sie auf Kameras exportieren.

    Ergebnis: Die Seite Kameras exportieren öffnet sich, standardmäßig mit jedem abgehakten Gerät.

  2. Schalten Sie App-Einstellungen einschließen ein.

    Ergebnis: Der Schalter ist eingeschaltet, und die LiveView-Mix-Seiten und die Bedienfelder reisen mit dem Code.

  3. Optional: Legen Sie eine PIN oder ein Passwort wie in „Einen Code sperren“ beschrieben fest.

    Ergebnis: Die Exportschaltfläche wird verfügbar, sobald die Eingabe vollständig ist.

  4. Tippen Sie auf die Exportschaltfläche, dann auf Teilen, und senden Sie den Link an das neue Telefon.

    Ergebnis: Das Teilen-Menü des Systems hat den Link gesendet. Senden Sie die PIN oder das Passwort über einen anderen Kanal.

  5. Tippen Sie auf dem neuen Telefon auf den empfangenen Link, tippen Sie auf Kameras importieren und geben Sie bei einem gesperrten Code die PIN oder das Passwort ein.

    Ergebnis: Der Dialog Dieser Code enthält auch die App-Einstellungen des Absenders erscheint.

  6. Tippen Sie auf Auch die Einstellungen übernehmen.

    Ergebnis: Der Bildschirm zeigt 5 Kameras hinzugefügt. Der Tab LiveView Mix zeigt die Wand des alten Telefons.

Keine der beiden Methoden überträgt das Abo. Nach der Anmeldung mit demselben Apple Account wird es auf dem neuen Telefon mit Käufe wiederherstellen abgerufen; siehe „Abonnieren, Käufe wiederherstellen und Code einlösen“.

Die Einrichtung auf das Apple TV übertragen

Auf dem Apple TV lassen sich einer Wand nur ihre Kameras, jeweils in SD oder HD, ein Layout und schwarze Balken zuweisen (siehe „Der Tab LiveView Mix“); das Anordnen einer Wand, das Bearbeiten ihrer Kacheln, das Zeichnen eines eigenen Layouts und das Erstellen von Bedienfeldern erfolgen auf einem iPhone oder iPad, und das Eingeben eines langen Codes mit der Fernbedienung ist mühsam. Empfohlen wird, die Einrichtung zuerst auf einem iPhone oder iPad abzuschließen. Ein Backup mit Apple TV als Ziel (siehe „In iCloud sichern“) oder ein Freigabecode (siehe „Kameras exportieren (Code erstellen)“) bringt dann die Geräte und die Wand auf den Fernseher. Das Apple TV stellt nur die Apple-TV-Kopie wieder her, nicht die Backups von Mein Backup, und zeigt YouTube- und Twitch-Streams nur mit ihrem Namen an. Die Schritte für das Apple TV und die dortigen Unterschiede sind in Kapitel 14, „Apple TV“ beschrieben.
