隱私權政策

Cam Hub 以裝置端處理與使用者主動控制為原則，不要求建立服務帳號，也不使用第三方廣告追蹤。

生效日期2026 年 10 月 29 日
AppCam Hub
聯絡信箱app-dev@almx.cc

政策概要

Cam Hub 不要求您建立 Cam Hub 服務帳號，也不整合第三方廣告或廣告追蹤。App 的用途是連接由您設定的攝影機與錄影主機。

若您加入 YouTube 或 Twitch 直播，會由這些服務自己的播放器播放；播放器可能顯示它們自己的廣告，並接收來自您裝置的資訊，詳見下方「YouTube 與 Twitch 直播」。

設備資料與登入資訊

攝影機與錄影主機的名稱、位址、連接埠、使用者名稱、通道資訊及 App 設定會保存在您的裝置上。密碼保存在 Apple 鑰匙圈。Cam Hub 只會為了執行您要求的連線與操作使用這些資訊。

攝影機連線與影像

查看即時或錄影影像時，App 會連線至您提供的設備位址。您的設備、網路服務商、VPN 服務商、DNS 服務商或您選擇的任何遠端端點，可能依其政策處理連線資訊。Cam Hub 不會將攝影機影像用於廣告或行為分析。

YouTube 與 Twitch 直播

  • 若您加入 YouTube 直播或頻道、或 Twitch 頻道，Cam Hub 會使用該服務自己的嵌入式播放器播放：YouTube 的播放器（YouTube API Services）或 Twitch 的播放器。任一服務的第一個直播播放前，App 會請您同意該服務的條款。若您從未加入這類直播，本節不適用於您。
  • 播放器從 YouTube 或 Twitch 載入，並直接連線到它們的伺服器。播放時，該服務會收到您的 IP 位址以及裝置與瀏覽器資訊，並可能使用 Cookie 或類似技術、統計播放情形及顯示廣告，詳見下方連結的 Google 隱私權政策（YouTube）或 Twitch 隱私權聲明（Twitch）。Cam Hub 只在 App 執行期間保留播放器的 Cookie 與儲存資料，也不會收到這些資訊。
  • Cam Hub 只會在您的裝置上保存您加入的連結與頻道名稱；若您建立分享代碼或 iCloud 備份，也會包含在其中。在 App 中刪除該直播即會移除。
  • Google 隱私權政策
  • Twitch 隱私權聲明

Webhook 控制面板與第三方端點

您可以設定 HTTP 或 HTTPS 方法、端點網址、自訂標頭與請求內容，建立 LiveView Mix 控制按鈕。這些設定可能包含 Authorization 權杖或其他敏感資料，會保存在裝置上的 LiveView Mix 設定中，也可能包含在您主動建立的加密 iCloud 備份內。

只有在您點按按鈕時，App 才會從您的裝置直接把請求送到您指定的端點，例如 Home Assistant、Node-RED 或其他第三方服務。該端點及網路服務商可能依其政策處理您的來源 IP 位址、標頭與請求內容；Cam Hub 的開發者不會選擇、控制或接收傳送到這些端點的資料。HTTP 傳輸未加密，敏感資料請使用 HTTPS，並自行確認接收端的隱私與安全做法。

區域網路存取與掃描

Cam Hub 會請求「區域網路」權限，以直接連接攝影機與錄影主機。當您在「工具」分頁啟動掃描時，App 會探測您選擇的子網路及常見攝影機服務連接埠，並可能讀取回應中的設備位址、開放連接埠與 HTTP Server 名稱，協助您辨識設備。

掃描由您主動啟動，結果在裝置上處理，不會傳送給 Cam Hub 的開發者。

設備報告（實驗性）

  • 若新增攝影機或錄影主機失敗，Cam Hub 會提供一項選用的實驗性設備報告，協助開發者了解原因。此功能只會在新增設備的嘗試失敗之後提供；只有在您點選「將詳細資訊傳送給開發者」並已接受首次使用前顯示的聲明後才會開始，且僅在其畫面開啟期間執行。您可以隨時停止。
  • 執行時，您的 Apple 裝置會直接向您輸入的設備位址傳送唯讀請求：連至您輸入的連接埠；若設備位於區域網路，另會連至常見的攝影機連接埠。這些請求用於檢查哪些連接埠有回應、讀取設備的型號、韌體與支援的通訊協定（例如 ISAPI、ONVIF 與 RTSP），並簡短測試影像串流是否有資料傳來。這些請求不會變更設備上的任何設定，也都不會傳送給開發者或任何其他伺服器。
  • 這些請求會以您輸入的使用者名稱與密碼登入，與新增設備時相同。若失敗的嘗試本身就是登入被拒，報告完全不會送出登入請求。登入失敗會由設備計次，也可能被設備記錄。
  • 報告內容包括：App 版本、iOS 版本、Apple 裝置型號與語言設定；您選擇的連線模式與 App 顯示的錯誤；隱藏最後一段數字的設備位址（網際網路上的位址不會列入）；您輸入的連接埠與有回應的連接埠；設備自行回報的品牌、型號、韌體與支援的通訊協定；狀態碼與設備回應的簡短節錄；Apple 裝置的連線方式（例如 Wi-Fi、行動網路或 VPN）；以及測試影像串流的封包數量與大小，絕不包含畫面。
  • 在顯示或保存任何內容之前，自動過濾機制會將密碼、使用者名稱、權杖、Cookie、序號、MAC 位址、公開 IP 位址、主機名稱、電子郵件地址、設備與通道名稱、Wi-Fi 網路名稱、電話號碼，以及較長的金鑰或識別碼，替換為可見的佔位標記；網頁文字不會保留。過濾是自動進行的，並非萬無一失，因此送出前請先閱讀報告。
  • 不會有任何內容自動傳送給開發者。報告會先顯示在畫面上，您可以關閉其中各個部分，或不送出就直接關閉。若要送出，請點選「以電子郵件寄給開發者」：報告會在「郵件」的撰寫視窗中開啟，收件人為支援信箱，內容同時放在郵件本文與文字檔附件中；在該視窗按下「傳送」之前不會寄出任何內容，您也可以改為取消。若「郵件」尚未設定，報告會被複製到剪貼簿，並在您的郵件 App 中開啟已填好收件人的郵件。您也可以複製報告，或透過 iOS 的分享表單分享。
  • 複製的報告不會透過通用剪貼簿傳到您的其他裝置，並會在 120 秒後從剪貼簿中失效。
  • 最近的最多五份報告會保存在您的裝置上，方便您稍後傳送。這些報告不會納入裝置備份，也不會納入 Cam Hub 的 iCloud 備份。您可隨時在設備報告畫面以「刪除已儲存的報告」刪除這些報告；儲存第六份時也會刪除最舊的一份，刪除 App 時則會全部移除。
  • 若您以電子郵件寄出報告，開發者會收到該郵件與您的電子郵件地址。報告僅用於查明您回報的問題，並只會在回覆問題及保留必要支援紀錄所需的期間內保存。
  • 設備報告為實驗性功能，可能隨時變更或移除。傳送報告並不保證您的設備會獲得支援，也不保證會收到回覆或修正。

照片與相機

您可以透過 Apple 的系統照片選擇器挑選特定照片，或授權相機拍攝新照片，放入 LiveView Mix 空格。App 只取得您選取或拍攝的圖片，不會取得整個照片圖庫；圖片會縮小並壓縮後保存在裝置的 LiveView Mix 設定中。

圖片僅保存在您的裝置上，Cam Hub 開發者不會接收或存取。只有在您自行建立 Cam Hub 加密 iCloud 備份時，圖片才可能隨備份存入您自己的 iCloud，以供裝置還原。您可在 LiveView Mix 中移除圖片，並可在系統設定中變更相機或照片權限。

位置

Cam Hub 只在「使用 App 期間」要求位置權限。位置與指南針方向只會在需要它們的畫面開啟期間讀取，例如「工具」分頁中顯示車速與指南針方向的時速表；App 不會在背景追蹤位置。

位置與指南針方向在您的裝置上處理，用於顯示車速與方向，不會儲存、不會納入備份，也不會傳送給 Cam Hub 開發者或任何其他對象。若時速表以語音報讀車速，語音由您裝置上 iOS 內建的語音合成產生，您可在該畫面中關閉。您可隨時在 Apple 裝置的「設定」中拒絕或撤回定位權限；沒有定位時，App 的其他功能仍可使用。

攝影機分享代碼

  • 您可分享含所選攝影機或錄影主機之位址、使用者名稱、通道資訊及密碼的代碼。若您開啟「包含 App 設定」，代碼也會帶有 App 設定，其中可能含有 LiveView Mix 設定，例如可能包含權杖的 Webhook 設定。代碼以 AES-256-GCM 加密，金鑰由 PBKDF2-HMAC-SHA256（600,000 次迭代）衍生。分享時，您可從三種鎖定方式中擇一。
  • 不鎖定：金鑰來自 Cam Hub 內建的一組祕密值，因此任何相容版本的 Cam Hub 都能開啟代碼。這只能避免內容被一眼看穿，無法防範同時取得代碼與 App 的人。
  • 六位數 PIN：必須輸入您設定的 PIN 才能開啟代碼。六位數 PIN 只有一百萬種可能，取得代碼的人可在自己的電腦上離線逐一嘗試。
  • 複雜加密（密碼）：必須輸入您設定的密碼才能開啟代碼；密碼至少八個字元，可使用任何字母、數字與符號。唯有又長又獨一無二的密碼，才能讓猜測在實務上行不通。
  • Cam Hub 不會把代碼、PIN 或密碼傳送給開發者，開發者也無法找回忘記的 PIN 或密碼。請把 PIN 或密碼與代碼分開傳送。
  • 代碼不會自動到期。從來源裝置刪除設備或 App，也不會撤銷已分享的副本；若代碼可能外洩，請更改相關設備的密碼。
  • 代碼由您選擇的分享對象 App 傳遞，並依該 App 的政策處理。若以連結分享（連至 Cam Hub 網站），代碼位於連結中「#」之後，瀏覽器不會把這部分傳送給網站伺服器。

選用的 iCloud 備份

若您選擇使用 iCloud 備份，App 會先加密支援的攝影機與錄影主機設定、登入資訊、通道及 App 設定，再存入您私人的 iCloud Key-Value Store。iPhone、iPad 與 Apple TV 的備份和還原不使用 PIN。備份以 App 內建的金鑰加密，而非您自行設定的密碼；其保護仰賴您的 Apple 帳號與 iCloud。

備份時間、設備數量與站點名稱會分開保存，供 App 顯示備份狀態。還原時選擇可用備份即可繼續。

購買與訂閱

購買與訂閱由 Apple 處理。我們不會取得您的完整付款卡號或銀行資訊。App 只會讀取 Apple 提供的購買狀態，以啟用相應的使用上限或功能。

分享、保留、刪除與選擇

我們不販售個人資料。本機設定會保留在您的裝置上，直到您刪除相關內容或移除 App。您可在 App 內刪除設備、LiveView Mix 圖片與控制設定，並可分開刪除 iCloud 備份；系統權限可在 Apple 裝置的「設定」中撤回。

選用的 iCloud 資料由您的 Apple 帳號與 iCloud 服務管理。您透過電子郵件主動寄給支援信箱的資訊，只會在回覆問題及保留必要支援紀錄所需的期間內保存。

兒童與政策更新

Cam Hub 並非以兒童為主要對象，也不會刻意蒐集兒童的個人資料。當 App 功能、法規或商店要求變更時，我們可能更新本政策，並在本頁公布新的修訂日期。

網站統計

本網站（不是 Cam Hub App）使用 Cloudflare, Inc. 提供的 Cloudflare Web Analytics 統計造訪次數。它不會設定 Cookie、不使用本機儲存空間、不會跨網站追蹤您，也不會建立您的個人檔案。統計內容為各頁面的瀏覽數、來源網站、國家或地區、瀏覽器與裝置類型。若您的瀏覽器送出「不追蹤」（Do Not Track）或 Global Privacy Control 訊號，則不會載入。Cam Hub App 本身不含任何分析工具。
