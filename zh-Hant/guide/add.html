3加入設備

加入攝影機或錄影主機需要設備的位址與帳號。Cam Hub 會自行找出連線到設備的方式；也可以在「進階」中指定連線方式與連接埠。YouTube 直播與 Twitch 頻道則在各自的畫面中新增。

免費方案只會自動啟用額度內的通道，其餘通道顯示為已停用。已達方案允許的錄影主機數量時，畫面開啟方案頁。範例設備占用免費方案的錄影主機名額時，方案頁會說明此情況；刪除範例設備即可釋出名額。YouTube 直播與 Twitch 頻道一律不計入方案額度。額度說明見第 11 章「方案與限制」。

已加入設備的位址無法編輯

已加入的設備可以重新命名，使用者名稱與密碼可透過編輯帳號密碼變更，見「變更設備的使用者名稱與密碼」。位址則無法變更。IP 位址變更時，新位址會被視為另一台設備，錄影主機也會占用錄影主機額度。此時請先刪除舊設備（見第 4 章「設備頁與通道」），再以新位址新增。以相同的位址、連接埠與使用者名稱再次新增時，會就地更新已儲存的設備，而不是建立第二台。

不選品牌直接加入

使用預設的自動偵測時，Cam Hub 只需要位址與帳號。加入分為兩個階段：

  1. 連接埠檢查。Cam Hub 檢查該位址上攝影機與錄影主機常用的連接埠有哪些是開放的：網頁與控制介面、ONVIF、RTSP，以及某一設備系列專用協定的連接埠。檢查不會送出使用者名稱與密碼，因此不會累計為帳號鎖定的次數。沒有任何回應時，會以較長的等待時間再檢查一次。
  2. 連線嘗試。接著 Cam Hub 在有回應的連接埠上，依序嘗試各種連線方式：內建支援的原廠通訊協定、某一設備系列的專用協定、ONVIF，最後是純 RTSP。RTSP 會先嘗試設備透露出的品牌的串流路徑，再嘗試多數攝影機使用的路徑，最後嘗試清單中所有品牌的路徑。第一個連線成功的方式會連同成功時的連接埠一起保留。
  • 在進階中填入的連接埠會優先嘗試。填入的連接埠不是預設值（80 或 554）且為開放時，只使用該連接埠，因為在轉送多台設備的位址上，其他連接埠可能屬於另一台設備。
  • 為保護帳號，原廠通訊協定拒絕登入時，嘗試會立即結束，並顯示使用者名稱或密碼錯誤。ONVIF 與 RTSP 可能使用各自的帳號，因此在第二次登入被拒絕後才結束。登入被拒絕之後，串流路徑改為一次只嘗試一條。
  • 只能以 RTSP 連到的攝影機，一律加入為獨立攝影機。只提供 RTSP 的錄影主機，須選擇其品牌並輸入攝影機數量，見「連線方式的選擇」。
  • 某一設備系列的專用協定，只會在區域網路內的位址、以其預設連接埠自動嘗試。這類設備位於區域網路之外或使用其他連接埠時，請在進階中選擇其連線方式，見「連線方式」。
  • 嘗試大量串流路徑需要時間。遇到錯誤路徑時不回應的攝影機，加入可能要一分鐘以上才會成功或失敗。
  • 加入失敗時，錯誤訊息下方會列出找到的開放連接埠，例如找到的開放連接埠：80, 554，或顯示這個位址沒有找到任何開放的連接埠。前者表示設備有回應但無法連線；後者表示完全沒有回應。

自動偵測能辨識的品牌與嘗試的完整順序，見「連線方式」。

連線方式的選擇

多數設備使用自動偵測即可。自動偵測找不到設備，或需要使用特定協定時，在進階中選擇連線方式。

  1. 在新增設備表單中點選進階。

    確認：區塊展開，顯示連線方式、HTTP 連接埠、RTSP 連接埠與使用 HTTPS開關。

  2. 點選連線方式。

    確認：開啟附有搜尋欄位的連線方式清單。最上方是自動偵測、ONVIF、某一設備系列的專用協定與 RTSP；下方的品牌依字母順序列出支援的品牌。

  3. 選用：在搜尋欄位輸入品牌名稱的一部分。

    確認：清單只顯示符合的選項。品牌也可以用其攝影機販售時使用的其他名稱找到。

  4. 點選連線方式。

    確認：表單的連線方式列顯示所選的方式，區塊下方附有說明。選擇清單中的品牌或 RTSP 時，表單增加含攝影機與路徑欄位的區塊；選擇某一設備系列的專用協定時，兩個連接埠欄位改為設備連接埠。使用 HTTPS只在自動偵測與ONVIF時提供。

  5. 設備不使用預設連接埠時，修改連接埠欄位。

    確認：欄位顯示設備實際使用的連接埠。

各選項：

  • 自動偵測（預設）：Cam Hub 自行找出連接埠與協定，見「不選品牌直接加入」。
  • ONVIF：略過偵測，只在HTTP 連接埠所填的連接埠上使用開放的 ONVIF 協定。適用於自動偵測找不到的攝影機，或想在同時支援原廠協定的設備上改用 ONVIF。設備上須已開啟 ONVIF；設備有獨立的 ONVIF 使用者清單時，須在其中新增使用者。錄影回放與 PTZ 控制是否可用，取決於設備是否提供。
  • RTSP：以純 RTSP 連線任何品牌的攝影機，並嘗試多數攝影機使用的串流路徑。都無法連線時，填入攝影機說明書或網頁上標示的路徑。
  • 某一設備系列的專用協定：在設備連接埠上以該協定連線；除非已更改或轉送，連接埠為 34567。適用於自動偵測找不到的錄影主機，或從區域網路之外連入的主機。位址在區域網路之外時，表單以橘色顯示警告：此協定不會加密影像，許多設備對密碼的保護也很薄弱。要用什麼方式從外部連線（例如透過 VPN），由您自行決定。該設備系列的名稱見「連線方式」。
  • 清單中的品牌：依該品牌文件所載的串流路徑，直接以 RTSP 連線。適用於設備已關閉 ONVIF，或要加入只提供 RTSP 的錄影主機。增加的區塊有兩個欄位：
    • 攝影機：可填 1 到 64。填 1 時加入為獨立攝影機；填 2 以上時加入為錄影主機，並占用錄影主機額度。網段掃描得知通道數量時，會自動帶入。
    • 路徑欄位：留白時，Cam Hub 依序嘗試該品牌文件所載的路徑，並保留設備有回應的路徑。欄位中顯示的是第一條嘗試的路徑。只有需要指定特定路徑時才填寫。

Cam Hub 內建原廠通訊協定的品牌不在清單中，由自動偵測找到，清單下方的說明也指出這點。部分品牌須先在設備原廠的 App 或網頁介面建立專用的攝影機或 ONVIF 帳號，RTSP 才能連線；只使用管理員帳號可能被拒絕。部分品牌的路徑會因型號或韌體而異，第一次嘗試不一定符合。表單會在路徑欄位下方顯示這些說明。品牌清單與各品牌的注意事項，見「清單中的品牌」。

以 RTSP 或清單中的品牌連線時只提供即時影像

這些連線方式沒有錄影回放、PTZ 控制與快照。設備提供該品牌的第二路串流時，SD 使用該串流；否則 SD 與 HD 顯示同一路串流。

設備控制使用 HTTP，開啟 HTTPS 時除外

設備控制（辨識設備、讀取通道清單、搜尋錄影）使用 http://位址:連接埠，該設備開啟 HTTPS 時則改用 HTTPS；使用專用協定的設備系列則改用該協定。只接受 HTTPS 的設備，以使用 HTTPS加入，見「透過 HTTPS 加入設備」。

以 RTSP 或清單中的品牌連線時，失敗訊息不同

連不上或逾時時，只會顯示發生錯誤。請再試一次。這些連線方式的不支援的設備。表示所有候選路徑都沒有串流，常見原因是 RTSP 連接埠錯誤，或設備的串流功能已關閉。

不確定設備能否使用時，點選表單中的相容性參考，查看支援與不支援的設備。表單是從已辨識出品牌的掃描結果開啟，且位址未經修改時，不會顯示此項目，也不會顯示加入範例攝影機。

透過 HTTPS 加入設備

網頁使用 HTTPS 的設備可以透過 HTTPS 加入，關閉了一般 HTTP 的設備也可以。HTTPS 預設關閉，而且只在自動偵測與ONVIF時提供：某一設備系列的專用協定、RTSP 與清單中的品牌，沒有需要 HTTPS 保護的網頁介面。已加入的設備改在設備頁切換為 HTTPS，見「已儲存設備的 HTTPS」。

  1. 在新增設備表單中輸入位址、使用者名稱與密碼，再點選進階。

    確認：區塊中顯示使用 HTTPS開關，目前為關閉。

  2. 開啟使用 HTTPS。

    確認：出現HTTPS 連接埠欄位，內容為 443；區塊下方出現這個選項的說明。

  3. 設備使用其他 HTTPS 連接埠時，在HTTPS 連接埠輸入該連接埠。

    確認：欄位顯示該連接埠。維持 443 時，Cam Hub 也會在 5001 與 8443 尋找；填入其他連接埠時只使用該連接埠。

  4. 點選右上角的新增。

    確認：表單顯示正在連線到設備…。連線成功後表單關閉，新設備出現在設備清單中；其設備頁的資訊卡片顯示HTTPS列與連接埠。

  • 說明文字為僅適用於網頁使用 HTTPS 的設備；不確定的話請保持關閉。Cam Hub 會在這個連接埠尋找 HTTPS（維持 443 時，也會試 5001 和 8443），並信任設備現在出示的憑證。之後可以在設備頁面的「HTTPS」中查看。開關開啟期間，即使收合進階，說明仍會顯示。
  • 尋找 HTTPS 時不會送出使用者名稱與密碼：Cam Hub 只檢查哪些連接埠會出示憑證。沒有任何連接埠出示憑證時，表單顯示這台設備剛才沒有透過 HTTPS 回應。有多個連接埠出示憑證時會逐一嘗試，轉送到其他設備的連接埠不會讓加入就此中止。
  • 信任的是加入時設備出示的憑證。之後可以與設備自己網頁的憑證比對，見「已儲存設備的 HTTPS」。
  • HTTPS 加密的是設備控制。透過 RTSP 取得的影像不會因此加密。

加入 YouTube 直播與 Twitch 頻道

YouTube 直播或 Twitch 頻道可以加入設備清單，像攝影機一樣顯示。影像由該服務自己的播放器播放，不需要帳號，也一律不計入方案額度。這類串流沒有錄影、PTZ 控制與快照。串流可在 iPhone 與 iPad 上播放；Apple TV 只顯示名稱。YouTube 與 Twitch 在部分國家或地區不提供服務，這時不會出現這兩個選項。

設備報告（實驗性功能）

實驗性功能，不保證支援

設備報告是實驗性功能，可能隨時變更或移除。寄出報告不代表開發者會為該設備加入支援，也不保證回覆、修正或訂出時程。部分設備在設計上即無法支援，例如通訊協定封閉或專有、僅限雲端連線、受授權或加密限制，或有硬體限制。此功能不是客戶支援或緊急求助的管道。

蒐集資訊時會以輸入的帳號與密碼登入設備。登入失敗的次數由設備累計，也可能被設備記錄。密碼可能有誤時，請先依「加入失敗時的檢查清單」修正，不要反覆嘗試。

只有在加入失敗後，檢查清單下方才會出現將詳細資訊傳送給開發者，並附有實驗性標示；加入成功時不會出現。此功能僅在點選後執行：以唯讀請求檢查設備，整理成一份文字報告，由您檢視。Cam Hub 不會自動上傳報告，只有在您選擇以自己的郵件帳號寄出時，報告才會送出。

  1. 在加入失敗的表單中向下捲動到檢查清單，點選清單下方的將詳細資訊傳送給開發者。

    確認：報告區塊中的文字隨即更新。

    確認：報告為純文字，內容一律為英文。被自動遮蓋的資料以遮蓋標記取代。

登入行為

蒐集時，需要登入的請求一次只送出一個，直到設備表示接受或拒絕帳號密碼。設備拒絕之後，報告不再送出任何登入。導致報告的加入失敗本身就是登入被拒絕時（使用者名稱或密碼錯誤。），報告完全不會再嘗試登入，以免帳號被設備鎖定。開啟使用 HTTPS時，報告會先在不登入的情況下尋找設備的憑證，再以該憑證透過 HTTPS 重做一次加入；設備沒有出示憑證時，報告不會登入。蒐集只送出唯讀請求，不會變更設備上的任何設定。

報告包含與不包含的內容

  • 包含：App 與系統的版本、手機的機型代號、語言設定、所選的連線方式（開啟使用 HTTPS時連同 HTTPS 連接埠）、設備位址（私人網路位址的最後一段以 x 遮蓋，公開位址只標示類別）、連接埠、加入失敗的錯誤代碼、偵測到的廠牌與型號、開放的連接埠、設備回應的標頭與結構（已遮蓋）、串流的編碼與參數、時鐘與時區的差異，以及各檢查步驟與結果。
  • 不包含：密碼、使用者名稱、您為設備取的名稱、公開位址與動態網域名稱、網卡的實體位址、電子郵件位址、權杖與識別用的資料、影像與畫面。長序號只保留最後四個字元。
  • 遮蓋是自動進行的，每處遮蓋都留有標記。寄出前仍請檢視報告，並可關閉任一項目。
郵件內的問題

郵件內文附有數個問題，包括設備標籤上印的廠牌與型號、韌體版本、設備種類、預期與實際結果的差異、原廠 App 或媒體播放器能否顯示該設備，以及可在媒體播放器開啟的 RTSP 位址（須先移除使用者名稱、密碼與位址）。回答這些問題有助於開發者判斷。

已儲存的報告

每份報告都會儲存在這台裝置上，保留最近的五份。失敗訊息下方會出現一個顯示儲存日期的上一份報告項目，點選後可再次開啟。已儲存的報告顯示儲存當時的內容，無法逐項開關；需要重新選擇內容時，須重新蒐集。

刪除已儲存的報告：

  1. 在報告頁面的底部點選刪除已儲存的報告。

    確認：畫面顯示對話框要刪除所有已儲存的報告嗎？，說明此操作會刪除儲存在此裝置上的所有設備報告，已透過電子郵件寄出的報告不受影響。

  2. 點選對話框中的刪除已儲存的報告。

    確認：所有已儲存的報告已刪除。目前畫面上的報告只顯示在螢幕上，不會再次儲存。

以網段掃描尋找設備

位置：底部的工具分頁。

不知道設備的 IP 位址時，可使用工具分頁掃描網段。掃描會探測 80、554、2020、8000、34567 與 37777 六個連接埠，列出有回應的位址。接著透過許多攝影機與錄影主機不需登入即可回應的探索方式，詢問找到的設備身分。回應了詢問、但連接埠探測沒有找到的設備，也會加入清單。

  1. 點選底部的工具分頁。

    確認：子網路區塊的本機列顯示目前的網路位址與遮罩，例如 192.168.1.10/24。位址欄位與範圍已帶入目前所在的網段。

  2. 選用：要掃描其他網段時，在位址欄位輸入網段，例如 192.168.1.0，並在範圍選單選擇範圍。

    確認：欄位下方顯示將掃描的網段與主機數，例如將掃描 192.168.1.0/24 · 254 個位址。

  3. 點選掃描。

    確認：畫面顯示進度已掃描 120 / 254，按鈕變為停止。

  4. 等待掃描結束；需要提前結束時，點選停止。

    確認：找到的設備列出有回應的位址，每列右側以標籤顯示該位址開放的連接埠。詢問設備身分期間顯示正在辨識設備…；之後，有設備回應的列會顯示其名稱或型號、廠牌與型號、錄影主機的通道數量，尚需開通的設備則顯示尚未開通。沒有結果時，顯示尚未找到設備。

  5. 點選結果中的一列。

    確認：畫面開啟新增設備表單，IP 位址或主機名稱欄位已帶入該位址，並帶入設備回報的資訊；接續「新增設備表單」的步驟。

  • 除了位址，表單也會帶入設備回報的內容：名稱或型號作為名稱、管理服務的連接埠作為HTTP 連接埠，以及清單中品牌的通道數量作為攝影機。使用專用協定的設備系列，其連接埠不是預設值時，會選好該連線方式與設備連接埠，並展開進階。
  • 掃描回報設備尚未開通時，表單最上方會先顯示須先開通的說明，見「開通新設備」。
  • 範圍從 /26（最小）到 /16（最大）。超過 1,024 個位址時，掃描會均勻取樣，不逐一探測。
  • 位址欄位或範圍與目前所在的網段不同時，會出現使用我的子網路，點選後恢復為目前的網段。
  • 位址欄位格式不正確時，畫面顯示輸入子網路，例如 192.168.1 或 192.168.1.0。
  • 新增完成後，畫面回到工具分頁，而不是設備清單。
掃描結果的限制

掃描只能找出在攝影機連接埠回應，或回應探索詢問的設備。沒有表明身分的設備可能是攝影機，也可能是錄影主機，類型須在新增時確認。開放的連接埠與伺服器名稱可作為判斷廠牌的線索。

掃描完整結束卻沒有任何結果時，畫面顯示如果攝影機就在這個網路裡，請到系統的隱私權設定，確認已允許 Cam Hub 尋找區域網路上的設備。本地網路權限遭拒絕時，掃描不會顯示錯誤，結果同樣是空的。請確認權限已開啟：設定 › 隱私權與安全性 › 本地網路 › Cam Hub。
