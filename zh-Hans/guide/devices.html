4设备标签页与通道

设备标签页列出所有已添加的录像机和摄像头。打开某台设备后，其通道以实时缩略图显示。在这里可以重命名、停用、暂停通道，或以全屏墙显示，可以更改设备的用户名和密码，还可以检查受支持设备的磁盘。套餐的上限决定哪些通道能显示画面。

设备列表

路径：屏幕底部的设备标签页。

每一行显示设备的名称、型号和地址。左侧的图标标明是录像机还是摄像头。右侧的连接指示器位于类型标签之上，类型标签为录像机或摄像头。指示器反映设备的 HTTP 端口是否接受连接；为设备开启 HTTPS 后，则反映其 HTTPS 端口（参见“已保存设备的 HTTPS”）。每次该行出现在屏幕上时都会开始检测，并等待响应约 4 秒。

指示器含义
旋转的小圆圈正在检测。
绿色 Wi-Fi 符号设备有响应（可连接）。
带斜线的红色 Wi-Fi 符号设备没有响应（无法连接此设备——请检查网络或防火墙）。设备可能已关机、位于其他网络，或被防火墙拦截。
指示器只检测一个端口

设备不接受所检测端口上的连接时，即使视频正常，也可能显示红色符号，例如通过列表中的品牌添加的摄像头。示例摄像头使用地址 demo，它不是网络上的设备，因此始终显示红色符号。

右上角的加号按钮会打开一个菜单。添加设备用于添加录像机或摄像头，参见第 3 章“添加设备”。

打开设备

  1. 点击屏幕底部的设备标签页。

    确认：屏幕显示设备列表。尚未添加设备时，屏幕显示没有设备、文字添加您的第一个摄像头或录像机即可开始。和添加设备按钮，参见第 3 章“添加设备”。

  2. 点击列表中的一行。

    确认：打开设备页，参见“设备页”。

调整设备的顺序

  1. 点击左上角的编辑。该按钮仅在至少存在一台设备时显示。

    确认：每一行右侧出现拖动手柄，按钮变为完成。

  2. 按住某一行的手柄，把该行拖到新的位置。

    确认：该行停留在新的位置。

  3. 点击完成。

    确认：列表退出编辑模式，顺序已保存。实时标签页中的设备选择列表使用相同的顺序。

删除设备

删除会把设备从 Cam Hub 中移除，设备本身不受影响。

  1. 在设备所在的行上向左滑动。

    确认：该行右侧出现带垃圾桶符号的删除按钮。即使一直滑到底，也只会打开确认对话框；未经确认不会删除任何内容。

  2. 点击删除。

    确认：出现标题为要删除这台设备吗？的对话框，其中写明设备名称和摄像头数量，并说明此操作无法撤销。该设备保存有密码时，对话框还会说明密码将被一并删除。

  3. 点击对话框中的删除。要保留设备，改为点击对话框以外的任意位置。

    确认：该行消失。设备、其通道、已保存的密码、SNMP 设置、磁盘读数，以及从该设备下载为文件的录像（参见“录像播放期间”）从这台 iPhone 或 iPad 上移除。该设备也会从 LiveView Mix 墙中移除；如果它曾被选为实时标签页的设备或启动时打开的目标，这些选项也会随之清除。

已删除的录像机不再计入套餐允许的录像机数量，参见“套餐上限与启用通道”。要重新添加该设备，参见第 3 章“添加设备”。

设备页

设备页顶部是一张信息卡片，支持的设备在其下方有磁盘健康一行，再往下是标题摄像头，以缩略图显示设备的各个通道。页面标题为设备名称。缩略图按屏幕能容纳的列数排列。

  • 信息卡片：显示设备的名称和类型，以及型号、IP 地址、端口（HTTP 端口）、HTTPS（HTTPS 端口，仅在开启 HTTPS 时显示）、序列号、固件和摄像头（通道数量）各行。序列号和固件仅在设备上报时才会显示。
  • 磁盘健康：打开设备的磁盘报告，参见“磁盘健康”。该行右侧的橙色三角形或红色符号表示上一次读数中最差的磁盘判定结果。
  • 缩略图：录像机的每个通道显示一个缩略图；单独的摄像头只有一个通道，显示一个缩略图。每个缩略图的左下角显示通道的编号和名称。缩略图使用 SD 还是 HD，取决于设置 › 默认画质 › 多个摄像头（未更改时为 SD）。在“设置”中所做的更改会立即作用于此页；此页自身没有 SD/HD 按钮。
  • 刷新：打开设备页时（同一台设备每分钟最多一次），以及每次下拉页面时，Cam Hub 会从设备读取通道列表。名称和在线状态会更新，设备新增的通道会出现，设备移除的通道会消失。新通道仅在套餐还有空余名额时才会启用，有信号的通道优先获得空余名额（参见“套餐上限与启用通道”）；没有获得名额的新通道显示为已停用。原已列出的通道保持原来的启用或停用状态，在 Cam Hub 中设置的名称也会保留。设备没有响应，或返回的列表看起来不完整（一个通道都没有，或本应有多个通道却只有一个）时，列表保持原样，也不显示任何提示。
  • 登录被拒绝：刷新时设备拒绝已保存的用户名或密码，缩略图上方会出现提示用户名或密码错误。和编辑凭据按钮，参见“更改设备的用户名和密码”。
  • 没有保存密码：这台 iPhone 或 iPad 上没有保存该设备的密码时，缩略图上方会出现一条提示，带有重新输入密码和从 iCloud 恢复按钮，参见“没有保存密码的设备”。
  • 没有通道：设备没有上报任何通道时，页面显示未找到摄像头。和刷新按钮，点击该按钮会重新读取通道列表。

右上角的三个按钮从左到右依次为：黑边按钮、全屏墙和铅笔按钮。对于用用户名和密码登录的设备，铅笔按钮（编辑设备）会打开一个菜单，其中有重命名和编辑凭据；设备提供 HTTPS 或已开启 HTTPS 时，还有 HTTPS，参见“已保存设备的 HTTPS”。对于示例摄像头，铅笔按钮本身就是重命名按钮。

像书一样持握 iPhone Duo

iPhone Duo 半折叠、折痕从上到下贯穿屏幕时，设备页在一半屏幕上显示缩略图，在另一半显示某个摄像头的页面。点击缩略图会在另一半显示该摄像头，而不是打开新页面；起初显示的是第一个能显示画面的摄像头。参见“iPhone Duo 折叠时的视图”。

隐藏或显示详情

  1. 点击信息卡片右侧的箭头（隐藏详情）。

    确认：名称下方的各行消失，箭头改变方向（显示详情）。再次点击可重新显示这些行。该选择按设备分别保存。

重命名设备

  1. 点击设备页右上角的铅笔按钮。

    确认：对于用用户名和密码登录的设备，会打开一个菜单，其中有重命名、编辑凭据，以及在提供时出现的 HTTPS。对于其他设备，会直接打开下一步中的对话框。

  2. 显示菜单时，点击重命名。

    确认：打开对话框重命名设备，名称输入框中是当前名称，对话框中还有文字给此设备起一个您能认出的名称。

  3. 在名称输入框中输入新名称。

    确认：输入框显示新名称。

  4. 点击保存。

    确认：页面标题和设备列表显示新名称。空名称会被忽略，仍保留旧名称。名称只保存在 Cam Hub 中，设备本身不会更改。

更改此页对黑边的处理方式

黑边按钮是三个按钮中最左边的一个。每点击一次，切换到三种模式中的下一种；第三种之后回到第一种。

模式效果
默认显示完整画面。画面的形状与缩略图的形状不同时，会出现黑边。
放大填满画面按比例放大，直到填满缩略图。画面边缘会被裁掉。
拉伸填满画面被拉伸，直到填满缩略图。画面会变形。

  1. 点击右上角三个按钮中最左边的一个。

    确认：所有缩略图切换到下一种模式，按钮图标随当前模式变化。

第一种模式取自设置 › 画面 › 黑边。在此页所做的更改只作用于此页，不会保存。

更改设备的用户名和密码

在设备本身上更改了密码之后，例如由安装人员更改或设备重置之后，Cam Hub 就无法再登录，缩略图显示用户名或密码错误。编辑凭据可为同一台设备保存新的用户名和密码。摄像头、摄像头的名称、启用和暂停的选择以及在 LiveView Mix 墙上的位置都保持不变；而删除设备后重新添加会丢失这些内容。

所有用用户名和密码登录的设备都提供编辑凭据。示例摄像头不提供此项。设备的地址和端口不在此处更改。

  1. 打开该设备的设备页。

    确认：显示设备页。上一次刷新被拒绝时，缩略图上方会出现提示用户名或密码错误。和编辑凭据按钮；该按钮打开的界面与第 3 步相同。

  2. 点击右上角的铅笔按钮（编辑设备）。

    确认：打开一个菜单，其中有重命名和编辑凭据；对于提供 HTTPS 的设备，其后还有 HTTPS。

  3. 点击编辑凭据。

    确认：打开编辑凭据界面。其分区以设备名称为标题，包含已填入当前用户名的用户名，以及空白的密码输入框，光标位于该输入框中。输入框下方的说明为新凭据会先在设备上验证，通过后才会保存。设备的摄像头、它们的名称以及您的 LiveView Mix 墙面都会保持不变。

  4. 用户名也已更改时，在用户名中更正。

    确认：输入框显示用户名。用户名为空时，保存不可用。

  5. 在密码中输入新密码。

    确认：输入框中每个字符显示为一个圆点。与添加设备时一样，可以接受空密码。

  6. 点击保存。

    确认：Cam Hub 用新凭据登录设备一次并读取其通道列表，在此期间保存处显示转圈。设备接受新凭据时，界面关闭，缩略图用新凭据重新连接，通道列表也会刷新。设备不接受时，界面保持打开，不保存任何内容，并以红色显示原因，例如用户名或密码错误。或无法连接设备。请检查地址和您的网络。

点击取消可关闭界面而不保存；仍在进行的验证会停止，不会更改任何内容。新用户名不能与同一地址和端口上另一台已保存设备所用的用户名相同；出现这种情况时，界面显示此地址上的另一台设备已在使用该用户名。

每台设备只登录一次

许多录像机和 NAS 在几次登录失败后会锁定账号或 iPhone、iPad 的地址，这种锁定也会影响其他 App。因此，Cam Hub 验证新凭据时，只通过添加设备时所用的连接方式登录一次，而不会尝试多种连接方式。对大多数设备而言，墙上的缩略图也是整台设备只登录一次：设备拒绝登录时，该设备的所有缩略图会同时显示失败，Cam Hub 约一分钟后或回到前台时才会再次尝试相同的凭据。保存新凭据后会立即重新开始。

没有保存密码的设备

Cam Hub 将每台设备的密码保存在 iPhone 或 iPad 的钥匙串中。iPhone 或 iPad 的内容迁移到新机时，密码可以一同迁移；Cam Hub 的 iCloud 备份和共享代码包含制作它的 iPhone 或 iPad 上保存的每一个密码（参见“备份和代码包含的内容”）。设备列表已迁移而密码没有随之迁移时（例如新 iPhone、iPad 或 Mac 在设置时没有带上旧机的钥匙串），会出现下面的状态。此时 Cam Hub 不会向设备发送任何内容：既不会用空密码登录，也不会报告密码错误。

  1. 打开该设备的设备页。

    确认：缩略图上方显示此 iPhone、iPad 或 Mac 上没有保存这台设备的密码，换用新机后可能会出现这种情况。请重新输入，或从 iCloud 备份恢复。以及重新输入密码和从 iCloud 恢复按钮。缩略图显示没有保存密码，请到“设备”重新输入。

  2. 点击重新输入密码输入这台设备的密码，或点击从 iCloud 恢复从 iCloud 备份中恢复所有设备的密码。

    确认：重新输入密码打开编辑凭据界面，如“更改设备的用户名和密码”所述。从 iCloud 恢复打开“从 iCloud 恢复”中所述的页面。

密码保存或恢复后，提示消失，缩略图重新连接。恢复会一次找回所有设备的密码；没有备份时，需要逐台设备输入。

已保存设备的 HTTPS

网页界面提供 HTTPS 的设备，可以改用 HTTPS 代替普通 HTTP 进行控制。HTTPS 默认关闭，需要为设备单独开启。使用 HTTPS 时，Cam Hub 只接受开启 HTTPS 时所信任的证书，或公共证书颁发机构为设备地址签发的证书，因此这类证书自动续期后仍可正常连接。通过 RTSP 获取的视频不会因此设置而加密。

对于曾通过 HTTPS 响应的设备，以及已开启 HTTPS 的设备，铅笔菜单中提供 HTTPS。Cam Hub 检查时不登录设备，只确认是否有端口出示证书。检查结果会被记住：设备有响应时保留一周，没有响应时保留一天；下拉设备页会立即重新检查。Apple TV 上无法下拉，没有响应的设备会在超过一小时后再次打开其设备页时重新检查。通过某一设备系列的自有协议、RTSP 或列表中的品牌连接的设备不提供此项，示例摄像头也不提供。

开启 HTTPS

  1. 在设备页上，点击右上角的铅笔按钮（编辑设备），然后点击 HTTPS。

    确认：打开 HTTPS 界面，其分区以设备名称为标题。Cam Hub 检查设备期间显示正在检查 HTTPS…；随后显示端口（设备响应的端口）和证书（SHA-256）（设备当前出示的证书的指纹，分四行显示）。

  2. 尽可能将指纹与设备自身网页的证书进行核对，例如在浏览器的证书详细信息中查看。

    确认：两个指纹完全相同。不一致时，通信中间可能插入了另一台设备；请保持 HTTPS 关闭。

  3. 开启使用 HTTPS，然后点击保存。

    确认：Cam Hub 用已保存的凭据通过 HTTPS 登录设备并读取其通道列表，在此期间保存处显示转圈。成功时，界面关闭，缩略图重新连接，信息卡片中显示 HTTPS 一行及端口。不成功时，界面保持打开，不保存任何内容，并以红色显示原因。

  • 设备没有通过 HTTPS 响应时，界面以橙色显示这台设备刚才没有通过 HTTPS 响应。此时开关无法开启。
  • 该分区下方的说明为除非您开启，否则保持关闭。开启 HTTPS 后，Cam Hub 与这台设备之间的通信会加密，并且只接受此处显示的证书，或公共证书颁发机构为此地址签发的证书（因此证书自动续期后仍可连接）；如有可能，请与设备自身网页上显示的证书核对。通过 RTSP 传输的视频不会因此设置而加密。
  • 关闭 HTTPS：关闭使用 HTTPS并点击保存。Cam Hub 会先确认设备能以已保存的凭据通过普通 HTTP 响应。不能时，不做任何更改，界面显示这台设备没有通过普通 HTTP 响应，因此 HTTPS 保持开启。关闭 HTTPS 会清除所信任的证书，因此再次开启时会重新检查证书。
  • 证书已更改：设备出示的证书与所信任的证书不同，且不是公共证书颁发机构为该地址签发的证书时，Cam Hub 不会连接，缩略图显示这台设备的安全证书已更改。请在设备编辑菜单的“HTTPS”中检查。此时 HTTPS 界面显示新的指纹，并附有这台设备当前出示的证书与开启 HTTPS 时信任的证书不同。只有在您知道它为何改变时（例如设备重置后），才点击“保存”信任它。点击保存后，Cam Hub 会进行与开启 HTTPS 时相同的检查，然后信任新证书。
  • 设备在另一个 HTTPS 端口上以相同的证书响应时，界面显示新端口，保存会直接保存该端口，不显示警告。
  • HTTPS 设置连同其端口和所信任的证书，会随 iCloud 备份和共享代码一起转移，但恢复或导入绝不会关闭 HTTPS，参见“备份和代码包含的内容”。

磁盘健康

磁盘健康报告录像机或 NAS 的磁盘状态：每块磁盘是否健康、其温度以及硬盘自身的 S.M.A.R.T. 数据，以便在录像丢失之前更换即将故障的磁盘。Cam Hub 只读取这些信息，不会更改设备上的任何内容。

能够报告磁盘状态的设备，其设备页上会出现磁盘健康一行：通过支持此功能的品牌连接添加的设备（参见第 16 章“支持的品牌与连接方式”），以及通过 SNMP 提供磁盘健康信息的 NAS。通过 ONVIF 或视频流地址添加的设备以及示例摄像头不显示该行。

打开磁盘健康

  1. 打开录像机或 NAS 的设备页。

    确认：信息卡片下方出现磁盘健康一行。右侧的橙色三角形表示上一次读数时有磁盘需要留意；红色符号表示有磁盘即将故障。

  2. 点击磁盘健康。

    确认：打开磁盘健康页面并读取设备。对于尚未进行 SNMP 设置的 NAS，页面显示此 NAS 通过 SNMP 提供磁盘健康信息。设置一次即可查看 S.M.A.R.T. 数据、温度和存储空间的状态。和设置 SNMP按钮，参见下文的“在 NAS 上设置 SNMP”。无法读取设备时，页面显示原因和重试，NAS 还会显示SNMP 设置。

  3. 下拉页面以重新读取设备。

    确认：页面显示新的读数。新的读取失败时，页面上保留上一次的读数，其上方显示原因和说明正在显示上一次的读数。下拉即可重试。

在 NAS 上设置 SNMP

NAS 通过 SNMP 报告其磁盘。SNMP 是一种只读服务，会应答任何知道其团体名称的人。请先在 NAS 的管理界面中打开 SNMP：启用 SNMP 服务，选择 SNMPv1/v2c，并设置团体名称。iPhone 或 iPad 必须能通过 SNMP 端口访问 NAS，通常需要位于同一本地网络中。仅设为 SNMPv3 的 NAS 不受支持。SNMP 设置界面上的说明写明了 NAS 上打开 SNMP 的菜单。

  1. 在 NAS 的磁盘健康页面上，点击设置 SNMP。已有设置时，改为点击SNMP 设置（右上角的齿轮）。

    确认：打开SNMP 设置界面，其中有团体名称（首次打开时为 public）和端口（161）两个输入框，以及关于在哪里打开 SNMP 的说明。

  2. 在团体名称中输入 NAS 上设置的团体名称。

    确认：输入框显示团体名称。

  3. 仅当 NAS 在 161 以外的端口上应答 SNMP 时，才更改端口。

    确认：输入框显示端口。

  4. 点击保存。

    确认：界面关闭，磁盘健康读取 NAS。有输入框为空或端口不在 1 到 65535 之间时，界面保持打开并显示请输入团体名称和 1 到 65535 之间的端口。NAS 没有应答时，页面会说明这一点，写明询问所用的端口，并请您检查 SNMP 是否已打开、团体名称是否一致；端口被拦截也会出现同样的结果。NAS 不会应答它不认识的团体名称，因此名称错误与 NAS 无法访问看起来是一样的。

用自动检测添加的 NAS 尚无 SNMP 设置时，添加完成后会立即打开同一界面，作为可选步骤：保存保存设置，以后再说关闭界面。无论选择哪一项，设备都已添加，之后也可以从磁盘健康设置 SNMP，参见第 3 章“添加设备”。

SNMP 设置按设备保存在 iPhone 或 iPad 的钥匙串中，并随设备一起删除。它们包含在共享代码和 iCloud 备份中，因此导入或恢复之后，磁盘健康无需重新设置即可使用，参见第 10 章“共享与备份”。

摄像头套餐已启用的摄像头数量不超过套餐的上限：8、16 或不限。与免费版相同：2 个已启用的通道，且都在同一台录像机上。1

  • 两种套餐可以同时持有。两项上限各自独立生效：摄像头套餐提高单独摄像头的上限，NVR 套餐提高所有通道均可使用的录像机数量。
  • 显示中的 LiveView Mix 页面上的每个控制面板，都按一个摄像头计入摄像头上限。真实的摄像头优先保留画面；超出上限的控制面板显示不在您的套餐内。参见第 8 章“LiveView Mix”。
  • 录像机一经添加就计入录像机数量，无论其通道是否已启用。示例摄像头与真实设备一样计入。
  • 添加设备时，以及每次重新读取的通道列表中出现新通道时，套餐的空余名额按以下顺序分配给新通道：先是设备报告有信号的通道，然后是没有信号的通道，两组各按设备列出的顺序排列。没有获得名额的新通道显示为已停用。原已列出的通道保持原来的启用或停用状态。示例：在免费版中，没有其他已启用的通道时，一台通道 1 和 2 没有信号、通道 3 和 4 有信号的录像机，添加后通道 3 和 4 为启用状态；通道 1 和 2 显示为已停用。
  • 套餐到期，或套餐上限低于已启用的通道数量时，已保存的选择会保留。超出上限的通道显示不在您的套餐内：单独的摄像头优先保留画面，其次是录像机的通道，各自按设备的添加顺序和通道编号的顺序排列。
  • 两项上限均为不限时，所有通道自动启用，不提供选择要显示的摄像头页面。

启用已停用的通道

前提条件：通道的缩略图显示已停用。

  1. 长按已停用通道的缩略图。

    确认：菜单中您的套餐下方显示启用。点击已停用的缩略图同样会提供启用。

  2. 点击启用。

    确认：套餐还有空余名额时，缩略图开始显示实时画面，操作到此结束。已达到上限时，会打开套餐界面并显示提示，该通道保持停用。对于单独的摄像头，免费版中的提示为您已达到免费版 2 个已启用摄像头的上限。持有套餐时的提示为您已达到当前套餐 8 个已启用摄像头的上限。（数字为该套餐的摄像头上限）。对于录像机的通道，提示为订阅 NVR 套餐即可解锁所有通道。

  3. 关闭套餐界面。

    确认：重新显示设备页。

  4. 长按不需要的已启用通道的缩略图。

    确认：打开该通道的菜单。

  5. 点击停用。

    确认：缩略图显示已停用，其套餐名额已空出。

  6. 对要显示的通道重复前两步。

    确认：缩略图显示实时画面。

选择要显示的摄像头

路径：设置 › 选择要显示的摄像头

此页面把所有设备的通道集中列在一处，无需逐个打开设备页，即可跨设备分配套餐名额。仅当套餐的两项上限中至少有一项生效时，才提供此项。

  1. 点击屏幕底部的设置标签页。

    确认：屏幕显示设置。

  2. 在订阅部分，点击选择要显示的摄像头。

    确认：打开选择要显示的摄像头页面。您的套餐部分显示摄像头（例如 2 个摄像头或无限）和录像机两行，以及提示打开您想观看的摄像头。免费版可显示同一台录像机上的 2 个摄像头。其下是每台设备一个分区，列出每个通道的编号、名称和开关。

  3. 关闭不需要的通道的开关。

    确认：开关关闭。该通道被停用，其套餐名额空出。关闭开关始终可以执行。

  4. 打开要显示的通道的开关。

    确认：套餐有空余名额时，开关打开。没有空余名额时，会打开套餐界面并显示提示，开关保持关闭。在免费版中，打开第二台录像机的通道时，会出现在免费版中，您显示的摄像头必须全部连接在同一台录像机上。

  5. 点击左上角的返回按钮，离开此页。

    确认：所选内容在各处生效：墙和设备页只为套餐范围内已启用的通道显示画面。

尚未添加任何设备时，页面显示没有设备、请先添加设备，然后在此选择它的摄像头。和添加设备按钮。

设备的全屏墙

全屏墙把一台设备所有已启用的通道铺满屏幕显示。它可从设备页和实时标签页打开（参见“全屏墙”），并随 iPhone 的持握方向变化：竖屏时，缩略图保持 16:9 的形状，每行排一个或两个（参见下方的布局按钮）；横屏时，两行占满屏幕高度。只有一个已启用通道的设备，其摄像头占满整个屏幕。

  1. 点击设备页右上角的全屏墙按钮（三个按钮中的第二个）。

    确认：墙覆盖整个屏幕，显示设备已启用的通道；超出套餐的通道显示不在您的套餐内。没有已启用的通道时，屏幕显示没有已启用的摄像头和在设备页面上启用摄像头。

  2. 通道多于屏幕所能容纳的数量时，竖屏下上下滚动墙，横屏下左右滑动。

    确认：显示后续的通道或下一页。墙分页时，底部的圆点指示当前页。

  3. 点击显示画面的缩略图。

    确认：该摄像头的特写在墙上方打开，顶部显示返回和摄像头名称。

  4. 点击特写左上角的返回。

    确认：重新显示墙。

  5. 点击关闭（墙左上角的叉号）。

    确认：屏幕回到设备页或实时标签页。

墙顶部的按钮功能
关闭（左上角）关闭墙。
SD 或 HD一次性切换墙中的所有摄像头（将所有摄像头切换为 HD 或将所有摄像头切换为 SD）。按钮上的文字为当前画质。墙启动时使用设置 › 默认画质 › 多个摄像头的画质。更改不会保存。
布局在每行一个和每行两个缩略图之间切换。此选择会保存。
黑边按钮依次切换默认、放大填满和拉伸填满，与设备页相同。更改不会保存。
  • 特写：画面使用设置 › 默认画质 › 单个摄像头的画质（未更改时为 HD），不显示墙上的按钮。两指张开可将画面放大至 5 倍，放大后拖动可移动画面，双击可在正常大小和 2 倍之间切换。
  • 扬声器（左下角）：摄像头发送声音时出现，参见“快照、声音与画质”。
  • 摄像头控制（右下角）：摄像头可移动或变焦时出现，参见“PTZ 控制：移动摄像头”。
  • 录像（右上角）：支持回放的设备会出现。它会在墙上方打开该摄像头的单摄像头视图，右上角的完成用于返回，参见第 7 章“录像回放与倍速”。
  • 设置项画面铺满屏幕和隐藏离线摄像头适用于墙。点击显示不在您的套餐内的缩略图会打开套餐界面。

设备画面上的 SD 和 HD

SD 是较轻量的画面，HD 是较清晰的画面。使用哪一种取决于所在的画面。起始值来自设置中的默认画质。

画面起始画质在该画面上切换
设备页上的缩略图多个摄像头（未更改时为 SD）；立即跟随设置。无。
全屏墙多个摄像头。通过 SD/HD 按钮切换所有摄像头。更改不会保存。
实时标签页多个摄像头。顶部栏的 SD/HD 按钮切换所有摄像头，参见“墙上的 SD 和 HD”。
全屏墙中的特写单个摄像头（未更改时为 HD）。无。
单摄像头视图单个摄像头。设备提供两路视频流时，画面下方的 SD/HD 开关。更改不会保存，参见“快照、声音与画质”。
LiveView Mix 墙每个格子各有自己的画质选择，未更改时为 SD，在排列墙时设置。墙上摄像头的特写始终使用 HD。参见第 8 章“LiveView Mix”。
录像回放播放的是已录制的视频流，没有 SD 和 HD 之分。无。

有些设备的一个通道只提供一路视频流。对这类设备，SD 和 HD 显示相同的画面，单摄像头视图不显示 SD/HD 开关。
