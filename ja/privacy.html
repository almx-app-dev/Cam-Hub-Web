プライバシーポリシー

Cam Hub は、端末上での処理とユーザーによる管理を中心に設計されています。サービスアカウントを必要とせず、第三者による広告トラッキングも組み込んでいません。

アプリCam Hub
お問い合わせapp-dev@almx.cc

概要

Cam Hub を利用するために Cam Hub のサービスアカウントを作成する必要はなく、第三者の広告や広告トラッキングも組み込んでいません。本アプリは、ユーザーが設定したカメラとレコーダーに接続するよう設計されています。

YouTube や Twitch のライブ配信を追加した場合、それらは各サービス自身のプレーヤーで再生されます。プレーヤーは独自の広告を表示し、お使いのデバイスから情報を受け取ることがあります。詳しくは下記の「YouTube と Twitch のライブ配信」をご覧ください。

デバイス情報と認証情報

デバイス名、アドレス、ポート、ユーザー名、チャンネル情報、アプリ設定は端末に保存され、パスワードは Apple のキーチェーンに保存されます。これらはユーザーが要求した接続と操作にのみ使用されます。

接続と映像

ライブ映像や録画映像を表示するとき、アプリはユーザーが指定したデバイスのアドレスに接続します。お使いのデバイス、ネットワーク事業者、VPN 事業者、DNS 事業者、またはユーザーが選択したリモートの接続先は、それぞれのポリシーに従って接続情報を処理する場合があります。Cam Hub は、カメラの映像を広告や行動プロファイリングに使用しません。

YouTube と Twitch のライブ配信

  • YouTube のライブ配信やチャンネル、または Twitch のチャンネルを追加すると、Cam Hub はそのサービス自身の埋め込みプレーヤー（YouTube のプレーヤー〈YouTube API Services〉または Twitch のプレーヤー）で再生します。いずれかのサービスの最初の配信を再生する前に、アプリはそのサービスの規約への同意を求めます。こうした配信を追加しない場合、本項は適用されません。
  • プレーヤーは YouTube または Twitch から読み込まれ、各サービスのサーバーに直接接続します。再生中、サービスはお使いの IP アドレスとデバイスおよびブラウザの情報を受け取り、Cookie や類似の技術を使用し、再生状況を計測し、広告を表示することがあります。詳しくは下記リンクの Google プライバシー ポリシー（YouTube）または Twitch プライバシー通知（Twitch）をご覧ください。Cam Hub はプレーヤーの Cookie と保存データをアプリの実行中にのみ保持し、これらの情報を受け取ることはありません。
  • Cam Hub が保存するのは、追加されたリンクとチャンネル名だけです。保存先はお使いのデバイスで、共有コードや iCloud バックアップを作成した場合はそれらにも含まれます。アプリでその配信を削除すると、これらも削除されます。
  • Google プライバシー ポリシー
  • Twitch プライバシー通知

Webhook コントロールパネルと第三者の接続先

LiveView Mix の操作ボタンには、HTTP／HTTPS メソッド、接続先 URL、独自ヘッダー、リクエスト本文を設定できます。Authorization トークンなどの機密情報を含む場合があり、端末上の LiveView Mix 設定に保存され、ユーザーが作成する暗号化 iCloud バックアップにも含まれることがあります。

ボタンをタップしたときだけ、アプリは端末から指定先（Home Assistant、Node-RED、その他の第三者サービスなど）へ直接リクエストを送信します。接続先やネットワーク事業者は、それぞれのポリシーに基づき送信元 IP、ヘッダー、本文を処理する場合があります。Cam Hub の開発者は接続先を選択・管理せず、そこへ送信されたデータを受信しません。HTTP 通信は暗号化されないため、機密情報には HTTPS を使用し、受信先のプライバシーと安全対策を確認してください。

ローカルネットワークへのアクセスとスキャン

Cam Hub はカメラやレコーダーへ直接接続するため、ローカルネットワーク権限を求めます。「ツール」でスキャンを開始すると、選択したサブネットと一般的なカメラ用ポートを調べ、応答したデバイスのアドレス、開放ポート、HTTP Server 名を読み取って識別を補助する場合があります。

スキャンはユーザーが開始した場合にのみ実行され、結果は端末上で処理されて Cam Hub の開発者へ送信されません。

デバイスレポート（実験的）

  • カメラやレコーダーの追加に失敗した場合、Cam Hub は、開発者が原因を把握しやすくするための任意の実験的デバイスレポートを提供します。この機能は、デバイスの追加に失敗した後にのみ表示されます。「詳細情報を開発者に送る」をタップし、初回使用前に表示される注意事項に同意した場合にのみ開始され、その画面を開いている間だけ実行されます。いつでも停止できます。
  • 実行中、お使いの Apple デバイスは、入力したデバイスのアドレスへ直接、読み取り専用のリクエストを送ります。送信先は入力したポートで、ローカルネットワーク上のデバイスには一般的なカメラ用ポートも含まれます。リクエストでは、どのポートが応答するかを確認し、デバイスの型番、ファームウェア、対応プロトコル（ISAPI、ONVIF、RTSP など）を読み取り、映像ストリームのデータが届くかを短時間テストします。デバイスの設定は一切変更せず、開発者や他のサーバーへ送られるリクエストもありません。
  • これらのリクエストでは、デバイスの追加時と同様に、入力したユーザー名とパスワードでサインインします。失敗した試行自体がサインインの拒否だった場合、レポートはサインイン要求を一切送りません。失敗したサインインはデバイス側で数えられ、記録されることがあります。
  • レポートに含まれるのは、アプリのバージョン、iOS のバージョン、Apple デバイスのモデルと言語設定、選択した接続方式とアプリが表示したエラー、末尾の数字を隠したデバイスのアドレス（インターネット上のアドレスは含めません）、入力したポートと応答したポート、デバイスが自己申告するブランド・型番・ファームウェア・対応プロトコル、ステータスコードとデバイスの応答の短い抜粋、Apple デバイスの接続方法（Wi-Fi、モバイル通信、VPN など）、およびテスト用映像ストリームから得た件数とサイズです。映像そのものは含まれません。
  • 表示や保存の前に、自動フィルターがパスワード、ユーザー名、トークン、Cookie、シリアル番号、MAC アドレス、公開 IP アドレス、ホスト名、メールアドレス、デバイス名とチャンネル名、Wi-Fi ネットワーク名、電話番号、長いキーや識別子を、目に見えるプレースホルダーに置き換えます。Web ページの本文は保持しません。このフィルターは自動処理で完全ではないため、送信前にレポートをお読みください。
  • 開発者へ自動で送信されるものはありません。レポートはまず画面に表示され、セクションごとにオフにしたり、送信せずに閉じたりできます。送信するには「開発者にメールで送る」を選びます。レポートは宛先をサポート用アドレスにした「メール」の作成画面で開き、本文とテキストファイルの添付の両方に入ります。そこで「送信」を押すまでは何も送られず、取り消すこともできます。「メール」が設定されていない場合は、レポートがクリップボードにコピーされ、宛先入力済みのメッセージがメールアプリで開きます。レポートをコピーしたり、iOS の共有シートで共有したりすることもできます。
  • コピーしたレポートはユニバーサルクリップボードで他のデバイスに渡されず、120 秒後にクリップボードから消えます。
  • 最新のレポートを最大 5 件までお使いの端末に保存し、後から送信できるようにします。これらは端末のバックアップにも Cam Hub の iCloud バックアップにも含まれません。デバイスレポートの画面で「保存済みのレポートを削除」を使えば、いつでも削除できます。6 件目を保存すると最も古いものも削除され、アプリを削除するとすべて削除されます。
  • レポートをメールで送信した場合、開発者はそのメールと送信元のメールアドレスを受け取ります。レポートは、報告された問題の調査に使用され、返信と必要なサポート記録の保持に必要な期間のみ保管されます。
  • デバイスレポートは実験的な機能で、予告なく変更または削除されることがあります。レポートを送っても、お使いのデバイスへの対応、返信、修正が保証されるわけではありません。

写真とカメラ

Apple のシステム写真ピッカーで特定の写真を選ぶか、カメラへのアクセスを許可して新しい写真を撮影し、LiveView Mix の空きスロットに配置できます。アプリが取得するのは選択または撮影した画像だけで、写真ライブラリ全体を閲覧しません。画像は縮小・圧縮され、端末上の LiveView Mix 設定に保存されます。

画像は端末内に保存され、Cam Hub の開発者が受信またはアクセスすることはありません。ユーザーが Cam Hub の暗号化 iCloud バックアップを作成した場合に限り、端末の復元用として画像がご自身の iCloud に保存されることがあります。LiveView Mix で画像を削除でき、システム設定でカメラや写真の権限を変更できます。

位置情報

Cam Hub が求める位置情報の許可は「このAppの使用中のみ許可」だけです。位置情報とコンパスの方位は、それらを必要とする画面が開いている間だけ読み取ります。たとえば「ツール」タブで速度とコンパスの方位を表示するスピードメーターです。バックグラウンドで位置を追跡することはありません。

位置情報とコンパスの方位は端末上で処理され、速度と方向の表示に使われます。保存されず、バックアップにも含まれず、Cam Hub の開発者やその他の第三者へ送信されません。スピードメーターが速度を音声で読み上げる場合、その音声は端末の iOS に内蔵された音声合成で生成され、同じ画面でオフにできます。位置情報の許可は、Apple デバイスの「設定」でいつでも拒否または取り消せます。位置情報がなくても、アプリのその他の機能は使えます。

カメラ共有コード

  • 選択したカメラまたはレコーダーのアドレス、ユーザー名、チャンネル情報、パスワードを含むコードを共有できます。「アプリ設定を含める」をオンにすると、コードにはアプリ設定も含まれ、トークンを含む可能性のある Webhook 設定など、LiveView Mix の設定が入ることがあります。コードは AES-256-GCM で暗号化され、鍵は PBKDF2-HMAC-SHA256（反復 600,000 回）で導出されます。共有時に、3 種類のロック方法から 1 つを選びます。
  • ロックなし：鍵は Cam Hub に組み込まれた秘密の文字列から作られるため、互換バージョンの Cam Hub であればどれでもコードを開けます。内容がひと目で読まれることを防ぐだけで、コードとアプリの両方を持つ人からは守れません。
  • 6 桁の PIN：設定した PIN を入力した場合にのみコードを開けます。6 桁の PIN は 100 万通りしかないため、コードを入手した人が自分のコンピューターでオフラインのまま総当たりで試すことができます。
  • 複雑な暗号化（パスワード）：設定したパスワードを入力した場合にのみコードを開けます。パスワードは 8 文字以上で、文字・数字・記号を自由に使えます。長くて他に使っていないパスワードでなければ、推測を現実的に防げません。
  • Cam Hub がコード、PIN、パスワードを開発者へ送信することはなく、開発者は忘れた PIN やパスワードを復元できません。PIN やパスワードはコードとは別に伝えてください。
  • コードに自動有効期限はありません。送信元の端末からデバイスやアプリを削除しても、共有済みのコピーは無効になりません。コードが漏れた可能性がある場合は、該当するデバイスのパスワードを変更してください。
  • コードは、共有に選んだアプリがそのポリシーに従って取り扱います。Cam Hub の Web サイトへのリンクとして共有する場合、コードはリンクの「#」より後ろに含まれ、ブラウザはこの部分を Web サイトのサーバーへ送信しません。

任意の iCloud バックアップ

「iCloud バックアップ」を選択した場合、アプリは対応するカメラとレコーダーの設定、認証情報、チャンネル、アプリ設定を暗号化してから、ユーザーのプライベートな iCloud キー値ストレージにバックアップを保存します。iPhone、iPad、Apple TV でのバックアップと復元には PIN を使用しません。バックアップは、ユーザーが設定するパスワードではなくアプリに組み込まれた鍵で暗号化されるため、その保護はご利用の Apple アカウントと iCloud の保護に依存します。

バックアップの日時、デバイス数、サイト名は、アプリがバックアップの状態を表示できるよう別途保存されます。復元するには、利用可能なバックアップを選択してそのまま続行します。

購入とサブスクリプション

購入とサブスクリプションは Apple が処理します。カード情報や銀行口座の情報を当方がすべて受け取ることはありません。アプリは Apple から提供される購入状況を読み取り、対応する上限や機能を有効にします。

共有・保存・削除と選択

当方は個人情報を販売しません。ローカルの設定は、該当する内容を削除するかアプリを削除するまで端末に残ります。アプリ内でデバイス、LiveView Mix の画像、操作設定を削除でき、iCloud バックアップは個別に削除できます。システムの許可は Apple デバイスの「設定」から取り消せます。

任意の iCloud データは、ご利用の Apple アカウントと iCloud のサービスを通じて管理されます。サポートへ任意でお送りいただいた情報は、返信と必要なサポート記録の保持に必要な期間のみ保管します。

お子様と本ポリシーの変更

Cam Hub はお子様に向けたものではなく、お子様の個人情報を意図的に収集することはありません。機能、法令、ストアの要件が変わった場合、本ポリシーを更新することがあります。改定日は本ページに掲載します。

ウェブサイトの統計

このウェブサイト（Cam Hub アプリではありません）は、Cloudflare, Inc. が提供する Cloudflare Web Analytics で訪問数を集計しています。Cookie は設定せず、ローカルストレージも使用せず、他のサイトをまたいで追跡することも、個人のプロファイルを作成することもありません。集計するのは、ページごとの閲覧数、参照元サイト、国または地域、ブラウザとデバイスの種類です。ブラウザが「トラッキング拒否」（Do Not Track）または Global Privacy Control を送信している場合は読み込まれません。Cam Hub アプリ自体には分析機能は含まれていません。
