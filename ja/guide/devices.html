4デバイスタブとチャンネル

デバイスタブには、追加したすべてのレコーダーとカメラが、カメラとして追加した YouTube と Twitch の配信とともに一覧表示されます。デバイスを開くと、そのチャンネルがライブのサムネイルで表示されます。ここからチャンネルの名前の変更、無効化、一時停止、フルスクリーンウォールでの表示ができるほか、デバイスのユーザー名とパスワードを変更したり、対応するデバイスのディスクを確認したりできます。どのチャンネルが映像を表示できるかは、プランの上限によって決まります。

デバイスの一覧

パス：画面下部のデバイスタブ

各行には、デバイスの名前、モデル、アドレスが表示されます。左のアイコンは、レコーダーかカメラかを示します。右側では、接続インジケータの下に、種類を示すラベル（レコーダーまたはカメラ）が表示されます。インジケータは、デバイスが HTTP ポートで接続を受け付けるかどうかを示します。確認は、その行が画面に表示されるたびに始まり、約 4 秒間、応答を待ちます。

インジケータ意味
小さく回転する円確認中です。
緑色の Wi-Fi 記号デバイスが応答しました（接続可能）。
赤色で斜線の入った Wi-Fi 記号デバイスが応答しませんでした（このデバイスに接続できません。ネットワークまたはファイアウォールを確認してください。）。デバイスの電源が切れているか、別のネットワークにあるか、ファイアウォールでブロックされている可能性があります。
赤い再生記号または紫のテレビ記号YouTube の配信または Twitch チャンネルです。確認するデバイスがありません。詳しくは「YouTube と Twitch の配信」を参照してください。
インジケータが確認するのは HTTP ポートだけです

保存された HTTP ポートで接続を受け付けないデバイスは、映像が正常に動作していても、赤い記号が表示されることがあります。たとえば、一覧のブランドで追加したカメラです。サンプルカメラはアドレス demo を使用します。これはネットワーク上のデバイスではないため、常に赤い記号が表示されます。

右上のプラスボタンでメニューが開きます。デバイスを追加は、レコーダーまたはカメラを追加します。詳しくは第3章「デバイスの追加」を参照してください。各サービスを利用できる国や地域では、メニューにYouTube ライブ配信とTwitch チャンネルもあり、ライブ配信をカメラとして追加できます。詳しくは「YouTube のライブ配信と Twitch のチャンネルを追加する」を参照してください。

デバイスを開く

  1. 画面下部のデバイスタブをタップします。

    確認：デバイスの一覧が表示されます。デバイスを追加していない場合は、デバイスがありません、最初のカメラまたはレコーダーを追加して始めましょう。の文、デバイスを追加ボタンが表示されます。追加の手順は第3章「デバイスの追加」を参照してください。

  2. 一覧の行をタップします。

    確認：デバイスのページが開きます。詳しくは「デバイスのページ」を参照してください。

デバイスの並べ替え

  1. 左上の編集をタップします。このボタンは、デバイスが 1 台以上あるときにのみ表示されます。

    確認：各行の右側にドラッグハンドルが表示され、ボタンが完了に変わります。

  2. 行のハンドルに触れ、行を新しい位置までドラッグします。

    確認：行が新しい位置に留まります。

  3. 完了をタップします。

    確認：一覧が編集モードを終了し、順序が保存されます。ライブタブのデバイス選択リストも、同じ順序になります。

デバイスの削除

削除すると、デバイスが Cam Hub から取り除かれます。デバイス自体は変更されません。

  1. デバイスの行を左にスワイプします。

    確認：行の右側に、ゴミ箱の記号が付いた削除ボタンが表示されます。大きくスワイプしても確認画面が開くだけで、確認なしでは何も削除されません。

  2. 削除をタップします。

    確認：このデバイスを削除しますか？のダイアログが表示されます。デバイスの名前とカメラ数が示され、この操作は取り消せないことが説明されます。デバイスにパスワードが保存されている場合は、そのパスワードも削除されることが説明されます。

  3. ダイアログの削除をタップします。デバイスを残す場合は、代わりにダイアログの外側をタップします。

    確認：行が消えます。デバイス、そのチャンネル、保存されたパスワード、SNMP の設定、ディスクの読み取り結果が、この iPhone または iPad から削除されます。そのデバイスは LiveView Mix ウォールからも削除されます。ライブタブと起動時に開くの選択肢にそのデバイスが選ばれていた場合は、そこからも削除されます。

削除したレコーダーは、プランで許可されているレコーダーの台数に数えられなくなります。詳しくは「プランの上限とチャンネルの有効化」を参照してください。デバイスをもう一度追加するには、第3章「デバイスの追加」を参照してください。

デバイスのページ

デバイスのページの上部には情報カードがあり、対応するデバイスではディスクの状態の行が続きます。その下のカメラの見出しの下に、デバイスのチャンネルがサムネイルで表示されます。タイトルはデバイスの名前です。サムネイルは、画面に収まる列数で並びます。

  • 情報カード：デバイスの名前と種類のほか、モデル、IP アドレス、ポート（HTTP ポート）、HTTPS（HTTPS ポート。HTTPS がオンの場合のみ）、シリアル番号、ファームウェア、カメラ（チャンネル数）の行を表示します。シリアル番号とファームウェアは、デバイスが報告した場合にのみ表示されます。YouTube または Twitch の配信では、IP アドレスとポートの代わりにリンクの行が表示されます。
  • ディスクの状態：デバイスのディスクのレポートを開きます。詳しくは「ディスクの状態」を参照してください。行の右側のオレンジ色の三角形または赤い記号は、前回の読み取りで最も悪かったディスクの判定を示します。
  • サムネイル：レコーダーではチャンネルごとに 1 つ、単体カメラではチャンネルが 1 つなのでサムネイルも 1 つ表示されます。各サムネイルの左下には、チャンネルの番号と名前が表示されます。サムネイルは、設定 › デフォルトの画質 › 複数のカメラに従って SD または HD になります（変更しない限り SD）。設定を変更すると、このページにすぐに反映されます。このページには、SD と HD を切り替える専用のボタンはありません。
  • 更新：Cam Hub は、ページを開いたとき（同じデバイスについては最大で 1 分に 1 回）と、ページを下に引いたときに毎回、デバイスからチャンネルの一覧を読み取ります。名前とオンラインの状態が更新され、デバイスに追加されたチャンネルが表示され、デバイスから削除されたチャンネルが消えます。新しいチャンネルは、プランで許可されている場合にのみ有効になり、許可されていない場合は無効と表示されます。Cam Hub で付けた名前は保持されます。デバイスが応答しない場合や、不完全に見える一覧（チャンネルがまったくない、または複数あるはずのチャンネルが 1 つだけ）が返された場合は、一覧はそのままで、メッセージは表示されません。
  • サインインの拒否：更新中に、保存されたユーザー名またはパスワードをデバイスが拒否した場合は、サムネイルの上にユーザー名またはパスワードが違います。のメッセージと認証情報を編集ボタンが表示されます。詳しくは「デバイスのユーザー名とパスワードの変更」を参照してください。
  • パスワード未保存：この iPhone または iPad にデバイスのパスワードが保存されていない場合は、サムネイルの上に、パスワードを入力ボタンとiCloud から復元ボタンの付いたメッセージが表示されます。詳しくは「パスワードが保存されていないデバイス」を参照してください。
  • チャンネルなし：デバイスがチャンネルを報告しない場合、ページにはカメラが見つかりません。と、チャンネルの一覧をもう一度読み取る更新ボタンが表示されます。

右上の 3 つのボタンは、左から順に、黒帯ボタン、フルスクリーンウォール、鉛筆ボタンです。ユーザー名とパスワードでサインインするデバイスでは、鉛筆ボタン（デバイスを編集）で名前を変更と認証情報を編集のメニューが開きます。デバイスが HTTPS を提供している場合や、HTTPS がオンになっている場合は、メニューにHTTPSも表示されます。「保存したデバイスの HTTPS」を参照してください。サンプルカメラと、YouTube および Twitch の配信では、鉛筆ボタンがそのまま名前を変更ボタンになります。

本のように持った iPhone Duo

iPhone Duo を半分に折り曲げ、折り目が上から下に通る向きで持つと、デバイスのページの一方の半分にサムネイルが、もう一方の半分に 1 台のカメラのページが表示されます。サムネイルをタップすると、新しいページを開く代わりに、そのカメラがもう一方の半分に表示されます。最初は、映像を表示できる最初のカメラが表示されます。詳しくは「折り曲げた iPhone Duo での表示」を参照してください。

詳細の表示と非表示

  1. 情報カードの右にある矢印（詳細を非表示）をタップします。

    確認：名前の下の行が消え、矢印の向きが変わります（詳細を表示）。もう一度タップすると、行が表示されます。この選択は、デバイスごとに保存されます。

デバイスの名前の変更

  1. デバイスのページの右上にある鉛筆ボタンをタップします。

    確認：ユーザー名とパスワードでサインインするデバイスでは、名前を変更と認証情報を編集（デバイスによってはHTTPSも）のメニューが開きます。それ以外のデバイスでは、次の手順のダイアログがすぐに開きます。

  2. メニューが表示された場合は、名前を変更をタップします。

    確認：デバイス名を変更のダイアログが開き、このデバイスに、わかりやすい名前を付けてください。のテキストと、名前欄の現在の名前が表示されます。

  3. 名前欄に、新しい名前を入力します。

    確認：欄に新しい名前が表示されます。

  4. 保存をタップします。

    確認：ページのタイトルとデバイスの一覧に、新しい名前が表示されます。空の名前は無視され、元の名前のままになります。名前は Cam Hub 内にのみ保存され、デバイス自体は変更されません。

このページでの黒帯の扱いの変更

黒帯ボタンは、3 つのボタンのうち左側のボタンです。タップするたびに 3 つのモードの次のモードが選択され、3 番目の次は 1 番目に戻ります。

モード効果
デフォルト映像全体が表示されます。映像の形とサムネイルの形が異なる部分には、黒帯が表示されます。
拡大して埋めるサムネイルがいっぱいになるまで、縦横比を保って映像が拡大されます。映像の端は切り取られます。
引き伸ばして埋めるサムネイルがいっぱいになるまで、映像が引き伸ばされます。映像は歪みます。

  1. 右上の 3 つのボタンのうち、左のボタンをタップします。

    確認：すべてのサムネイルが次のモードに切り替わり、ボタンのアイコンも現在のモードに合わせて変わります。

最初のモードは、設定 › 映像 › 黒帯で決まります。このページで行った変更は、このページにのみ適用され、保存されません。

デバイスのユーザー名とパスワードの変更

設置業者による変更やリセットの後など、デバイス自体でパスワードが変更されると、Cam Hub はサインインできなくなり、サムネイルにユーザー名またはパスワードが違います。と表示されます。認証情報を編集は、同じデバイスの新しいユーザー名とパスワードを保存します。カメラ、その名前、有効と一時停止の選択、LiveView Mix のウォール上の位置は、そのまま残ります。デバイスを削除して追加し直すと、これらは失われます。

認証情報を編集は、ユーザー名とパスワードでサインインするすべてのデバイスで使用できます。サンプルカメラと、YouTube および Twitch の配信では使用できません。ここでは、デバイスのアドレスとポートは変更されません。

  1. 対象のデバイスのページを開きます。

    確認：デバイスのページが表示されます。前回の更新が拒否された場合は、サムネイルの上にユーザー名またはパスワードが違います。のメッセージと認証情報を編集ボタンが表示されます。このボタンでも、手順 3 と同じ画面が開きます。

  2. 右上の鉛筆ボタン（デバイスを編集）をタップします。

    確認：名前を変更と認証情報を編集のメニューが開きます。HTTPS を提供するデバイスでは、その下にHTTPSが続きます。

  3. 認証情報を編集をタップします。

デバイスごとに 1 回のサインイン

Web インターフェースで HTTPS を提供しているデバイスは、通常の HTTP の代わりに HTTPS で制御できます。HTTPS は、デバイスごとにオンにしない限りオフのままです。HTTPS では、Cam Hub は、HTTPS をオンにしたときに信頼した証明書か、デバイスのアドレス向けに公的な認証局が発行した証明書だけを受け入れます。そのため、そのような証明書が自動更新されても、接続は続きます。RTSP で取得する映像は、この設定では暗号化されません。

鉛筆ボタンのメニューのHTTPSは、HTTPS で応答したデバイスと、HTTPS がオンになっているデバイスに表示されます。Cam Hub はサインインせずにデバイスに問い合わせ、ポートが証明書を提示するかどうかだけを確認します。応答したデバイスの結果は 1 週間、応答しなかったデバイスの結果は 1 日記憶されます。デバイスのページを下に引くと、すぐに問い合わせ直します。デバイスファミリー独自のプロトコル、RTSP、一覧にあるブランドで接続したデバイスや、サンプルカメラ、YouTube と Twitch の配信には、この項目は表示されません。

ディスクの状態

ディスクの状態は、レコーダーまたは NAS のディスクの状態を報告します。各ディスクが正常かどうか、その温度、ドライブ自身の S.M.A.R.T. データがわかるので、録画が失われる前に、故障しかけているディスクを交換できます。Cam Hub はこの情報を読み取るだけで、デバイスでは何も変更しません。

ディスクの状態の行は、ディスクを報告できるデバイスのページに表示されます。対象は、ディスクの報告に対応したブランドの接続で追加したデバイス（第16章「対応ブランドと接続方法」を参照）と、ディスクの状態を SNMP で提供する NAS です。ONVIF またはストリームのアドレスで追加したデバイス、YouTube と Twitch の配信、サンプルカメラには、この行は表示されません。

    確認：SNMP 設定の画面が開き、コミュニティ欄（初回は public）、ポート欄（161）、SNMP を有効にする場所についてのメモが表示されます。

  2. コミュニティ欄に、NAS に設定したコミュニティ名を入力します。

    確認：欄にコミュニティ名が表示されます。

  3. NAS が 161 以外のポートで SNMP に応答する場合のみ、ポートを変更します。

    確認：欄にポートが表示されます。

  4. 保存をタップします。

    確認：画面が閉じ、ディスクの状態が NAS を読み取ります。欄が空の場合や、ポートが 1〜65535 の範囲外の場合は、画面が開いたままコミュニティ名と、1〜65535 のポート番号を入力してください。と表示されます。NAS が応答しない場合は、ページにその旨と問い合わせたポートが示され、SNMP が有効になっているか、コミュニティ名が一致しているかを確認するよう求められます。ポートがブロックされている場合も同じ結果になります。NAS は知らないコミュニティ名には応答しないため、コミュニティ名の誤りは、NAS に到達できない場合と同じように見えます。

  • 利用できない場合：YouTube と Twitch は、一部の国や地域では利用できません。そのような国や地域では、一覧の配信には名前とこの地域または言語ではご利用いただけません。だけが表示されます。
